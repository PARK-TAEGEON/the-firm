# GEN-001 — 사건 생성기

Lane: experiment
Owner: Claude (생성기 코어, 검증기) + Codex (원형·반전 문구 초안)
Branch: task/gen-001
Owns: courtroom-prototype/generator/
Read only: docs/CURRENT.md, courtroom-prototype/data/trial-case.js (출력 형식 참고)

## 목표
원형 × 변수 × 반전 × 인물 조합으로 사건을 만든다. 숨은 진실을 먼저 만들고, 증거·증언·서류를 진실에서 도출한다.

## 범위
- 원형 3개: 형사 폭행·상해, 음주운전, 임대차 보증금 반환
- 반전 모듈 5개 (각각 대응 조사 카드 + 상대의 수습 + 재반대 한 세트)
- 등급: 일상 사건(요약 파일) / 승부 사건(trial-case 형식 출력)
- 대형 사건 3개 설계 문서 (구현은 1개, DEMO-001이 사용). 실제 사건을 알아볼 수 있는 이름·날짜·장소 금지, 법리 뼈대만 차용
- 시드 기반 난수, 같은 시드 → 같은 사건

## 역할 분담
- Codex: `generator/content/`에 원형·반전 데이터와 문구 초안
- Claude: `generator/core/` 생성 로직, 검증기, 밸런스 점검 스크립트, Codex 초안 검토

## 완료 기준
- 분야 3개 × 사건 10개 출력을 사람이 읽었을 때 모순·어색한 문장 없음
- 밸런스 점검: 절대 못 이기는 승부 사건 0개, 준비 없이 이기는 사건 0개
- `node --test` 로 결정성·검증기 테스트 통과
