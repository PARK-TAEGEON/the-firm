## 목표
WORLD의 사건이 실제 재판(GEN 자동 진행)을 거쳐 사건 기록으로 남고, 기록이 명성과 커리어를 만들며, 인물·로펌 페이지에서 그 역사를 볼 수 있다.

## 범위
1. **사건 기록 형식**: 원형·시드·생성기 버전·팩 버전·당사자(로펌·변호사·검사·판사)·결과(§2.9 공식 용어)·결정적 장면 한 줄·사건 등급. 시드로 재생성 가능해야 함(결정성 테스트).
2. **대형·승부 사건만 엔진**: WORLD가 배정한 대형·승부 사건은 GEN 자동 진행으로 판결. 변호사 역량은 자동 정책의 선택 품질로만(N4). 일상 사건은 통계층. 연간 엔진 실행 수와 실행 시간 보고.
3. **명성(별)**: §2.9 규칙. 기대 대비 평가, 상대 명성·등급 반영, 휴면 감쇠, 대표 분야 꼬리표. 판결에 미반영 테스트.
4. **시작 세계(혼합 방식, §2.10)**: 현실 분포로 연차가 섞인 명단 생성 → 저밀도 선행 시뮬(기간은 매개변수) → 시작 시점 분포를 docs/reference 기준과 비교한 표.
5. **페이지 출력(텍스트)**: 인물(경력 타임라인·명성 별·최근 사건 기록·라이벌·알려진 점/모르는 점), 로펌(별·소속·대표 사건), 판사(주목 판결). 공개 정보만(DEC-016).
6. **업계 소식 연동**: 대형 사건 기사가 사건 기록에서 나오고 기자 말투 허용, 기사에서 기록으로 링크.
7. 한국 고유 값·분포는 data(팩)로(DEC-032). 실제 로펌·인물 이름 금지.

## 완료 기준
- 같은 시드 → 같은 세계·기록·페이지(결정성)
- 기록 재생성 결과가 저장된 결과와 일치
- 명성 상위 10명에 "무명에서 큰 사건으로 뜬" 사례가 1명 이상 자연 발생(이야기 검증)
- 10년 실행 시간 보고(목표: 수 초 단위)
- REPORT에 인물 페이지 샘플 5개(신입·중견·베테랑·전관·판사)와 로펌 페이지 2개
