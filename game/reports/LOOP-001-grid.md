# LOOP-001 엔딩 조건 격자

엔진의 위대한 로펌 조건은 12주차 명성 42, 누적 매출 11,000만 원이다. 임대료는 설계의 6.25배(T1 500만, T2 750만, T3 1,250만), 성공보수는 승소 `fee`·조정 절반·패소 0, 강등은 주 종료 때 한 단계다.

자동 정책은 슬롯·남은 업무·수임료·난이도만 본다. 강등은 T2 명성 15, T3 명성 35·누적 매출 4,000만만 본다. 폐업은 현금이 두 주 연속 마이너스일 때이고 엔딩 문턱보다 먼저 판정한다. 그래서 위대한 로펌 문턱은 12주를 마친 판의 이름만 바꾼다. 조합 4개 × 시드 300을 한 번씩 돌리고 20칸은 그 기록으로 다시 분류했다. 기본 조합에서 엔진 엔딩(위대한 51, 폐업 18)과 재분류가 같다.

명령:

```
cd game && node scripts/ending-grid.js
```

## 정의

- 위대한 로펌: 12주를 마쳤고, 폐업이 아니며, 명성이 칸의 기준 이상이고 누적 매출도 칸의 기준 이상.
- 폐업: 현금이 두 주 연속 마이너스. 문턱과 무관해서 20칸이 같다.
- 명성 미달 탈락: 12주를 마쳤는데 명성이 칸의 기준 미만. 매출도 모자라면 이쪽만 센다.
- 매출 미달 탈락: 12주를 마쳤고 명성은 칸의 기준 이상인데 누적 매출이 칸의 기준 미만.
- 후보: (1) 기본 위대한 로펌 30~60건(10~20%) (2) 기본 폐업 15~30건(5~10%) (3) 네 조합 모두 위대한 로펌 9~105건(3~35%) (4) 기본 조합에 명성 미달과 매출 미달이 둘 다 1건 이상. 경계는 포함한다.
