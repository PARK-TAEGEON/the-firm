# LOOP-001 엔딩 분포

위대한 로펌은 12주차 명성 40 · 누적 매출 1억 2,000만 원이다. 성공보수는 승소 `fee`, 조정 절반, 패소 0이다. 주간 임대료는 설계값의 6.25배다. 이번 변경은 명성 문턱뿐이고 다른 숫자는 그대로다.

## 최종 숫자

| 항목 | 설계 | 이번 |
| --- | --- | --- |
| 착수금 | 수임 시 `fee` (영업 보정) | 같음 |
| 성공보수 | 승소 = `fee`, 조정 = 절반, 패소 = 0 | 같음 |
| 임대료 배수 | 1배 | 6.25배 (직전 6.4배) |
| T1 주간 임대료 | 80만 원 | 500만 원 |
| T2 주간 임대료 | 120만 원 | 750만 원 |
| T3 주간 임대료 | 200만 원 | 1,250만 원 |
| 주급 | 사무원 70만, 보조원 100만 | 같음 |
| T1 주간 운영비 (주급+임대료) | 250만 원 | 670만 원 |
| T2 주간 운영비 (주급+임대료) | 290만 원 | 920만 원 |
| T3 주간 운영비 (주급+임대료) | 370만 원 | 1,420만 원 |
| 위대한 로펌 | 직전: 12주차 명성 45 · 누적 매출 1억 2,000만 | 12주차 명성 40 · 누적 매출 1억 2,000만 |
| 강등 | 없음 | 주 종료 때 현재 등급 기준 미달이면 한 단계 |

강등은 정산 뒤다. T3는 명성 35 미만이거나 누적 매출 4,000만 미만이면 T2, T2는 명성 15 미만이면 T1이다. 한 주에 두 단계는 내리지 않는다. 이번 주 임대료는 주 시작 등급이고, 다음 주 임대료와 난이도 해금이 강등된 등급을 따른다. 이미 맡은 사건은 유지한다. 승급은 기존처럼 한 주에 T3까지 갈 수 있다.

자동 정책(수임은 이번 주 처리량 약 2주치까지만, 배정은 철회가 가까운 업무를 성공률이 높은 직원에게)으로 시드 1부터 300까지 돌렸다. 채용·교육·휴가·광고는 넘겼다. T1·T2·T3는 위대한 로펌이 아닌 12주 엔딩의 도달 등급이다.

명령:

```
cd game && node scripts/ending-report.js
```
