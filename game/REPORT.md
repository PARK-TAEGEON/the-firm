## 2. 완료 기준
1. **한 판이 이어진다 — 충족.** 타이틀 → 상담 → 5업무일 → 계획서(수정·담당 비교·날인) → 자동 공판(개입 2번) → 결산 → 계획서로 다시, 세 화면 크기에서 자동 플레이 통과.
2. **능력치·사무소 → 판결 — 충족.** 테스트: 기록 검토 3단계 모두 도달, 담당별 확인 항목 수(김현우 3/이정우 2/박서윤 2, 기한 넘김 기준), 신문 보너스, 개입 횟수(김현우·박서윤 2, 이정우 0), 기본 초안 폭행 유죄 → 합의 상담을 넣고 문구를 고치면 공소기각, 유도신문을 그냥 두면 상해 유죄.
3. **결정성·원자성·저장 — 충족.** 같은 선택 → 같은 기록·결산. 실패 명령 뒤 저장 동일. 결정 대기 중 저장을 다시 읽고 같은 결정을 내리면 view 전체 동일. 깨진·위조 저장 거부.
4. **문서 — 충족.** RULES.md P1~P7, 이 문서, `.agent/tasks/PORTFOLIO-002.md`.

## 4. 사람 확인이 필요한 것
- **재미.** 사람이 플레이해 본 적이 없다. 특히 "초안을 고치는 판단"이 단서 없이 가능한지(합의 상담의 가치가 계획서에서 보이는지) 확인해야 한다.
- **개입 빈도.** 김현우를 쓰면 매번 2번 묻는다. 너무 잦은지, 반대로 이정우를 쓰면 공판이 그냥 흘러가 지루한지.
- **자동 공판 속도.** 기록 약 40개를 보통 1.15초, 빠르게 0.42초 간격으로 보여 준다.
- **능력치 숫자.** 전부 임시값이다. 상해 결과가 대부분인 것은 방침 "접촉 부인"처럼 영상과 어긋나는 조합이 많기 때문이며, 수치 조정 전 플레이 소감이 먼저다.
