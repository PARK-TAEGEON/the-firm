# PORTFOLIO-001 규칙 — 실험용 authored 규칙, DEC 아님

이 폴더에서 새로 정한 규칙 전부다. 두 엔진(vendor/) 안의 규칙·수치는 바꾸지 않았다.

## R1. 사무소의 한 주 → 공판 준비 횟수 (`src/bridge.js`)
`정민호 · 기록 검토`의 완료 시점으로 공판 전 반나절 횟수를 정한다.

| 기록 검토 | 반나절 |
|---|---:|
| 기한(6/17) 안에 완료 | 4 |
| 기한을 넘겨 완료 | 3 |
| 주간 안에 미완료 | 2 |

- 사건 정의 원본은 그대로 두고 사본의 `prep.budget`만 바꿔 재판 세션에 넘긴다.
- 기본 배정을 그대로 두면 3번이 된다. 4번은 담당 조정으로만 나온다(테스트로 확인).
- 근거: 준비 가능한 범위가 넓을수록 도달 가능한 판결이 넓어진다. 신참 검사 기준 탐색에서 공소기각은 4번에서 12개 조합, 3번에서 3개, 2번에서 0개였다(REPORT 참조).

## R2. 판결 → 성공보수 (`SUCCESS_FEE`)
무죄·공소기각 300만 원, 폭행 유죄 150만 원, 상해 유죄 0원. 결산 화면에만 더하며 경영 엔진 상태(원장)는 바꾸지 않는다. 실제 형사 성공보수 약정과 무관한 단순화다.

## R3. 진행 순서
상담 → 5업무일 → 한 주 마감 → 검사 선택 → 공판 준비 → 공판 → 결산. 윤지훈 수임 여부는 기존 엔진 규칙 그대로다(결정 전에는 하루 진행 불가).

## R4. 다시 하기
"공판만 다시"는 같은 한 주 결과(같은 준비 횟수)로 검사 선택부터 다시 한다. "새 한 주"는 전부 처음부터다.

## R5. 저장
사무소 상태 + 공판 명령 기록을 브라우저 저장소에 둔다. 공판은 기록을 다시 실행해 복원한다. 다시 실행이 실패하는 저장은 통째로 거부한다.

## R6. 표시 규칙
- 판세·신뢰는 문장으로만 보인다(DEC-031 N1~N7 방향). 숫자로 보이는 것은 엔진이 원래 공개하던 질문 횟수·반나절·금액뿐이다.
- 용어 설명의 조문은 전부 "확인 필요"로 표시한다. 법률 검수 전이다.
- 효과음은 합성음이며 판정과 무관하다.
