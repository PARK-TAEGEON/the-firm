# TF-UI-001 · 실험용 authored 시각 규칙, DEC 아님

게임 규칙을 새로 정하지 않았다. 아래는 G1 목업의 표시와 디자인 검증에만 적용된다.

1. A/B/C는 하나의 공개 fixture.js를 사용한다. offline 추출은 원본 FirmPlanDemo.play의 포함/제외 두 경로에서 수행하며 브라우저는 해당 서비스를 로드하지 않는다.
2. 상담 원문 8개, 공개 자료 카드 4개, 실제 화자/ID/seq/발언, 기존 outcome을 보존한다. 내부 effects/점수/작가 진실을 fixture에 포함하지 않는다.
3. '이 계획 승인'은 G1에서 고정 결과 화면으로 이동하는 시연 컨트롤이다. 외부 제출·게임 실행·새 판정을 발생시키지 않는다. 상단과 footer에서 fixture임을 밝힌다.
4. 단계 탭은 디자인 검토를 위한 바로가기다. G3의 실제 서비스 lifecycle/접근 게이트를 구현하거나 승인하는 기능이 아니다.
5. 현장 동선 선택·취소·저장은 목업 로컬 표시 상태다. 상담 재방문과 기록 탐색으로 바뀌지 않는다. 새로고침 시 저장은 없다.
6. 기본 계획의 편집 순서는 영상→진료→현장, 실제 기록 표시는 진료→영상→검찰 재주신문→현장 대응 순서를 유지한다.
7. 계획은 점선/문구, 수행은 중립색/문구, 반론은 화자/강조선, 판단은 독립 구획으로 표시한다. 유리함과 실행 여부를 같은 체크나 색으로 만들지 않는다.
8. 기회 없음·표시 오류·긴 합성 한글은 components.html의 명시적 합성 상태 fixture다. 이 사건에서 발생한 기록이나 새 법정 규칙이 아니다.
9. A는 사건철의 대조, B는 발언 중심, C는 요약과 단계 중심이다. 색만 바꾸지 않는다. 자세한 글꼴·여백·반응형 값은 DESIGN-SYSTEM.md와 tokens.json.
10. 서비스 오류 처리/중복 명령/새로고침 복원/G3 실제 브라우저 회귀는 승인 후 계약에서 실제 서비스로 검증한다. G1의 고정 fixture 불변 검사를 실제 게임 기능 구현으로 보고하지 않는다.
