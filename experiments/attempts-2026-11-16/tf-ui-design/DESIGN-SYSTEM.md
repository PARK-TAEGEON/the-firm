# THE FIRM · 디자인 시스템 제안 v1.0.0

상태: G1 비교용 제안. 사람 선택 후 선택안 토큰을 고정한다. A/B/C는 같은 의미와 fixture를 사용하며, 토큰·레이아웃·읽는 순서를 함께 비교한다. [직접 보기](components.html) · [토큰](tokens.json).

## 타이포그래피와 간격

- 한글 본문: 로컬 맑은 고딕(Malgun Gothic), Apple SD Gothic Neo, sans-serif. 외부 글꼴 요청 없음. A의 페이지·판결 제목은 바탕(Batang) 계열 명조, B/C는 고딕이다. 시스템에 글꼴이 없으면 fallback이 달라질 수 있다.
- 기본 본문 15px/1.65, 실제 인용 16px/1.85. 큰 제목 A 34px, B 28px, C 27px; 작은 화면 25px. 섹션 22px, 항목 16px. 보조 정보 12px, 원 출처 11px. B 증언 21px로 발언에 무게를 준다.
- 간격 단위 4/8/12/16/20/24/28/32/40/48px. 패널 안쪽 22–26px, 주요 섹션 사이 24–32px. 좁은 화면의 좌우 여백 18px.
- 긴 한글은 단어 단위로 접되 긴 ID/합성 긴 문자열은 anywhere fallback. 원문은 영구 생략하지 않는다. 고정 글자수 제한 없음.

| 안 | 공간·위계 | 색 역할 | 읽는 방식 |

| C 업무 | 왼쪽 세로 단계 rail, 요약 다음 세로 계획, 상단 행동 띠, 둥근 패널 | 중립 배경 #f4f6f8 / 남색 본문 #1e3042 / 주 행동 #233f70 | 짧은 요약부터 행동으로, 자료는 항목에서 펼침. 경영 수치·대시보드 없음 |

B에 새 법정/인물 아트는 없다. 기존 office_lounge는 상담 장소에만 쓰며 법정 배경으로 오인시키지 않는다. 법정은 중립 무대와 기존 default.svg를 사용한다. 실제 개별 초상이 없는 baseline을 존중한다. 아트가 없어도 모든 말과 행동은 텍스트로 읽을 수 있다. 자산 원출처는 [기존 CREDITS](../../../courtroom-prototype/assets/CREDITS.md).

## 공통 컴포넌트

| 컴포넌트 | 의미·조작 | 표현 |
|---|---|---|
| 단계 안내 | 현재 위치 / 디자인 탐색 링크 | 숫자·단계명·aria-current. 진행률이나 성공 색 아님 |
| 주 행동 | 다음 단계 또는 명시적 내부 승인 | 채움 버튼 한 개; 44px 이상. 데스크톱 첫 화면에 배치 |
| 보조 행동 | 수정·상담 재방문·원문 확인 | 선/텍스트 버튼. 펼침과 선택 컨트롤 분리 |
| 계획 포함 | 아직 승인/실행 사실이 아님 | 점선 테두리와 '계획 포함 · 아직 미수행' |
| 신문 수행 | 실제 해당 record가 있음 | 중립색 사각 라벨. 체크/초록 성공색 없음 |
| 미실행 | 계획 제외 또는 실행 기록 없음 | 텍스트 사유. 답변을 대신 발명하지 않음 |
| 기회 없음 | 계획 포함이지만 답변이 기록되지 않음 | 별도 문구, 컴포넌트 합성 예시라고 표시 |
| 인물 발언 | 실제 화자와 원문 | 이름·역할·인용 부호·기록 번호; 발언이 증거가 되는지 추정하지 않음 |
| 자료 원문 | 확보한 공개 자료·출처 | details/summary로 원문과 원본 SHA 링크. 요약/원문 분리 |
| 상대 반론 | PROSECUTOR 발언 | '검찰 반론' 제목, 강조선, 화자와 원 문맥 접근 |
| 판결 | session outcome의 별도 판단 | 이중선/상단선 독립 영역, 죄명·주문·쟁점별 판단, 실험 양형 표시 |
| 오류 | 결과를 확인하지 못함 | alert + 원인/미확인 표시. 성공·판정으로 변환 금지 |

## 접근성과 크기

일반 본문/보조 본문/링크·주 행동의 색쌍은 4.5:1 이상을 목표로 검사한다. 색만으로 구별하지 않고 모든 상태에 텍스트와 선 형태를 둔다. 3px 명확한 focus-visible과 4px offset. 단계 전환 시 제목으로 포커스, 편집 완료/취소 시 편집 버튼, 체크 변경 시 같은 체크, 다음 대사 후 다음 버튼을 유지한다. 전체 장면 대신 작은 aria-live만 사용한다. 표준 details는 키보드로 접근한다. prefers-reduced-motion에서는 전환을 끈다.

1440×900, 1280×720, 390×844 실제 Edge에서 검사한다. 좁은 화면은 한 열로 바뀌며 텍스트/판결을 잘라내지 않는다. 법정의 보조 인물 rail은 작은 화면에서 숨기고 단계 탐색의 계획 화면과 전체 기록 원문에서 근거에 접근한다. 상태 갤러리에서 긴 한글/긴 발언/기회 없음/오류를 별도로 점검한다. 전체 목업 접근성 인증이나 실제 게임의 접근성 완료를 주장하지 않는다.

## 승인 경계

편집 중에는 저장/취소 toolbar만 화면 위에 유지하고 현장 동선 checkbox를 화면 중앙으로 이동한다. 스크롤해도 편집의 다음 행동을 잃지 않으며 체크박스가 toolbar에 가리지 않음을 1280×720·390×844에서 별도로 검사한다. 일반 읽기 상태에서는 toolbar를 고정하지 않는다.

tokens.json은 아직 proposed다. 선택된 안, 패킷 해시, 승인 범위를 DECISIONS.md에 기록한 후에만 G3 계약의 UI 토큰 파일로 이관할 수 있다. 여기서의 행위는 고정 스냅샷 표시와 선택 연습이며 실제 서비스·판정을 구현하지 않는다.
