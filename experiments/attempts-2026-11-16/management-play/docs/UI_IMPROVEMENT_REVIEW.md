# UI 개선 독립 검토

검토일: 2026-10-27. 대상: 첨부된 경영 v0.4를 기준으로 한 UI 개선본. 기능 검증, 화면 가독성, 사람의 재미 판단을 구분한다.

## 디자인 기준과 참조 범위

기존 `references/original/THE_FIRM_UI_Prototype_v1.html`의 테마 토큰·헤더/진행 동선·목록/상세·인물 표시를 직접 읽었다. 기존 프로토타입의 A/B/C는 Navy & Brass / Paper & Ink / Verdict Graphite의 시각 테마다. 경영 실행본의 A/B/C는 브리핑 / 서류철 / 편성표의 화면 구조이므로 별개 선택이다.

`THE_FIRM_Font_Candidates.html`에서 F0~F9 조합과 설치형 후보(Pretendard, SUIT, Wanted Sans, Spoqa Han Sans Neo, LINE Seed Sans KR, Paperlogy, NEXON Lv2 Gothic, D2Coding, MaruBuri)를 확인했다. 후보의 이름이 보이는 것과 실제 서체가 로드된 것은 별개다. 기본 내장 Firm Sans/Noto Sans KR, 후보의 실제 사용 가능 상태, 오프라인 대체 표시를 나누어 검증한다.

아래 내용은 첨부 `02_REFERENCE_BRIEF.md`의 역할 제한을 이번 화면에 적용한 결정이다. 이 독립 검토에서는 외부 원격 이미지를 실제로 시각 검사하지 않았다. URL의 존재나 과거 브리프의 이미지 응답 확인을 이번 검토의 시각 확인으로 주장하지 않는다.

## 검증 기록

- 개선 전 기준선: `node --test tests/engine.test.cjs tests/audit-regressions.cjs tests/audit-ui.test.cjs tests/play-engine.test.cjs tests/play-ui.test.cjs` 직접 실행, 46개 통과 / 0개 실패.
- 신규 브라우저 검증: `node tests/ui-improvement-smoke.cjs` 직접 실행, 16개 그룹 통과 / 0개 실패. Chromium의 실제 `file://` 실행본을 검사했다.
- 대상 HTML SHA256: `db0aac8a264ecdf3a75f5343a0e03f9df51e5c713c46a343e616dc9939455727` (실행 전후 동일). 실행본이 다시 바뀌면 이 기록의 해시를 새 결과로 대신할 수 없다.
- 1440×900, 1366×768, 390×844에서 총 35개 화면·모달의 페이지 가로 넘침을 검사했다. 각 크기의 주요 진행 버튼과 배정 적용 버튼은 실제 화면 안에 있고 다른 요소에 가리지 않았다.
- 기본 오프라인 흐름: 런타임 오류 0건, 외부 요청 0건. 별도 명시적 온라인 글꼴 불러오기 테스트에서는 Google Fonts 요청 1건을 의도적으로 차단하고, 실패 후 재시도와 대체 글꼴 상태를 확인했다. 이 예상 네트워크 실패는 기본 실행의 오류와 분리해 기록했다.
- 실제 글꼴: 내장 Firm Sans(100~900) 로드를 확인했다. 검증 PC에서는 로컬 Noto Sans KR와 Noto Serif KR가 탐지되어 F1이 로드됐고, IBM Plex·Pretendard 등 미설치 후보는 대체 상태를 표시했다. F6는 본문 Noto Sans와 숫자 JetBrains의 상태를 나누어 표시했다. 다른 PC의 설치 상태는 달라질 수 있다.
- 신규 검증은 화면 조회·테마·글꼴·미적용 배정·취소의 게임 저장 불변성, 배정/우선순위의 실제 엔진 명령 일치, 5일 진행 결과, 0.3/0.4 저장 왕복, 1366/1440/390 화면과 모달 행동 접근을 다룬다.
- 기존 회귀의 게임 결과 기대값은 UI 편의에 맞춰 변경하지 않는다.

## 화면 시각 검수

`docs/ui-after/`의 업무실·구성원·사건·배정·모바일 업무실·모바일 배정 이미지를 직접 열어 보았다. 업무실의 위험과 수임 행동, 문서 영역의 요청/계약/준비 구분, 구성원별 가용시간, 모달의 적용/취소를 확인했다. 초기 모바일 헤더의 522px 가로 넘침은 수정 후 390px 검사에서 해소됐다.

검수 중 구성원 표의 남은 시간과 수행 시간이 한 줄에 붙는 표현, 업무실 직원 이름과 역할이 붙는 표현을 발견해 수정을 요청했다. 두 항목 모두 줄을 구분한 최종 CSS로 수정됐고, 재촬영된 `people.png`와 `office.png`를 다시 열어 분리된 표현을 확인했다. 최종 실행본에서 신규 16개 브라우저 검증 그룹을 다시 실행해 모두 통과했다.

## 남은 판단

자동 검증은 명령과 결과의 연결 및 UI 접근 조건을 확인한다. 사람의 실제 읽기 속도, 두 직원 비교의 부담, 반복 플레이의 재미는 자동 통과로 입증되지 않는다. 이번 검토는 사람 플레이테스트를 수행하지 않았다. 원격 참조 이미지의 시각 평가는 하지 않았다.
