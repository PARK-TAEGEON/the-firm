# THE FIRM 0.4 플레이 실험 — 독립 검토

검토일: 2026-10-27 (한국시간). 판정: **PASS — 현재 experiment 범위의 기능·일관성 검토**. 사람 플레이의 재미나 판매 가능성을 승인한 판정은 아니다. 검토자는 production·테스트·도구 코드를 수정하지 않았다.

## 직접 실행한 검증

- `node --test tests/engine.test.cjs tests/audit-regressions.cjs tests/play-engine.test.cjs`: 기존 엔진 16개, 감사 10개, 새 실험 11개, **37/37 통과**.
- `node --test tests/audit-ui.test.cjs tests/play-ui.test.cjs`: 실제 UI 렌더러의 기존 4개와 새 5개, **9/9 통과**.
- 이전 감사 JSON의 원본 7전략 명령 trace를 별도로 재생했다. 각 최종 상태 SHA-256과 일일 보고가 모두 기존 결과와 정확히 같았다.
- 시작 현금 60만원에서 새로운 인계 경로를 독립 실행했다. 윤지훈 자료 취합은 한도윤에게 유지하고, 나머지는 문서의 기한 준수 인계를 적용하면 **준비 3/3건, 업무 7/7개, 기한 위반 0, 환급 0, 최저 현금 26,000원, 현금 부족 0일**이다. 마감 현금은 4,368,000원, 확정 미수는 1,200,000원이다. 세 목표의 동시 달성이 가능함을 확인했다.

## 소스와 산출물에서 확인한 내용

1. 인자 없는 초기 상태와 0.3 저장은 기존 규칙을 유지한다. 명시적인 새 실험만 0.4 상태와 환급률을 가진다. 정상 명령에는 진행 중 계약 규칙을 변경하는 행동이 없다.
2. 환급은 윤지훈 준비 보고의 계약 기한 업무 수행 뒤 판정한다. 당일 완료와 수임 거절에는 발생하지 않고, 미완료이면 착수금의 설정 비율을 원 미만 버림하여 한 번 지출한다. 기존 미수금이나 이미 완료된 다른 업무의 보수를 소급 취소하지 않는다.
3. 환급 발생 조건·날짜·금액과 원장·현금·일일 보고를 대조한다. 환급 누락·중복·금액 변조 등 일관성이 깨진 JSON은 거부되며, 실패한 명령은 입력을 바꾸지 않는다.
4. 예측은 실제 일일 로직을 복사 상태에 적용한다. 새 summary는 실제 기록에서 계산하며, 예측 summary는 과거와 예상 잔여 기간을 합친 주간 결과다. 최저 현금은 시작 시점과 각 업무일 마감 잔액의 최솟값이다. 과거 기한 위반은 뒤늦게 완료해도 남는다.
5. UI는 수락 전에 환급 조건과 예상 환급을 보여준다. 배정 초안 취소는 게임을 바꾸지 않고, 새 주간 설정은 재시작을 확정해야 적용된다. 결과는 현금·미수·준비·기한·현금 부족·환급을 구분한다. 최저 현금의 일말 기준과 준비 완료가 승소·종결이 아니라는 설명도 있다.
6. 브라우저 담당자의 `docs/play-ui-qa/result.json`을 확인했다. 신규 11개 흐름이 통과했고 1366px·390px에서 본문 가로 넘침, 런타임 오류, 원격 요청, 실행 중 HTML 변경은 없었다. 이것은 검토자가 독립 재실행한 브라우저 검사가 아니라 별도 담당자의 실행 증거를 검토한 것이다. 결산 화면 캡처도 직접 확인했다.
7. 최종 `test-results.log`의 `node tools/play-verify.cjs --browser` 결과를 확인했다. 기존·신규 회귀 46개, 원본 70조건+70반복의 baseline 동일성, 새 실험 64회+64반복(14,035개 검증), 기존 브라우저 20개·신규 11개가 모두 통과했다. 여섯 명령 그룹의 종료 코드는 모두 0이다. 독립 검토자는 위 직접 실행 항목 외에 이 통합 로그를 읽어 확인했다.

## 검토 중 확인하고 해소한 설계 문제

처음 제안된 시작 현금 20만원은 정상 UI 배정으로 첫날의 현금 목표를 달성할 수 없다. 시작 가능한 법률 업무의 최소 수행비 16만원과 운영비 16만원만으로 이미 32만원이 필요하기 때문이다. 이 조건은 스트레스 검증으로 남기고 플레이용 도전은 60만원으로 바뀌었다. 위 독립 경로에서 준비·기한·현금 목표가 모두 달성되는 것을 확인했다. 기본 시나리오의 1,820만원과 보수·업무비·업무량은 변경하지 않았다.

## 남은 경계

- 환급은 신규 한 계약의 최종 준비 약속에만 적용한다. 모든 사건의 지연 유인이나 장기 경제를 해결했다고 일반화하지 않는다. 가용시간 압박 조건에서는 저비용 미이행 전략의 현금 우위가 다시 나타난다.
- 저장 검증은 상태 일관성 검사다. 이용자가 설정과 이력 전체를 일관되게 재작성하는 행위를 막는 서명·온라인 부정행위 방지 기능은 아니다.
- 현금 부족은 기록·경고만 하며 대출·파산을 만들지 않는다. 무료 인계와 원본 기본 수치를 유지했다. Godot·재판 기능은 이번 검토에서 실행하거나 확장하지 않았다.
- 자동 검증으로 확인한 것은 규칙과 선택 결과의 일관성이다. 병목을 이해하는지, 인계가 재미있는 판단인지, 재도전할 행동을 떠올리는지는 사람 플레이로 확인해야 한다.
