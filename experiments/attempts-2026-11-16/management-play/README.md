## 바로 실행

`dist/THE_FIRM_Management_Play_v0.4.html`을 내려받아 데스크톱 브라우저에서 엽니다. 서버·설치·네트워크 연결 없이 실행합니다. 한국어 가변 글꼴과 직원 초상도 파일에 포함되어 있습니다. 소스의 v0.3 HTML 이름은 기존 검증용 진입점을 유지하는 동일 바이트의 별칭이며 이전 구현 파일이 아닙니다.

1. **의뢰 내용 검토**에서 윤지훈 사건의 추가 16시간과 계약 조건을 확인합니다.
2. 수임하거나 거절한 다음 **구성원 → 담당 조정**을 엽니다.
3. 담당자·우선순위를 바꾸면서 현재/변경 후 완료 예정일과 현금을 비교합니다. 적용 전까지 실제 상태는 변하지 않습니다.
4. 오른쪽 위 **하루 진행**을 누릅니다. 실제 수행·입금·지출과 일일 보고가 생성됩니다.
5. 보고를 읽고 다시 배정합니다. 5업무일 후 주간 결과를 확인합니다.

첫 플레이에서는 **정민호 자료 정리가 끝나야 기록 검토를 시작한다**는 연결을 먼저 살펴보세요. 한도윤에게 싼 비용으로 자료 정리를 맡기면 변호사 시간이 남아도 검토가 대기할 수 있습니다. 변호사에게 자료 정리를 맡기면 기한·비용·다른 사건 준비가 함께 달라집니다.

## 세 화면을 비교하는 방법

상단의 A/B/C는 동일한 상태를 유지한 채 업무실의 중심을 바꿉니다.

| 화면 | 먼저 보이는 것 | 확인할 질문 |
|---|---|---|
| **A · 브리핑** | 오늘의 결정, 사무실 요약, 사건과 동료 | 다음에 해야 할 일을 빨리 찾을 수 있는가? |
| **B · 서류철** | 의뢰인의 요청, 계약 조건, 사건별 준비 범위 | 사람과 사건을 맡는 느낌이 드는가? |
| **C · 편성표** | 직원 × 업무일, 선행 업무로 인한 대기, 늦어지는 작업 | 배정을 바꾸는 이유와 효과를 이해할 수 있는가? |

사건·구성원·재무·보고 메뉴와 게임 상태는 공통입니다. 세 가지 색상 테마를 고르는 방식이 아닙니다.

## 저장과 다시 비교

새 주간 설정에서 **약속 책임 실험 / 원본 규칙 비교**, **첫 주 / 빠듯한 현금(시작 60만원)**을 선택할 수 있습니다. 선택만으로 현재 게임은 바뀌지 않고 새로 시작을 확정할 때 적용됩니다. 실험은 윤지훈 준비 보고의 계약기한 미완료에만 착수금 50% 환급을 적용합니다. 법정 승패나 실제 법률상 환불 규정은 아닙니다.

약속 지키기·준비 마치기·현금 지키기는 서로 다른 판단 축입니다. 진행 중에는 현재 배정을 유지한 예상이며, 주간 마감에는 실제 결과입니다. 최저 현금은 시작 및 각 업무일 **마감 잔액**의 최솟값으로, 하루 중 순간 잔액을 계산한 값은 아닙니다. 현금 부족 시 강제 종료하지 않습니다.

오른쪽의 조정 아이콘을 누르면 **저장과 다시 시작**을 엽니다.

- 브라우저 자동 저장: 성공할 때마다 현재 상태를 로컬에 저장합니다. 브라우저나 파일 위치를 바꾸면 저장소가 달라질 수 있습니다.
- **현재 진행 JSON 내보내기**: 다음 비교나 Godot 화면 확인을 위해 진행 상태를 보관합니다.
- **저장 JSON 가져오기**: 형식·연결 식별자·작업 이력·현금 일관성을 검사한 뒤 적용합니다. 잘못된 파일은 현재 상태를 바꾸지 않습니다.
- **처음부터 다시 시작**: 확인 후 첫날로 돌아갑니다. 현재 결과는 먼저 파일로 보관할 수 있습니다.

5업무일은 2026년 6월 12·15·16·17·18일입니다. 6월 19일 화면은 주간 마감 상태로, 그날의 추가 작업과 입금은 수행하지 않습니다. 마지막 날 보고를 끝내면 잔금은 다음 업무일 지급 예정 미수금으로 남습니다.

## Godot에서 같은 상태 확인

**이번 0.4 실험 저장의 Godot 호환은 검증하지 않았습니다.** 아래는 기존 0.3 원본 저장을 대상으로 한 대표 화면 안내입니다. Godot 코드는 이번 작업에서 변경하지 않았습니다.

`godot/project.godot`을 Godot 4.7.2에서 가져와 실행합니다. 시작 시 공통 엔진이 만든 기본 샘플을 표시합니다.

웹에서 JSON을 내보낸 다음 Godot의 **웹에서 내보낸 기록 열기**를 누르면 같은 상태를 **업무실 / 구성원 / 보고** 탭에서 확인할 수 있습니다.

이 Godot 프로젝트는 실제 `Control`·`Theme`·`Container`로 만든 **읽기 전용 대표 화면**입니다. 배정·날짜 진행·경제 계산을 Godot로 옮긴 것은 아닙니다. 네이티브 화면에서 한국어 글꼴·인물·정보 배치를 검토하는 출발점이며, 기존 THE FIRM 게임 프로젝트에 통합되어 있지 않습니다. 자세한 범위와 실행 방법은 `godot/README.md`를 확인하세요.

### 다시 빌드

프로젝트 디렉터리에서 실행합니다. 빌드에는 Python 3 표준 라이브러리만 필요합니다.

```sh
python3 tools/build.py
node tests/engine.test.cjs
```

브라우저 검증에는 Playwright와 Chromium 실행 파일이 필요합니다. `tests/ui-smoke.cjs`의 실행 설명을 확인하세요. Godot 검증 명령은 `godot/README.md`에 있습니다.

### 경계

- 수치와 이 시나리오의 처리 순서는 **실험용 설정**입니다. 정식 경제·인사 규칙으로 채택하지 않았습니다.
- 준비 완료는 사건 종결·승소·법적 판단의 확정이 아닙니다.
- 실제 작업과 예측은 같은 스케줄러를 사용하지만 예측은 상태의 사본에서만 실행합니다.
- 과다 배정은 허용하고 실제 수행만 사람별 가용시간으로 제한합니다.
- 재판 시스템·재판 결과·명성·채용·장기 성장·최종 상용 품질은 이번 실험 범위에 포함하지 않습니다.
- 원본 UI 첨부와 기존 저장소의 코드·브랜치·재판 코어는 변경하지 않았습니다.
