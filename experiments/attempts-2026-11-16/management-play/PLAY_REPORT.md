# THE FIRM 0.4 — 약속과 병목

2026-10-27 · Lane: experiment. 플레이 가능한 웹 실험이며 재미·출시 품질을 입증한 완성 게임은 아니다.

## 게임으로 표현한 선택

핵심 질문은 **누구의 시간을 어디에 쓰면 어떤 약속을 지키고 무엇을 포기하는가**다. 개발자 자료에서 반복 조작을 줄이는 최적화(Factorio), 문제를 본 뒤 고르는 작은 선택지(Against the Storm), 공개 정보로 대응을 설계하는 방식(Into the Breach)을 확인했다. THE FIRM에 대한 적용은 자체 설계 판단이다. 원문·조회일은 `docs/management-research.md`에 있다.

| 재미 가설 | 이번 실행본에 반영한 것 |
|---|---|
| 막힌 이유를 알아내기 | 오늘의 병목 최대 2개와 담당 조정 바로가기 |
| 선택으로 결과 바꾸기 | 인계 전후 지연 업무·준비 완료·현금과 미수의 변화 요약 |
| 약속과 비용 사이의 긴장 | 신규 준비 보고의 계약기한 미완료 시 착수금 50% 환급 실험 |
| 계획이 실제로 이어지는 만족 | 일일 보고의 실제 완료·해제된 후속 업무·환급 표시 |
| 다음 판에서 개선하기 | 세 목표와 분리 결산, 원본/실험 및 시작 현금 선택 후 재도전 |

원본 보수·업무비·작업시간·가용시간과 무료 인계는 유지했다. 새 규칙은 윤지훈의 준비 계약에만 적용하며 과거 고은아 미수금은 취소하지 않는다. 준비 완료는 사건 종결·승소가 아니다. 현금 부족 시 강제로 진행을 막지 않는다.

## 직접 실행한 결과

같은 시작 현금 1,820만원, 같은 사건·인력·5업무일이다.

| 전략 | 원본 마감 현금 | 환급50% 실험 현금 | 확정 미수 | 준비 완료 | 기한 위반 | 실험 환급 |
|---|---:|---:|---:|---:|---:|---:|
| 저비용 직원 집중 | 23,500,000원 | 22,300,000원 | 0원 | 1/3 | 6개 | 1,200,000원 |
| 고정 분산 | 23,236,000원 | 23,236,000원 | 0원 | 3/3 | 3개 | 0원 |
| 절약형 기한 준수 인계 | 21,968,000원 | 21,968,000원 | 1,200,000원 | 3/3 | 0개 | 0원 |

이 비교에서는 일을 덜 끝내는 집중 전략의 현금 우위가 사라졌다. 그러나 모두의 가용시간을 1시간 줄인 스트레스 조건에서는 비교한 경로 모두 준비 미완료이고 같은 환급을 부담해 집중이 현금상 다시 유리했다. **환급 하나로 모든 경제적 유인이 해결된 것은 아니다.** 기존 사건 지연의 경제적 후속 효과도 새로 넣지 않았다.

### 풀 수 있는 현금 도전

시작 현금 20만원은 정상 첫날 비용을 감당할 수 없어 스트레스 검증에만 남겼다. 플레이용 **빠듯한 현금**은 60만원이다.

절약형 인계는 60만원에서 **일말 최저 현금 26,000원, 적자 0일, 준비 3/3건, 기한 위반 0개, 환급 0원**을 달성했다. 마지막 현금 4,368,000원에 확정 미수 1,200,000원이 별도로 남는다. 기존 인계보다 88,000원을 덜 쓴다.

차이는 윤지훈 자료 취합을 사무직원에게 맡기는 데서 나온다. 당장 가능한 모든 일을 비싼 인력으로 시작하는 대신, 후속 업무를 시작할 시점까지 자료 취합을 끝내도록 배치한다. 기존 규칙에서도 가능한 새 발견 경로이며 전역 최적해가 아니다. 전체 trace와 결과는 `docs/play-experiments.json`, 비교표는 같은 이름의 CSV·MD에 있다.

## 검증과 실행

- 기존 엔진·감사·렌더러30개 + 새 엔진11개 + 새 렌더러5개: **46/46 통과**.
- Chromium 기존 흐름 **20/20**, 새 흐름 **11/11 통과**. 계약 공개, 미리보기 취소, 실제5일 환급, JSON 내보내기·가져오기·재시작·새로고침, 변조 환급 거부, 원본 저장 복원, 60만원 선택·20만원 별도 스트레스, A/B/C 상태 유지와 390px 화면을 확인했다.
- 원본70조건+70회 재실행: **12,699개 검증, 실패0**. 기존 감사의 결과·명령·보고·최종 상태 해시가 전부 같다.
- 새8전략×8조건=**64회+64회 재실행,14,035개 검증,실패0**. 환급0·25·50·100%, 기본/60만원/20만원 현금, 가용시간 감소를 분리 비교했다.
- 새 절약형 인계도 보존한 이전 엔진에서 같은 결과가 나온다. 게임 계산에 난수·현재 시각을 사용하지 않아 seed는 없다.
- 브라우저 실행 오류·외부 네트워크 요청·검증 중 HTML 변화0. 1366px 주요 화면과390px 인계·재시작을 직접 시각 검토했다. 인간 플레이 테스트와 다르다.
- 독립 검토 **PASS**: `docs/PLAY_REVIEW.md`. 정확한 명령·해시·종료 코드는 `test-results.log`에 있다.

프로젝트 폴더에서:

```sh
python tools/build.py
node tools/play-verify.cjs
node tools/play-verify.cjs --browser
```

첫 두 명령은 Python·Node 표준 라이브러리만 필요하다. 브라우저 검증은 Playwright와 Chromium이 필요하다. `FIRM_CHROMIUM`에 실행 파일을, 필요하면 `CODEX_PRIMARY_RUNTIME_NODE_MODULES`에 Playwright가 설치된 node_modules 폴더를 지정한다. `FIRM_QA_DIR`은 기존 브라우저 검증의 임시 출력 폴더를 지정한다.

`node tools/play-experiments.cjs`로 새 CSV·JSON·설명·로그를 재생성한다. 기존 감사 실행기도 보존했다.

## 사람에게 확인할 질문 — 세 가지

1. 첫날 위험을 하나 찾고, 수임이나 인계가 무엇을 바꿀지 설명할 수 있는가?
2. 결산에서 현금과 미수, 준비 완료와 기한 준수를 구분하고 다음 판에 바꿀 행동을 떠올리는가?
3. 인계가 상황을 해결하는 선택처럼 느껴지는가, 알고 있는 답을 반복 클릭하는 일처럼 느껴지는가?

이 답을 얻기 전에는 전문 능력·채용·평판·대출·무작위 사건을 추가하지 않는 것을 권한다. 현재는 고정 사건3건의 짧은 퍼즐이므로 장기 경영의 성장감과 반복 플레이 깊이는 검증하지 못했다. Godot는 읽기 전용 대표 화면 그대로이며 새0.4 저장 호환을 검증하지 않았다.

## 작업 보존

기존 감사 완료 ZIP을 기준으로 독립 실험을 수정했다. 기존 Git 미커밋 변경은 읽기만 했고 커밋·push·배포하지 않았다. 변경 범위는 `docs/play-source-diff.patch`, `docs/play-provenance.json`에 기록한다. 내부 QA 스크린샷은 배포 패키지에서 제외한다.
