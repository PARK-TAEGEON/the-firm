- RNG·현재 시각에 의존하지 않으므로 seed는 없음. 초기 조건 해시·명령 trace·엔진 SHA-256은 JSON에 기록했다.
- 독립 검토 **PASS**. 게임 재미·시각적 선호의 승인과 구분한다.

프로젝트 폴더에서:

```sh
python tools/build.py
node tools/audit-verify.cjs
node tools/audit-verify.cjs --browser
```

첫 두 명령은 Python 표준 라이브러리와 Node만 필요하다. `--browser`는 기존 `tests/ui-smoke.cjs`와 같은 Playwright/Chromium 의존성이 필요하다. `FIRM_CHROMIUM`에 브라우저 실행 파일, 필요하면 `CODEX_PRIMARY_RUNTIME_NODE_MODULES`에 Playwright가 설치된 node_modules를 지정한다. Windows에서 `python`이 없는 경우 설치된 Python의 절대 경로를 사용한다.

수정 전 실패를 재현하는 명령(실패 exit 1이 기대 결과):

```sh
node tests/audit-regressions.cjs --baseline
node tests/audit-ui.test.cjs --baseline
```

`test-results.log`는 최종 실행 명령·종료 코드·해시를 포함한다. 전체 규칙/민감도는 `docs/audit-strategies.md`, 결과는 `docs/audit-strategies.csv`, 상세 기록은 같은 이름의 JSON, 개별 엔진 재현은 `docs/ENGINE_AUDIT.md`, 검토는 `docs/INDEPENDENT_REVIEW.md`에 있다. 별도 모형을 만들지 않고 실제 엔진을 호출했다.
