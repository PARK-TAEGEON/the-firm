# v0.5 UI budget / text audit

## 동일 장면 측정

1440×1080, Theory A, 거리·관찰 시간·최초 진술 확보 및 세 전제 선택, Press/Frame 이전. 상세 접힘. 공백을 제외하고 실제 표시되는 text node 문자 수를 계산하며 닫힌 details/dialog, script, sr-only를 제외한다. 뷰포트 아래에 있는 펼쳐진 내용도 포함한다. 브라우저/글꼴에 따라 결과가 달라질 수 있다.

| 항목 | 실제 v0.4 배포본 | v0.5 |
|---|---:|---:|
| 표시 문자 | 1,004 | 183 |
| 문서 높이 | 1,080px | 1,080px |
| 행동 영역 높이 | 624px | 283px |
| Argument Lane 하단 | 863px | 958px |

상시 정보가 증가하지 않고 이 표본에서는 821자, 약 81.8% 감소했다. 남는 세로 공간을 증언에 배분하여 Lane은 95px 아래로 이동했지만 행동 버튼까지 첫 화면에 남는다. 모든 플레이 상황에서 같은 감소율이라고 주장하지 않는다. 절차 사건이 누적되면 기록 목록은 길어질 수 있고, 필터와 접기로 관리한다.

명시적 예산: 새 상시 절차 패널 0개, 이의 행동 최대 4개, 설명 요청 최대 3개, 사건 종료 후 절차 행동 0개, 장식 체크/상태 배지 0개, 동시에 열린 dialog 최대 1개. 이 장면에서 문자 수 1,004 이하, 문서 높이 1,080px 이하, Lane/행동 버튼 viewport 안. 브라우저 테스트로 해당 구조를 검사했다.

## 새 문구 감사

| 문구 또는 범주 | 처리와 이유 |
|---|---|
| 질문 유지 / 근거 제시 / 좁혀 묻기 / 철회 | 이의 순간에만 필요한 선택. 긴 행동 설명 삭제. |
| 기록 연결 | 재판장이 설명을 요청할 때만 표시. 현재 Inference의 문장을 함께 보여줌. |
| 질문과 근거 | 원 질문과 실제 연결 자료는 기본 접힘. 연결 대상 확인 용도. |
| 논증 상세 | Inference 본문·강도·핵심/보조 쟁점은 펼쳐서 확인. 기본은 제목만. |
| 전체 / 증언 / 논증 / 절차 | 하나의 Court Record 필터. 세 상시 패널 없음. |
| 검사 이의 세 문장 | 실제 개입 이유라 유지. 별도 ‘이의 발생’ 상태 설명 없음. |
| 판사 설명 요청·허용·차단·제한 문장 | 다음 행동과 범위를 바꾸는 대사라 유지. 내부 reason/profile 숫자는 숨김. |
| 재판장 설명 요청 / 질문 범위 제한 / 질문 철회 | 과거 절차의 짧은 기록 제목. 본문은 접힘. |
| 친분과 당시 식별의 확신은 구분됨 | 반대 기록의 의미 제한을 설명하는 상세 한 문장. 성공 배지 없음. |
| 최초 진술과 대조 / 필요한 기록 | 실제로 대응 가능한 반대 증언의 상세에서만 노출. 완료 후 행동 삭제. |
| 기록 없음 | 빈 목록일 때만. |
| 근거·질문·판결정 연결 오류 문구 | 서비스 명령 실패 시에만 알림. 정상 화면에는 없음. |
| 원 결론 대신 관찰 조건만 확인 / 현재 질문에 연결된 기록 제시 | 버튼 title. 모든 버튼 밑에 반복 설명하지 않음. |

## 제거·축약한 기존 문구

- 사실 버튼 아래 질문 의도와 완료 체크 제거. 실제 질문은 title·대화에서 확인.
- 인정/버팀/설명 배지 제거. 증인의 실제 답변 유지.
- 상시 전략 평가, Major Commitment 0건, Frame 확인 문장 제거.
- 위험 예고·근거 보강 안내와 항상 펼친 Inference 강도 제거.
- Stop/Frame/Press의 긴 설명을 ‘신문 종료 / 논증 기록 / 압박’으로 축약.
- 세 기록 영역 제목·개수 대신 한 목록과 필터 사용.
- 증거 dialog의 중복 제목·상시 교육성 주의 문장 제거.
- 판사·증인 상태 패널과 숫자 집계 결과 대신 실제 대사·접힌 기록 검토 사용.

전체 scene의 aria-live를 제거했다. 작은 별도 live region이 최신 이의·판사 결정·답변 최대 두 개만 알린다. 과거 대화와 고정 UI, 전제 선택은 읽어주지 않는다. 선택 시 DOM·키보드 초점·스크롤·펼침 상태, 서비스 갱신 후 기록 펼침을 검사했다.

새 플레이어가 대사와 짧은 행동으로 이해하도록 구성했지만, 실제 초심자 사용자 테스트는 하지 않았다. 자동 브라우저 검증과 화면 검토를 학습성 입증으로 취급하지 않는다.
