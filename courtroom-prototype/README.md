# THE FIRM — Courtroom Core v0.6

같은 창고 사건에서 목격자 서지훈과 감식 담당 수사관 한서윤을 신문한다. 새 논점은 **지문 접촉과 범행 당시 사용의 구분**이다. 기존 exact-premise Inference, Press/Frame, 반대 기록, 절차 engine을 재사용한다.

## 실행

`index.html`을 브라우저로 열면 설치·인터넷 없이 실행된다. 또는 이 폴더에서 `node serve.js` 실행 후 `http://127.0.0.1:4173/?v=0.6`을 연다.

## 플레이 흐름

1. 전략과 증인을 선택하고, 관찰 조건·진술 변화 또는 감식 한계·접촉 경위 중 질문 방향을 고른다.
2. 의도를 선택하면 실제 질문과 답변이 나온다. 조명에서는 광원까지 더 묻거나 다른 논점으로 이동할 수 있다.
3. ‘기록을 연결한다’에서 법정 기록을 선택한다. 평소의 기록이 논점 재료로 바뀐다. ‘이 논점을 남긴다’와 ‘확답을 요구한다’는 다른 결과를 남긴다.
4. 감식 시점+공용 비품으로 확답을 요구하면 근거 선택을 시험할 수 있다. 후보 중 1~2개를 질문에 붙인다. 모든 후보를 고르는 방식이 아니다.
5. ‘이 논점은 여기까지’는 현재 방향만 접고, ‘신문을 마친다’는 해당 증인 신문을 닫는다. 기록은 증인 이동 후에도 보존된다.

한서윤의 최초 주신문은 피고인 지문과 피해자 혈액 검출을 기록한다. 뒤의 논증은 그 검출을 지우지 않는다. 종합 유무죄 판결은 구현하지 않았다.

## 설계 기준

저장소 root의 `DESIGN.md`가 웹 실험의 공통 기준이다. root `AGENTS.md`가 다음 작업 전에 읽도록 지정한다. 별도 Godot Accepted design을 대체하지 않는다. 앞으로 요청은 `DESIGN.md 기준으로 v0.7 구현. 변경점은 …`처럼 줄일 수 있다. 이 배포 ZIP에는 같은 문서의 사본이 포함된다.

## 검증

```text
npm test
npm run test:browser
npm run test:budget
```

앱에는 외부 패키지가 없다. 테스트는 Node, 브라우저 테스트는 Playwright와 Edge가 필요하다. 기본 회귀 100개를 유지하고 새 감식/흐름 32개를 추가했다. 브라우저 92+47, UI budget 14, 기존 Godot 회귀 2,280 및 시작 검사를 별도로 실행했다.

- `REVIEW_PACKET.md`: 변경 범위, 불변 조건, 실제 결과, 요청된 10개 질문의 답.
- `UI_TEXT_AUDIT.md`: 데스크톱/모바일 전후 수치와 문구 감사.
- `EXPERIMENT_RULES.md`: 실제 코드에 대응하는 사건 전용 규칙과 한계.

질문·답변·판사 판단은 작성된 데이터다. 범용 법률 추론, 과학적 자동 감정, 판사 AI, 실제 판결, 저장, 다음 VS는 구현하지 않았다.
