# THE FIRM — Courtroom Core v0.2

별도 실험용 웹 프로토타입. 원본 HTML의 3열 구성과 색상을 유지하고, 질문 목록을 **사실 확보 → 근거 선택 → Stop / Press / Frame** 루프로 바꿨다. 정식 Godot 설계에 통합하지 않았다.

## 실행

`index.html`을 브라우저로 열면 된다. 설치나 서버, 네트워크 연결이 필요 없다. ZIP 배포본은 먼저 전체 압축을 푼다.

선택적으로 이 폴더에서 `node serve.js`를 실행하고 `http://127.0.0.1:4173`을 연다.

## 플레이

1. 전략을 선택한다. A는 식별 공격이 핵심이고 B는 고의 다툼이 핵심이라 식별 논증이 보조 전략으로 표시된다.
2. 거리·조명·관찰 시간·최초 진술을 원하는 순서대로 확인한다. 최초 진술 질문은 진술서를 함께 제시한다.
3. 기록된 전제 2–4개를 선택한다. 미확보 사실은 선택할 수 없다.
4. 기록만 남기고 끝내거나, 증인에게 결론을 압박하거나, 공개 논증으로 보존한다. 논증을 남긴 뒤에도 사실을 더 확보할 수 있다.
5. 종료하면 Evidence Record에서 시연 판정을 계산한다. Advocacy Record를 증거처럼 가산하지 않는다.

### 반응 비교

- 거리 + 관찰 시간 → 압박: 버팀.
- 거리 + 조명 → 압박: 간판 불빛 설명과 반대 명제.
- 최초 진술 + 거리 + 관찰 시간 → 압박: 식별 한계 인정.
- 반복 압박: 근무 관계 설명. 이미 기록된 사실은 중복 생성되지 않는다.
- 아무것도 묻지 않고 종료: 자료 부족. 유죄나 상대 주장의 자동 인정이 아니다.

모든 규칙은 `EXPERIMENT_RULES.md`에 명시된 사건 전용 시연 규칙이다. 화면의 결과는 식별 쟁점에 한정되며 실제 유무죄 판결이나 법률 추론 엔진이 아니다.

## 구조

| 파일 | 책임 |
| --- | --- |
| `data/case.js` | 사건, 프로필, 명제, 질문, 별도 답변, 논증 계획, 조건별 반응과 시연 판정 |
| `engine/core.js` | 순수 콘텐츠 검증, 가용성, 논증 검증, 반응/판정 해석 |
| `services/courtroom.js` | 유일한 상태 변경 경로, 원자적 명령, ID, 기록/공개 입장 |
| `ui/app.js` | 서비스 projection 표시, 플레이어 명령 전달 |
| `ui/original.css`, `ui/courtroom.css` | 원본 스타일과 반응형 화면 확장 |
| `reference/original.html` | 제공받은 원본 참고본 |
| `tests/` | headless 회귀, 브라우저 플레이 경로 |

일반 조건문은 사건의 질문 ID를 검사하지 않는다. 콘텐츠를 바꿔 다른 프로필을 실행하는 민사 smoke는 테스트에서만 제공한다. 현 UI는 단일 증인·첫 번째 논증 계획에 한정한다.

## 검증

`node --test tests/core.test.js`

브라우저 테스트는 테스트 환경의 Playwright 및 Microsoft Edge가 필요하다: `node tests/browser.test.js`. 앱 자체에는 외부 의존성이 없다. 이번 실행 환경에서는 번들 Node 패키지 경로를 `NODE_PATH`에 지정했다.

실행 결과는 `test-results.log`, 범위와 제한은 `REVIEW_PACKET.md`를 참조한다. 테스트 캡처와 기존 Godot 실행 로그는 로컬 `tests/artifacts/`에 보존하며 Git에 포함하지 않는다.

## 확장 지점과 남은 작업

- 이의·배제: `records.procedural`에 서비스 명령을 추가할 수 있으나 증거능력과 기록 효력 규칙부터 설계해야 한다.
- 판사 개입: 프로필의 행동/단계와 별도 서비스의 사건 규칙을 통해 연결한다. 현재 관찰 문구는 AI가 아니다.
- 민사: 프로필의 역할/단계/해결 타입 및 사건 데이터. 실제 민사 입증 기준은 별도 작성해야 한다.
- 정식 통합 전 과제: 사건별 규칙 검토, 진짜 판결에 필요한 다른 쟁점, 다중 논증 계획 선택, 접근성 개선 및 저장 설계.
- EVADE/CONTRADICT, Negotiated Resolution은 예약 타입이며 실행 기능이 없다. 전략 충돌은 알림만 있고 페널티는 없다.
