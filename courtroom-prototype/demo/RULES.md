이 문서의 수치·조건·문구는 DEMO-001 플레이테스트용으로 에이전트가 정한 값이다. 실제 법적 입증 기준이나 양형기준이 아니다. 진입점은 `courtroom-prototype/demo.html`. v0.10 `trial.html`·`engine/trial.js`·`services/trial.js`는 수정하지 않았다.

## 1. 구조

- `data/demo-separated-moments.js` → 기존 `engine/trial.js`·`services/trial.js`(공판) → `services/demo-session.js`(사건·검사 선택, 합의, 공판 위임) → `services/demo-outcome.js`(주문·양형·복기, 순수 함수) → `ui/trial-demo-app.js`.
- 한국 규칙 값(죄명, 조문, 반의사불벌 여부, 처벌불원 마감, 양형 표)은 `data/demo-ko-pack.js`에만 있다(DEC-032). 서비스 코드에는 사건 ID·검사 버전·한국 규칙 문자열이 없다(테스트로 검사).
- 판정 모델은 v0.10 더하기 방식 그대로: 쟁점 기준값 + 기록 effects 합산 → 밴드(5 이상 입증됨 / 3–4 다툼 있음 / 2 이하 의심). DEMO-DESIGN §1.4의 “갱신” 방식은 쓰지 않았다.
- 결과 판정은 `services/demo-outcome.js`에 둔다. 엔진이 수정 금지이고 Owns가 `services/demo-*`이기 때문이다. 상태를 바꾸지 않는다.

## 2. 사건 “두 장면 사이” (죄명 상해)

- 쟁점: `ISSUE_SIG_ACT` 밀침(목격자), `ISSUE_SIG_CAUSE` 상해와의 연결(조사관). 기준값 둘 다 5. 재판장 신뢰 3, 1 이하에서 반대신문 시간 −1(v0.10 그대로).
- 준비 예산 반나절 4. 조사 5종 각 1(최초 진술, 연속 영상, 진료자료, 가림막 뒤 동선, 의뢰인 재면담) + 합의 상담 1.
- SIGNATURE에서 바꾼 점: 영상은 접촉 순간이 기둥에 가려 보이지 않는다(밀침 다툼이 성립하도록). 최초 진술에 “손이 닿는 순간은 가려져 못 봤다”는 기재를 추가. 가림막 뒤 동선은 검찰 증거목록이 아니라 변호인만 찾는 자료다. 숨은 진실은 SIGNATURE와 같다.
- 모두진술: 시간 배분(목격자/조사관) 2/2, 3/1, 1/3. 입장 “밀침 인정”은 목격자 주신문에 +3(밀침 다툼 없음), “접촉 부인”은 +1·신뢰 −1·모순 기록.
- 이의 창: 각 증인 유효 1·무효 1. 유효 창 통과 시 상해와의 연결 +1(두 창 모두 연결 쟁점에 작용), 인용 시 0. 무효 창 이의는 기각·신뢰 −1.
- 반대신문: 카드 접근 −1, 한정 결론(근거 2개 이상) 성공 −1·실패 +1, 과한 결론 +2·신뢰 −1. 자료 없는 질문은 delta 0(§1.10: 증인은 물러서지 않는다).
- 재반대: 조사관 재주신문 뒤 가림막 뒤 동선 카드 −1.

## 3. 신참 / 베테랑 검사 (데이터로만 차이)

| 항목 | 신참 | 베테랑 |
| --- | --- | --- |
| 재주신문 복구 | delta 0 (이미 나온 진술 반복) | delta +1 (본 것/판단 분리, “회복만으로 배제 불가”) |
| 증인 준비(카드 제시 후 인정 범위) | 최초 진술 제시 시 목격자가 새 한계를 인정 −1 | 주신문에서 한계를 먼저 밝혀 최초 진술 제시가 0 |
| 이의 | 하지 않음. 조사관은 “원인 판단은 내 역할 밖”이라 답해 근거 1개를 준다(delta 0) | 원인 의견 질문·근거 없는 추궁에 즉시 이의 인용 → 답 없이 질문 시간 1이 소진(=플레이어 신문 시간 −1), 근거 없음 |
| 영상 범위 | — | 조사관 주신문에서 영상의 범위를 먼저 밝힘(문구만, 효과 없음) |

사건·진실·쟁점·기준값·밴드·판정 규칙·조사·카드는 두 버전이 같다. 숨은 판정 보너스 없음(DEC-031 N4). 결과는 기록의 effects로만 정해지므로 같은 기록을 다른 검사 정의로 재평가해도 결과가 같다(테스트).

**해석 [사람 확인]:** “베테랑의 유효 이의는 플레이어 신문 시간 −1”을 “이의가 인용된 질문의 시간 1이 답 없이 소진된다”로 구현했다. 엔진 수정 없이 추가 차감을 만들 방법이 없었다.

결과적 경로 수치:
- 신참: 밀침 5−1−1−1 = 2 → 무죄 가능. 연결 5−1−1−1 = 2 → 표면 접근(영상·진료·한정 결론)만으로 의심 가능.
- 베테랑: 밀침 최소 4(의심 불가 → 베테랑 무죄 경로 없음). 연결은 동선 재반대 없이는 최소 3, 동선까지 5−1−1−1+1−1 = 2. 두 유효 이의 인용 + 연결 집중(시간 3) + 영상·진료·동선 필요.

## 4. 재판 전 합의 (§1.13, DEC-027·028)

- 상대는 피해자 측. 고정 제안: 150만 원, 합의서·처벌불원서, 단 합의서에 “폭행으로 상해를 입었다” 문구.
- 의뢰인 상담은 반나절 1, 준비 단계에서 한 번만. 변호인은 먼저 “합의해도 재판은 계속된다”를 설명한다.
- 조언 3종 → 의뢰인 결정(같은 조언 → 같은 반응): 제안 그대로 권함 → 의뢰인 거절(상해 인정 문구), 문구 삭제 조건 → 수락·처벌불원서 제출, 합의 말자 → 불성립. 재시도·설득 확률 없음.
- 수락 시 `settlement_agreed`, `victim_will_filed`(제출 시점의 공판 기록 수 포함) 세션 기록. 합의는 판결을 만들지 않으며 재판은 계속된다.

## 5. 결과 판정 (ko 팩)

1. 밀침 “의심” → 무죄.
2. 밀침 인정 + 연결 “의심” → 축소사실 폭행. 폭행은 반의사불벌이므로 처벌불원서가 마감(제1심 선고) 전에 제출돼 있으면 공소기각, 없으면 폭행 유죄.
3. 둘 다 인정(“다툼 있음” 포함) → 상해 유죄. 처벌불원은 양형 감경 사유일 뿐.

“다툼 있음”에서 유죄면 합리적 의심 기준을 설명하고, 해당 증인의 재주신문 복구가 있으면 인용한다.

## 8. 2026-10-07 복기·표시 수정 — 실험용 authored 규칙, DEC 아님

- 판정·합의·질문 시간·effects·points는 변경하지 않는다. P1-1 방법 a: 실제 통과 기록 중 유효하고 양수 효과를 남긴 이의를 `통과시킨 이의`에 출처 recordId와 함께 표시한다. 인용한 이의와 통과해도 효과 없는 질문은 제외한다.
- 놓친 준비는 유죄 근거 쟁점으로 제한한다. 무죄·공소기각은 비우고, 폭행 유죄는 밀침 쟁점만 남긴다. 같은 준비 카드는 구체 기록의 안내를 우선해 한 번만 표시한다. 준비했지만 쓰지 않은 카드는 별도 실제 선택으로 설명한다.
- 재면담 카드를 얻고 부인했다면 `missedUnlessCard`로 놓친 준비를 제외하고 `knownMemo`로 실제 모순을 설명한다. v0.10은 `when.hasCard`를 지원하지 않으므로 주신문 분기를 추가하지 않고 데모 복기에서 카드 기록을 확인한다. 기존 판정 효과와 기록 순서는 보존한다.
- ko 팩의 주문 문구와 증인 호출 문구를 표시 복사본 `displayRecords`에 적용한다. raw `records`는 재생·판정용으로 유지한다. 유죄 양형·법률 확인 상태는 기존 실험값 그대로다.
- 데모 용어는 모두진술(첫 변론), 담당 수사관, 의견을 묻는 신문으로 통일한다. 을/를은 표시 전용 조사 함수가 고른다. 시작 화면에 어려움 모드·신참 권장을 표시하고 일상 사건 요약 버튼은 보기/닫기로 토글한다. v0.10 화면 문구에는 적용하지 않는다.

## 9. 2026-10-07 첫인상·점진 공개 — 실험용 authored 표시 규칙, DEC 아님

- 표시명은 작업실 정산 다툼 상해 사건, 의뢰인은 정민호(38세). 기존 사건 ID·trial 정의·원본 기록은 그대로이며 별도 presentation 데이터만 추가한다. 두 장면 사이는 내부 제목으로만 보존하고 화면에서는 제거한다.
- 매 판 사건 선택 직후 사건 메모를 자동으로 한 번 연다. 사건 파일 열기로 시작하며 이후 상단에서 재열람한다. 메모에는 처음 아는 내용만 넣고 재면담·영상·현장 조사 결과를 미리 공개하지 않는다. 열람은 조사 시간을 쓰지 않는다.
- 내 준비 자료는 제목만, service가 현재 사용 가능하다고 제공한 접근법 카드·재반대 카드만 강조한다. 검찰 증거는 제목+한 줄 요약, 클릭하면 기존 데이터의 발췌문 전체를 보여준다. 미열람 증거의 내용은 공개하지 않는다.
- 재판장 메모는 현재 판세가 기본이며 모든 근거 기록은 펼쳐 읽는다. 법정은 최근 문답을 기본으로, 전체 기록은 접힌 공판 조서에 보존한다. 기록 자체의 줄·순서·효과를 삭제하거나 수정하지 않는다.
- 판결은 결과+핵심 세 항목(주문·복기 핵심·다음 시도), 판결 근거/양형과 세부 복기는 펼침으로 공개한다. 유죄에 통과시킨 유효 이의가 있으면 핵심 두 번째 항목에 우선 표시한다.
- 900px 이하에서는 자료/법정/메모 버튼으로 패널 하나를 고른다. 1440px에서는 세 패널을 유지한다. details 상태는 UI 메모리에서 진행 중 유지하고 새 판에서 초기화한다. 선택한 모바일 패널도 새 판에서는 법정으로 돌아간다.
- 팝업은 native dialog로 배경을 비활성화하고 키보드 포커스를 가둔다. Esc·바깥 클릭·닫기 버튼으로 닫으며 호출 버튼으로 포커스를 돌린다. 최초 브리핑만 사건 파일 열기로 진입한다.
- 일상 사건: 원룸 보증금 반환은 내용이 명확하여 유지, 공용 보관대 사건은 공용 보관대 물건 오인 반출 · 절도 혐의로 변경한다. 사건 내용과 자동 진행 여부는 그대로다.
