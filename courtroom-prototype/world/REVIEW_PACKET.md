# WORLD-001 리뷰 자료

Lane: experiment · Owner: Codex · Branch: `task/world-001`

## 목적과 결과

플레이어 없이 움직이는 법조 시장을 10년 진행하고 신문과 연간 통계로 검토한다. 사용자 후속 지시에 따라 미정 수치를 실험용 authored 규칙으로 문서화했다. Accepted DEC 변경은 없다.

시드 1 결과: 활동 인구 주별 70~74명, 연말 74명, 선두 6개 사무소, 기사 500개, 서비스 성과 12,360건. 은퇴자 14명을 포함한 누적 88명의 ID와 경력 기록을 보존한다. 기사 첫 읽기 링크 5개를 제공한다.

## 불변식과 검증

- 서비스만 공개 상태를 반영한다. 실패한 명령은 RNG/ID/기록/상태를 오염시키지 않는다. snapshot 외부 변경도 영향을 주지 않는다.
- 같은 시드·기간은 같은 상태/신문/JSON. 여러 명령으로 기간을 나누어도 같다. 다른 시드의 변동도 검증했다.
- 인물·로펌·사건·이벤트 ID를 재사용하지 않는다. 과거 이벤트는 append-only, 은퇴 인물은 보존한다.
- 휴직자는 사건을 수임하지 않는다. 복귀 주차는 기록한 예정 주와 일치한다. 은퇴/공직 퇴직은 휴직을 종료할 수 있다.
- 기록의 입력으로 사건 성과를 재계산하고 연간 실적/순위/인구를 재집계할 수 있다. 업무량 상한과 경험 연속성도 기록으로 확인한다.
- 전관은 유치 점수에만 영향을 준다. 사건 성과는 상세도·전관 여부·판사 프로필을 읽지 않는다. 결과는 법적 사실판정/판결이 아니다.
- 숫자 관찰은 결과 검사다. 선두를 강제로 바꾸거나 검증에 맞는 seed를 선택하지 않는다.

## 실행 명령과 결과

`courtroom-prototype/`에서:

```powershell
npm test
node --test world/world.test.js
node world/run.js --years 10 --seed 1
```

기존 Node 247 + 신규 World 20 = **267 checks / 0 failures / exit 0**. 신규 테스트는 최종 코드에서 실행했으며 CLI를 다른 작업 디렉터리에서 두 번 실행하여 결과 바이트까지 비교한다. 시드 0~19의 모든 10년 실행에서 주별 인구 60~90 범위와 복수 연간 선두를 확인했다. 기존 Node 회귀 이후 기존 코드 변경은 없다.

브라우저/UI 글자 수/Godot 테스트는 실행하지 않았다. 새 기능은 독립 headless 실험이고 기존 UI/엔진/서비스/데이터는 수정하지 않았다.

## Fixture/authored, 미구현과 판단 대기

- 시장 수요, 인물 성향, 나이/역량/경력, 이직 효용, 74명 봄 충원, 12개 로펌 상한, 압축 서비스 목표는 전부 합성 authored 모델이다. 실제 법조 통계나 GEN-001 사건을 주입하지 않는다.
- 초기 1월에 이동과 개업이 집중된다. 순위는 시장점유율이 아닌 중립 10건 보정을 쓴 달성률이다. 무실적 사무소도 50점으로 남는다. 사람이 이 단순화를 평가해야 한다.
- 사건은 같은 주에 종결되므로 계속 중 사건 인계/재판장 교체는 미구현이다. 공직자는 배치·퇴직·압축 업무량만 있고 판결/검사 AI는 없다.
- 상세도는 판단 규칙을 공유한다. 대규모 통계 집단/관찰 시 인물 생성, 실제 자격·승진, 관계/유착, 해고, 단축근무/정직, 경제 회계, UI, 게임 저장/불러오기, Godot/기존 법정/GEN 통합은 하지 않았다.
- 전체 사건 원장은 메모리에 남고 동일 seed로 재생성한다. stats에 모든 경력 이벤트와 사건 참조를 보존하지만 전체 사건 원장 export/import는 없다. 출력 2파일의 원자적 동시 교체는 제공하지 않는다.
- 사람의 재미 판정·병합·폐기·다음 단계 결정은 대기. 독립 Reviewer PASS는 experiment lane에서 요구하지 않으며, 자동 검증을 사람 PASS로 표기하지 않았다.

## 범위와 Git

- 변경은 `courtroom-prototype/world/` 12개 파일뿐이다. 루트/기존 REVIEW_PACKET, test-results, docs/CURRENT/CHANGELOG, DESIGN 및 계약서는 수정하지 않는다.
- 사용자 작업 공간의 미추적 generator와 patch를 건드리지 않고 별도 Orca worktree에서 작업했다. 다른 에이전트를 실행하지 않았다.
- staged diff의 소스/범위를 검토했고 `git diff --cached --check`가 exit 0이었다. 출력은 회귀의 기록 재계산 및 바이트 비교로 검증했다.
- 테스트 통과 후 한 개 목적 커밋. main 병합·push·다음 단계 작업은 하지 않는다.
