# WORLD-001 — 법조 세계 실험

화면 없이 74명으로 시작하는 가상의 법조 시장을 주 단위로 진행한다. 모든 임시 수치와 판단 규칙은 [RULES.md](RULES.md)에 **실험용 authored 규칙, DEC 아님**으로 기록했다.

## 실행

저장소의 `courtroom-prototype/`에서 Node.js 24로 검증했다. 외부 패키지는 필요 없다.

```powershell
node world/run.js --years 10 --seed 1
node --test world/world.test.js
npm test
```

- [법조 신문](out/news.md): 연간 표, 먼저 읽을 기사, 전체 기사 500개.
- [통계와 인물 기록](out/stats.json): 연간 직역별 인구·순위·휴직자 수, 은퇴자 포함 경력.
- [검증 결과](test-results.log), [리뷰 자료](REVIEW_PACKET.md).

CLI는 매번 자신의 `out/`에 결과 두 개를 덮어쓴다. 시드와 기간, 프로그램 버전이 같으면 바이트 단위로 재현된다. 출력에 실제 날짜를 넣지 않는다.

## 시드 1, 10년 관찰

- 활동 인구: 주별 70~74명, 모든 연말 74명. 실험 관찰 범위 60~90명 이내.
- 연간 선두: 6개 사무소. 최장 연속 1위는 김유진 법률사무소의 4년(3~6년차).
- 서비스 성과 기록 12,360건, 휴직 144회, 복귀 138회, 은퇴 14명. 종료 시 휴직 5명이며 휴직 중 은퇴한 사례가 1명 있다.
- 누적 인물 88명을 보존한다. 초기 로펌 5개에서 개업 후 12개가 됐다.
- 같은 시드 재실행과 20개 시드(0~19) 민감도 검증 통과.

사건 성과는 업무 목표의 압축 모델이며 판결을 뜻하지 않는다. 초기 한 달에 이직·개업이 몰리고, 새 로펌 12개 상한과 신입 충원 74명은 이번 실험의 인위적 수치다. 사람이 읽고 그럴듯함을 평가해야 한다.

## 사람 리뷰

1. 신문의 먼저 읽을 기사 5개와 연결된 인물의 앞뒤 기사를 읽었을 때, 기억에 남는 이야기가 있는가?
2. 공직 퇴직→영입, 개업→순위 진입, 휴직→복귀 흐름이 그럴듯한가?
3. 74명 보충 방식과 초기 이동 집중을 재미 검증에 쓸 수 있는가?

**자동 검증 완료, 사람 리뷰 대기.** 병합·폐기·다음 단계 방향은 사람이 결정한다. main에 병합하지 않는다.
