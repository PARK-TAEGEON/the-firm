# GEN-002 실험 규칙

**실험용 authored 규칙, DEC 아님.** 적용 범위는 `generator/`. GEN-001의 `content/RULES.md`를 아래 항목에서 확장한다. 판정 엔진과 서비스는 기존 v0.10을 사용한다.

## 콘텐츠와 진실

- CATALOG 8종을 `CAT_* → ARCH_*`로 대응한다. 기존 폭행·음주운전과 신규 원형은 별개다. 원형마다 쟁점 2개, 기본 조사 4개, 반전 후보 3개, 증인 2명이다.
- `catalog-data.json`은 카탈로그의 쟁점·변수 도메인·반전 조건·보수 범위를 보존한 실행 데이터다. `node generator/content/import-catalog.js`로 원문에서 다시 추출할 수 있다. 런타임은 Markdown을 읽지 않는다.
- `catalog-scenes.js`의 원형별 자료와 `catalog-dialogue.js`의 24개 수습·재반대 대사를 사용한다. 주신문은 관찰 사실을 유지하고, 자료 제시 후 한계를 인정한다. 자료 없는 추궁과 전면 철회 요구로 관찰 자체를 없애지 않는다.
- `catalog-facts.js`는 서로 모순될 수 있는 변수의 독립 추첨 대신 호환되는 사실 프로필을 만든다. 카탈로그의 변수 이름은 모두 보존하되 일부 사실은 고정하고 반전·관찰 조건에 따른 부분집합만 생성한다. 모든 후보값 조합을 구현한 것은 아니다. 예: 주거침입의 실제 장소는 세대 현관 안으로 고정하고 허락·철회·인식을 함께 바꾼다. 무고의 원사건은 승인된 물품 이동으로 고정한다.
- 관찰 상세도 2개와 반전 후보 3개의 시드 값은 생성 시점에 확정된다. 반전 활성 임계값은 0.6이며 조사로 진실을 바꾸지 않는다. 반전의 대상 쟁점은 아래 표로 고정한다. 법률 적용이나 양형 검토에 관한 부분은 메타데이터이며 자동 종결 효과가 아니다.
- 반전 후보 조사는 발생 여부와 무관하게 같은 순서·비용·제목·설명으로 제공한다. 조사 후 반전 자료 또는 추가 근거 없음이 나온다. 미발생 반전은 재주신문을 만들지 않는다. 기존 2종의 조사 목록은 GEN-001 동작을 보존한다.
- 신규 일상 요약은 승부 사건과 같은 진실·사실·초기 강도·착수금을 사용한다. 원형별 RNG 스트림과 기존 중앙 RNG를 유지한다.

| 원형 | 반전 1 / 2 / 3의 쟁점 |
|---|---|
| 절도 | A / B / B |
| 사기 | B / A / B |
| 업무상 횡령 | B / B / B |
| 명예훼손 | A / B / B |
| 교통사고 치상 | A / B / A |
| 주거침입 | A / B / B |
| 무고 | A / B / B |
| 공무집행방해 | B / A / B |

배송 실재를 작성자 식별에, 지출 분류를 보관자 지위에, 발언 맥락을 직무 권한에 가산하지 않는다. 교통 R3은 위치에 따른 주의의무 검토만 A에 반영하며 보험 특례의 자동 적용은 없다.

## 밸런스와 공개 정책

- 기존 authored 수치 모형 유지: 쟁점 A 초기 강도 3~4, B 3~5, 생성 잡음 1. 기본 자료 제시마다 -1, 두 독립 근거의 한정 결론 -1. 수습은 A +1 / B +2, 대응 재반대는 수습분만 상쇄한다. 반복 사용은 서비스가 거부하고 같은 출처의 재반대가 추가 순이익을 만들지 않는다.
- 신규 준비 예산은 7개 조사 비용의 60%를 반올림한 4, 조사당 비용 1. 균형 신문 시간 2/2, 집중은 3/1. 무준비·최선·상식·조사 선택 게이트는 모두 300시드로 측정한다. 시험 정책의 무작위 선택은 비교용이며 판결에 난수를 더하지 않는다.
- (c)는 무작위 준비·개회사·이의 정책을 유지한다. 공개된 카드로 질문하고, 공개 제목이 “최초 입장과 다른 사실”인 불필요한 입장 번복은 피한다. 재반대는 자료가 있으면 사용한다.
- 모든 limited press의 `hint`: **결론 요구는 이 증인에게 서로 다른 자료로 확인한 근거 2개 이상 필요**. 같은 문구를 briefing에 표시한다. 기존 서비스는 press hint를 직접 투영하지 않으므로 briefing이 현재 UI의 공개 경로다.
- (c)는 공개 hint와 질문 기록에 사용된 서로 다른 자료 수만 읽는다. 내부 `pressSucceeds`, `minPoints`, 반전 활성값, 판정 강도를 읽지 않는다. 내부 성공 조건을 바꿔도 행동 결정이 바뀌지 않는 부정 테스트를 둔다. (b)/(d)의 최선 경로는 기존 전지적 검사 정책으로 구분한다.
- (d)는 조사 우선순위만 바꾼 대조다. 집중 쟁점·개회사·신문 정책은 고정한다. 전수 최적화가 아니라 기존 쟁점 집중 전략 공간의 최선 경로다.

## 자동 진행과 전망

- `content.resolveCase(id, seed, {grade, investigations, targetIssue, skill})`에서 `grade`는 daily/contested. 같은 사건·조사·정책이면 등급과 관계없이 동일 기록·판결이다. 명시한 조사를 예산 범위에서 순서대로 수행하며 남는 예산을 임의 소비하지 않는다. 기본 조사 목록은 빈 배열이다.
- `novice`: 목표 쟁점의 기본 자료 신문. `experienced`: 이에 더해 공개 조건을 충족한 한정 결론과 준비한 재반대. 양쪽 모두 기록으로 다투는 개회사, 이의하지 않는 고정 정책이다. 능력에 따른 판정 가산은 없다.
- 전망은 조사된 카드에 연결된 반전만 포함한 관측 모델에 같은 정책을 실행해서 만든다. 그 뒤 실제 사건에 실행한다. 미조사 카드 본문·숨은 진실·활성 반전 목록은 전망 입력에서 제거한다.
- 초기 제출 증거의 강도와 일반 신문 규칙은 알려진 사건 모형으로 가정한다. 이는 범용 법률 전망 엔진이나 실제 승률 추정이 아니다. 초기 증거에 대한 담당자의 오판은 이번 실험에서 모델링하지 않았다. 전망 오차의 유일한 가변 원인은 미조사 반전이다.
- **유리**: 예정 정책에서 무죄. **다툼**: 유죄지만 기록에 shaken 쟁점이 남음. **불리**: 나머지 유죄. 다툼은 제3의 판결이나 무승부가 아니다. 이는 사용자가 요청한 방어 방향 3단계이며 §1.9의 예측 가능성 표현과 구분한다.
- 전망 일치율은 위 3단계와 실제 판결 후 동일 기준의 기록 밴드가 일치한 비율이다. `유리 → 유죄`를 역배로 센다. 일치율·빈도·수치는 개발자 REPORT에만 기록하고 `.player` 반환에는 넣지 않는다.
- 모든 불일치에는 실제 실행된 미조사 재주신문의 recordId·쟁점·빠뜨린 조사 설명이 있어야 한다. 같은 준비 상태에서 미조사 반전을 제거하면 전망과 실제가 일치한다. 결정·판결 단계에는 RNG가 없다. 추가 조사로 불리한 사실을 알면 전망이 나빠질 수도 있다.
- 예기치 않은 반전에서 수동으로 전환하는 중단점, 화면 연결, 세계의 주간 시간 소비는 구현하지 않는다. 명령줄/API로 완전 자동 진행을 검증한다.

## 한국 팩과 미구현

- `content/packs/ko.json`의 버전 `gen-002-1`을 사건에 기록한다. 신규 형사 성공보수 불허 값은 DEC-032에서 가져온 팩 데이터다. 실제 시장 보수나 법률 자문이 아닌 CATALOG의 실험용 고정 보수 범위를 사용한다.
- 반의사불벌·친고죄·친족상도례·보험 특례·형사공탁·양형 후보는 전부 `unverified`, **[확인 필요]**로 보존했다. 카탈로그의 링크는 검증 완료의 증거로 취급하지 않는다. 이번 작업에서 원문 대조를 완료하지 않았으며 사건별 법 적용을 실행하지 않는다.
- 합의·처벌불원·고소 취소·환불·반환·공탁으로 무죄나 자동 종결을 만들지 않는다. 합의금·양형·절차 종결·추가 죄명은 별도 설계/확인이 필요하다.
- 증거능력 판단, 자동 법률 추론, 전체 범죄 구성요건, 항소, 판사/상대 AI, World/Career/Business 통합, UI/save는 미구현이다. 카탈로그 원형의 두 쟁점은 공방 실험 범위이고 전체 법률 요건을 대체하지 않는다.
- 모든 원형에 공통 수치·신문 골격이 많고 인물 이름도 재사용하는 authored 콘텐츠다. 재미와 문장의 자연스러움은 사람 플레이테스트가 필요하다. 자동 테스트 통과를 사람 검토 통과로 간주하지 않는다.
