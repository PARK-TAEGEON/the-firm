# DEMO-001 준비 설계 — 두 장면 사이

작성: 2026-09-30 · 상태: **실험용 authored 설계 초안, DEC 아님. 구현 전 인계용.**

이번 작업의 유일한 산출물은 이 파일이다. 기존 코드·계약서·SIGNATURE·RULES·REPORT·테스트 로그·Review Packet을 변경하지 않는다. DEMO 구현 착수, GEN 병합, core 변경을 승인하는 문서가 아니다.

SIGNATURE의 “§1.10 원문 대조 대기”는 이번에 대조했다. 성실하지만 관찰과 추론을 혼동할 수 있다는 원칙과 맞는다. 다만 기존 수치의 반복 가산, 합의 서비스 부재, 양형 부재는 그대로 옮길 수 없는 인계 항목이다.

### 반드시 구분할 것

1. **접촉 인정과 상해 인과관계 인정은 다르다.** 피해자의 자세 회복·독립 낙상이라는 고정 진실을 검사 버전에 따라 바꾸지 않는다. 숨은 진실을 판결 입력으로 읽지 않는다.
2. **일부 인정은 변론 입장이다.** SIGNATURE의 `S_SIG_CONTACT`를 사용하며 법적 일부 유죄를 새로 만드는 기능이 아니다.
3. **합의는 이 사건의 자동 종결이 아니다.** 혐의는 폭행치상이다. 처벌불원만으로 공소기각을 표시하지 않는다. 데모를 합의 장면에서 끝내더라도 형사 절차는 남았다고 표시한다.
4. **무죄는 이 데모가 심리한 폭행치상 연결의 미입증 결과다.** 밀침 자체의 단순폭행 성립·축소사실 인정·공소장 변경 판단까지 구현된 것으로 표시하지 않는다. 실제 재판 전체를 “완전 무죄”로 표현할 수 있는지는 법률 검수 TBD다.

## 1. 신참 검사 / 베테랑 검사 행동 명세

### 1.1 공통 조건

사건·진실·초기 자료·플레이어 예산·법적 기준·판사·판정기는 동일하다. 첫 화면에는 “신참 검사” / “베테랑 검사 · 형사 20년”만 보여준다. 대응 카드 정답과 행동 목록은 미리 공개하지 않는다.

능력은 아래 대사와 실제 행동 기록으로만 드러난다. 검사 프로필 ID로 판결을 보정하거나 임계값·초기 증명 강도를 바꾸지 않는다. 같은 최종 기록과 같은 사건·팩 버전이면 이름표를 바꿔도 결과는 같다.

공통 준비는 SIGNATURE의 다섯 조사 중 네 개, 각 비용 1이다. `F_SIG_CAUSE`의 목격자/조사관 시간은 1/3을 유지한다. 재주신문 뒤 재반대 기회는 별도이며, 사용 가능한 카드가 있어도 자동으로 실행하지 않는다.

### 1.2 네 가지 차이

아래 효과는 **향후 데이터·서비스에 작성할 동작 명세**다. 현 엔진에 이미 존재한다는 뜻이 아니다. 새 동작의 ID는 `DEMO_SIG_` 접두어로 분리하고 이전 ID를 재사용하지 않는다.

| --- | --- | --- | --- |
| 미리 준비된 반박: 영상에서 낙상 순간이 안 보인다는 공격 | 검사: “사건 뒤 손목을 다친 사실은 분명합니다.” 조사관: “진단서에는 손목 타박상이 적혀 있습니다.” | 검사: “영상에 없는 장면과 없었던 일은 다릅니다. 확인되는 구간을 나눠 주십시오.” 조사관: “다시 서는 모습까지 보입니다. 가림막 뒤 원인은 이 영상만으로 정할 수 없습니다.” | 신참은 상처 자료를 반복할 뿐 새 기여 없음. 베테랑은 영상의 한계에 대한 반박을 미리 남긴다. 방어 측의 ‘영상 밖이므로 무관’ 확장을 막되 자세 회복 사실은 보존한다. 새 영상이나 감정을 만들어내지 않는다. |

| 이의 정확도: “영상에서 다시 서는 장면은 확인되지요?”라는 적정 질문 | 신참: “유도신문입니다.” 재판장: “반대신문에서 자료 내용을 확인하는 질문입니다. 계속하십시오.” | 베테랑은 이의 없이 진행한다. | 신참의 기각은 대사·절차 기록만 남긴다. 플레이어 시간 추가 차감·입증 이익 없음. ‘반대신문의 유도 질문이면 모두 위법’으로 가르치지 않는다. 구체 절차 근거는 §6의 확인 항목. |
| 재주신문 복구: 조사관에게 영상·진료 한계를 확인한 뒤 한정 결론을 얻음 | 검사: “그래도 상처는 있었지요?” 조사관: “네, 손목 타박상입니다.” | 검사: “상처의 존재, 영상에 보이는 회복, 화면 밖 낙상의 원인을 구분해 주십시오.” 조사관: “상처와 자세 회복은 확인됩니다. 회복했다는 사실만으로 뒤 낙상의 원인까지 배제할 수는 없습니다.” | 신참은 같은 진료 출처 반복이므로 복구 없음. 베테랑은 한정 결론에 빠진 ‘원인 배제 불가’를 보충해 영상 연결의 평가를 좁힌다. 앞선 인정은 삭제하지 않고 보충 기록을 연결한다. |

| 증인 버팀: 진술·영상 카드를 정확히 제시 | 목격자: “네. 직접 본 부분은 거기까지입니다.” | 목격자: “맞습니다. 그 범위는 인정합니다. 앞의 동작을 본 기억은 그대로입니다.” | 동일하게 카드가 확인한 한계를 인정한다. 준비된 증인이 명백한 자료를 무시하거나 동일 질문 반복 끝에 굴복하는 구조는 금지한다. |

목격자 재주신문은 두 버전 모두 밀침 관찰을 유지한다. 신참: “앞의 동작은 보셨지요?” / 베테랑: “낙상 원인에 관한 판단을 빼고, 직접 본 동작만 말씀해 주십시오.” 목격자: “피고인의 팔 움직임을 봤습니다.” `CARD_SIG_CONTACT` 재반대는 “그 접촉과 이후 낙상 원인을 나누어 묻겠습니다”이며 접촉 부인을 성공시키지 않는다.

### 1.3 베테랑을 돌파하는 실마리

실마리는 `INV_SIG_LAYOUT → CARD_SIG_LAYOUT`이다. 검찰이 놓친 가림막 뒤 운반대와 이동 흔적을 조사한다. 새 게임마다 생성하거나 상대 수준에 따라 숨기지 않는다.

베테랑 재주신문 후 플레이어가 카드를 사용한다.

> 변호인: “현장에는 운반대와 이동 흔적이 있습니다. 영상에서 자세를 회복한 뒤의 경위와 함께 검토했습니까?”
>
> 조사관: “당시 취합한 진단서와 사진만으로 그 경로까지 검토하지는 못했습니다. 다른 낙상 경로도 살펴야 합니다.”
>
> 검사: “운반대가 있었다는 것만으로 원인이 확정되지는 않습니다.”
>
> 변호인: “그렇습니다. 특정 원인을 단정하려는 것이 아니라, 앞의 밀침만으로 설명했는지 묻는 것입니다.”

효과: 원인 특정의 한계에 **독립 현장 출처**가 연결된다. 운반대가 실제 원인이라는 숨은 진실을 법정에서 자동 확정하지 않는다. 카드 소지만으로 효과가 생기지 않으며 영상·진료 한계가 먼저 기록돼 있어야 이 재반대를 선택할 수 있다. 신참 버전에서도 같은 자료와 질문을 사용할 수 있다.

### 1.4 판정 기여와 출처 처리 초안

SIGNATURE의 `5 → 2` 무죄 목표를 유지하되 수치를 그대로 누적하는 이관은 금지한다. 아래는 **구현 전 검증할 실험용 산정 예시**이며 실제 법적 입증 강도가 아니다. UI는 원인 설명 문장만 출력한다.

| 원인 쟁점의 기록 상태 | 출처별 기여 초안 |
| --- | --- |
| 초기 검찰 기록 | 기준 5. 반드시 최초 증언·진료 등 출처 내역으로 분해해야 한다. 출처 없는 5를 새 설계의 완성형으로 인정하지 않는다. |
| 진료자료 한계 확인 `A_SIG_CAUSE_MEDICAL` | 진료 출처의 기존 기여를 1 낮춘다. |
| 영상 구간 확인 `A_SIG_CAUSE_SEQUENCE` | 영상 출처의 기여 −1. |
| 위 두 기록을 연결한 `P_SIG_CAUSE_LIMITED` 성공 | 영상의 평가를 −2로 갱신한다. 앞의 −1과 합산하지 않는다. 진료는 여전히 −1. 결론 요구 버튼 자체에는 점수를 주지 않는다. |
| 베테랑의 실제 보충 답변 발생 | 해당 한정 결론에 연결해 영상 평가를 −1로 좁힌다. 진료 −1은 유지. 반복적인 “상처가 있다”는 수습만으로는 이 효과가 없다. |
| 영상·진료 확인 후 동선 카드 재반대 | 독립 현장 출처 −1. 영상이나 진료의 사본으로 취급하지 않는다. |

신참의 한정 결론 경로는 `5−1−2=2`, 베테랑의 표면 경로는 보충 뒤 `5−1−1=3`, 베테랑의 동선 재반대 경로는 `5−1−1−1=2`가 목표다. 숫자는 대사의 실질적 차이와 출처 연결을 검증하는 용도다. 베테랑 ID를 검사해 무조건 +1 하는 구현은 실패다.

목격 쟁점도 같은 사람의 최초 진술·반복 답변을 한 출처로 묶는다. ‘낙상 직접 관찰 없음’으로 ‘밀침 관찰 없음’을 만들지 않으므로 이 사건의 표면 목격 공격만으로 무죄 기준에 도달해서는 안 된다. 이의 인용·기각, 입장 변경, 질문 횟수는 독립 증거 기여가 아니다. 기존 credibility가 시간에 미치는 동작과 과욕 후 반박은 실제 절차·답변 기록으로만 남긴다.

이 출처 처리와 기존 v0.10의 가산형 effects가 맞는지는 core 병합 후 확인한다. 서비스/엔진 수정이 필요하면 DEMO 계약의 Owns·규칙 변경 내용을 먼저 보완해야 한다. 이번에는 해당 코드를 읽어 추측 구현하거나 수정하지 않는다.

## 2. 결과 네 종류 — 조건, 문구, 복기

### 2.1 표시 결정 순서

재판 전 합의를 마치고 데모를 종료하면 합의 결과를 표시한다. 법정에 들어간 경우 실제 verdict를 먼저 따른다. `not_guilty`이면 입장과 무관하게 무죄, `guilty`이면서 `S_SIG_CONTACT`이면 일부 인정, 나머지 `guilty`이면 유죄다. 일부 인정에도 실제 유죄와 양형 층을 함께 표시한다. 양형 미산정이면 “양형 미산정”이며 임의의 기본 벌금으로 채우지 않는다.

| 결과 ID·조건 | 화면 문구 | 기록에 연결할 복기 | 다음에 시도해 볼 것 |
| --- | --- | --- | --- |
| `RESULT_SIG_ACQUITTAL`: 원인 등 필수 쟁점의 미입증으로 `not_guilty` | **무죄 — 이 데모의 폭행치상 쟁점**. “밀침과 손목 상해 사이의 연결이 충분히 입증되지 않았습니다.” | “접촉 사실을 지우지 않고 영상과 진료자료가 설명하는 범위를 나누었습니다.” 베테랑 돌파 때만 “검찰은 화면 밖의 경위를 수습했지만, 운반대 동선이라는 별도 자료에 답하지 못했습니다.” 추가. | “다른 검사 버전에서도 같은 자료를 어디에 연결해야 하는지 비교해 보세요.” |
| `RESULT_SIG_CONVICTION`: `guilty`, 입장 `S_SIG_CONTACT` 아님 | **유죄 · {실형/집행유예/벌금/양형 미산정}**. “검찰의 상해 연결 주장을 뒤집을 기록이 충분히 남지 않았습니다.” | 미조사면 “영상·진료자료의 한계를 확인하지 못했습니다.” 조사 후 미사용이면 “자료는 확보했지만 법정에서 원인 쟁점에 연결하지 못했습니다.” 수습 후 중단이면 해당 재주신문을 인용한다. | “연속 영상에서 다시 선 장면을 확인하고 진료자료의 한계와 연결해 보세요.” |
| `RESULT_SIG_PARTIAL_ADMISSION`: `guilty` + `S_SIG_CONTACT` | **일부 사실 인정 · 유죄 · {양형 층}**. “밀침은 인정하고 상해의 연결은 다퉜습니다. 이번 기록으로는 그 연결을 충분히 좁히지 못했습니다.” | “인정한 접촉과 다툰 원인을 나누는 입장은 남았습니다. 입장 선택만으로 증거가 바뀌지는 않았습니다.” 실제 사용한 카드·미대응 수습을 덧붙인다. | “접촉 인정은 유지한 채 가림막 뒤의 다른 낙상 경로를 조사해 보세요.” |
| `RESULT_SIG_SETTLEMENT`: 아래 §3의 양측 동의·위임·이행·처벌불원서 확인 후 재판 전 데모 종료 선택 | **재판 전 합의 성립 · 처벌불원 확인**. “피해자와 합의했습니다. 폭행치상에 대한 형사재판은 남아 있습니다.” | “의뢰인은 비용과 남는 재판 위험을 설명받고 이 조건을 승인했습니다. 합의서와 처벌불원 의사는 양형 검토 자료이며 무죄 판결이 아닙니다.” | “합의를 보류했다면 어떤 기록으로 상해의 연결을 다툴지 확인해 보세요.” |

복기는 실제 발생한 기록만 인용한다. 안 한 재면담을 했다고 쓰거나, 사용하지 않은 카드 덕분에 이겼다고 설명하지 않는다. 숨은 진실을 사후 정답 해설로 전부 공개하지 않는다. “상대가 막은 것 / 내가 새로 연결한 것” 두 문장을 각 기록 열기와 연결한다.

### 2.2 유죄 아래의 양형 층

실형·집행유예·벌금은 세 번째 사실판정 점수가 아니다. 유죄 판단을 동결한 뒤 별도의 양형 자료와 `ko` 팩의 요건으로 정한다. 검사 수준, 이의 실수, 무죄 주장, 일부 인정 버튼을 형벌 가중·감경 조건으로 쓰지 않는다.

| 층 | 설계상 필요한 조건 | 결과·복기 문구 | 다음에 시도해 볼 것 |
| --- | --- | --- | --- |
| 실형 | 유죄 + 기록에 근거한 징역 선택 + 집행유예 요건 불충족 또는 유예하지 않는 사유가 명시됨 | “유죄 · 실형. {기록된 양형 사유}에 따라 형의 집행을 유예하지 않았습니다.” | “사실관계 준비와 함께 제출 가능한 피해 회복 자료도 확인해 보세요.” |
| 집행유예 | 유죄 + 선택 형이 팩의 유예 대상 + 결격 없음 확인 + 유예 사유 기록 | “유죄 · 징역 {기간}, 집행유예 {기간}. 유죄 판단은 유지되지만 형의 집행을 유예했습니다.” 복기에는 사용한 피해 회복·생활 자료를 구체적으로 표시. | “유무죄를 다툰 기록과 집행유예에 반영된 자료를 나누어 보세요.” |
| 벌금 | 유죄 + 해당 죄의 벌금형 허용 확인 + 벌금을 택할 사건별 양형 근거 | “유죄 · 벌금 {금액}. {기록된 양형 사유}를 고려해 벌금형을 정했습니다.” | “벌금 결과와 무죄 결과에서 달라진 증거 기록을 비교해 보세요.” |

**TBD — 이 사건의 양형 경로를 완성했다고 볼 수 없다.** SIGNATURE에는 전과·유예 결격·양형 조사 행동·금액·형기가 없다. 같은 손목 타박상 사건에서 준비 부족만으로 실형을 만드는 것은 채택하지 않는다. 실제 형량과 세 층 모두의 도달 가능성을 위해 필요한 고정 사건 자료·행동 비용은 법률 검수와 후속 계약에서 정한다. 그전에는 세 층의 조건부 injected fixture로 결과 표시를 검증하되, 이를 플레이 가능한 경로로 계산하지 않는다. 초기 사건 사실이나 전과를 경로마다 몰래 바꾸지 않는다.

## 3. 재판 전 합의 흐름

### 3.1 장면과 조건 초안

상대는 검사 아닌 피해자다. 게임용 고정 제안 `DEMO_SIG_OFFER_01`: “치료비 등을 포함해 150만 원을 지급하면 합의서와 처벌불원서를 작성하겠습니다.” 금액은 실험용 제안이며 적정 합의금의 실무 기준이 아니다. 기본 의뢰인의 가용 합의금은 150만 원으로 고정해 숨은 가격 맞히기를 없앤다. 합의는 상해 인과관계 전면 인정이나 법정 진술 변경을 조건으로 하지 않는다.

| 시점 | 장면·선택 | 명시적으로 남길 기록 |
| --- | --- | --- |
| 사건 선택 후, 조사 전 | 피해자 측 제안 도착. “검토하기 / 준비 후 다시 보기”. 단순 열람은 준비 예산을 쓰지 않는다. | 제안 원문·제안자·조건·유효 시점. 도착만으로 수락 처리하지 않는다. |
| 준비 중 또는 준비 종료 직전 | “의뢰인에게 설명하기”. 상담 1회는 반나절 1을 쓴다는 실험 초안. 카드 면담 `INV_SIG_CLIENT`와는 별개 행동이며 그 카드를 자동 지급하지 않는다. | 알고 있던 자료, 실제 전달한 설명, 상담 비용, 의뢰인 질문·답변. |
| 의뢰인 결정 후 | 한도·지급·서명·제출 범위의 위임 확인 → 피해자에게 수락 전달 → 이행 및 서류 확인. | 의뢰인 결정, 위임 범위, 실제 수락 전달, 지급 확인, 피해자 서명·처벌불원 의사, 접수 상태. |
| 재판 시작 직전 | 미완료라면 “합의 검토를 계속하면 이번 준비 시간이 필요합니다. 재판 준비를 마치고 진행할 수도 있습니다.” | 보류/거절/위임 없음과 그 이유. 준비 예산 소진을 동의로 바꾸지 않는다. |
| 합의 완료 | 위 §2의 합의 결과·복기로 데모 종료. | 데모 종료일 뿐 사건의 형사 절차 종결 이벤트나 verdict를 만들지 않는다. |

예산 4의 합의 경로 예: 의뢰인 재면담 1 → 합의 상담 1 → 명시적 위임 → 고정 제안 수락·이행·서류 확인 → 합의 결과. 상담을 하지 않고 곧장 재판을 택한 플레이어는 네 조사를 그대로 사용할 수 있다.

### 3.2 의뢰인 자율과 구체 반응

| 상황 | 의뢰인·변호인 대사 | 후속 효과 |
| --- | --- | --- |
| 합의하면 끝난다고 오해 | 의뢰인: “돈을 주면 재판도 없어지는 거죠?” 변호인: “이 혐의는 합의해도 재판이 남습니다. 처벌을 원하지 않는다는 의사는 양형에서 검토될 수 있습니다.” | 설명 전달·질문·추가 설명을 보존. 이 단계는 동의나 위임이 아니다. |
| 기본 수락 분기 | 의뢰인: “재판이 남는 건 알겠습니다. 피해 회복을 위해 그 조건으로 진행해 주세요. 150만 원 지급과 서류 제출을 맡기겠습니다.” | 이 조건에 한한 위임 기록. 실제 지급·서류 수령은 후속 서비스 동작으로 따로 확인한다. |
| 좋은 설명 뒤에도 거절 | 의뢰인: “비용도 위험도 이해했습니다. 그래도 그 상해를 제가 일으켰다는 인상은 남기고 싶지 않습니다. 이번 제안은 거절하겠습니다.” | 거절을 정상 상태로 기록하고 재판 준비로 복귀. 신뢰·판정 감점 없음. |
| 결정 유보 | 의뢰인: “가족과 상의한 뒤 답하겠습니다. 아직 수락하지 마세요.” | 위임 없음. 마감이 와도 자동 수락 금지. |
| 조건 변경 | 의뢰인: “금액은 가능하지만 상해 원인을 전부 인정하는 문구에는 동의하지 않습니다.” | 문안 재확인 전 실행 중단. 기존 위임을 확장하지 않는다. |

수락·거절·유보는 authored 대화 입력이다. 같은 상태·입력에서 같은 반응을 재현한다. 설명을 잘하면 반드시 수락하는 점수표, 설득 확률, 재시도 끝에 승낙시키는 루프는 없다. 기본 데모 수락 경로와 별도로 거절·유보를 주입해 자율성 회귀를 검증한다. 선택적 재설명은 실제 새 질문·자료에 답할 때만 허용한다.

### 3.3 선고 전 마감

- 데모의 **재판 전 합의 결과로 빠지는 창**은 재판 시작 전 닫힌다. 이는 제품 흐름상의 마감이다.
- 한국 팩의 **반의사불벌죄에서 처벌희망 철회가 공소기각으로 이어지는 마감**은 제1심 판결선고 전이다. 처벌불원 의사표시·제출의 적법성과 효력은 별도 확인 대상이다.
- 폭행치상 사건에는 위 마감 경과에 따른 공소기각 효과를 적용하지 않는다. 이 사건의 선고 전 알림은 “이번 심리의 양형 검토에 제출할 자료가 남아 있습니다”라는 의미다. 선고 뒤 합의의 모든 법적 의미가 사라진다고 안내하지 않는다.
- 법정에 들어간 경로에는 선고 확정 명령 전에 “선고 단계로 진행하면 이번 심리에 자료를 더 제출할 수 없습니다”를 보여준다. 합의 연장·기일 변경·법정 중 새 협상은 이번 데모 구현 범위로 확장하지 않는다. 필요하면 후속 계약 대상이다.
- 서명·지급·처벌불원서 미수령·미접수는 각각 미완료로 남긴다. 마감 직전 제안 버튼을 눌렀다는 사실만으로 적법한 제출 완료가 되지 않는다. 향후 마감 판단은 실제 기록 순서로 재현한다.

## 4. 자동 경로 테스트 인계 목록

다음은 **작성할 테스트의 계약**이다. 이번 문서 작업에서 테스트 코드를 추가하거나 아래 경로를 실행한 것은 아니다. 자동 실행은 실제 서비스 명령을 사용하며 결과를 UI 태그로 덮어쓰지 않는다.

### 4.1 법정 경로

공통: 사건 선택 → 검사 버전 선택 → 조사 → 개회사 → 두 증인 주신문/이의 → 반대신문 → 재주신문/재반대 → 선고 → 복기. 유효 이의 창은 적정 이의, 무효 창은 통과한다. 이는 입증 점수를 직접 얻기 위한 동작이 아니다.

| 경로 ID | 입력·행동 | 기대 결과 |
| --- | --- | --- |
| `DEMO_PATH_NOVICE_ACQUIT` | 신참. SEQUENCE/MEDICAL/CLIENT 조사, F_SIG_CAUSE + S_SIG_CONTACT. 목격 신문 종료. 조사관 MEDICAL → SEQUENCE → P_SIG_CAUSE_LIMITED. | 재주신문이 상처를 반복해도 한정 결론 유지, 무죄. CONTACT 입장 때문에 ‘일부 인정·유죄’로 덮이지 않음. |
| `DEMO_PATH_VETERAN_ACQUIT` | 베테랑. SEQUENCE/MEDICAL/LAYOUT/CLIENT 네 조사. 같은 개회사·조사관 세 질문 → 재주신문 → LAYOUT 재반대. | 무죄. 영상·진료·현장 세 출처와 베테랑 수습·재반대가 복기에 모두 연결됨. |
| `DEMO_PATH_VETERAN_SURFACE` | 위 경로에서 LAYOUT을 조사하지 않거나 조사만 하고 재반대 생략. | 무죄 불가. 원인 한계를 확인했어도 베테랑 보충 답변이 남음. |
| `DEMO_PATH_CONVICTION` | 양 버전 각각 조사 없음, F_SIG_BALANCED + S_SIG_RESERVE, 자료 없는 질문과 신문 종료. | 유죄. 양형 미산정이면 그대로 표시. |
| `DEMO_PATH_PARTIAL` | 양 버전 각각 CLIENT 조사, S_SIG_CONTACT, A_SIG_OBS_CONTACT 뒤 신문 종료, 원인 자료 미제시. | 일부 사실 인정 · 유죄. 개회사 인정만으로 유무죄·양형 수치가 움직이지 않음. |
| `DEMO_PATH_OVERREACH` | 양 버전 무죄 경로에서 한정 결론 대신 ‘상해와 전혀 무관’ 선택. | 유리한 인정은 보존되지만 그 결론은 얻지 못함. 베테랑은 이의·질문 제한 기록, 신참은 증인 반박 기록. |
| `DEMO_PATH_SAME_RECORD` | 동일 최종 기록의 검사 표시명·프로필만 교체해 재평가. | 유무죄·양형 동일. 다른 결과는 실패. |

**표면 접근의 정의:** LAYOUT의 독립 현장 자료를 법정 원인 쟁점에 연결하지 않은 모든 합법적 명령열. 영상·진료·진술 카드, 적정 이의, 한정 결론, 목격 공격, 입장 변경, 조기 종료, 반복 질문까지 포함한다. 베테랑 버전은 이 집합 전체에서 무죄가 없어야 한다. 대표 경로 한 번의 실패로 이 조건을 통과시키지 않는다.

후속 자동 탐색은 예산·신문 시간으로 제한되는 선택을 열거하고, 상태가 변하지 않는 반복은 동일 상태로 묶는다. ACT 쟁점 우회 무죄, 반복 카드·복사본 누적, 신문 건너뛰기, 재주신문 미실행 우회도 검사한다. 무죄가 발견되면 명령열·출처별 평가를 반례로 출력한다. 이를 막기 위해 ‘베테랑이면 무죄 금지’ 조건을 넣지 않는다.

## 7. 구현 전 인계와 이번 검증

### 결정·보완이 필요한 것

1. **판정 경계:** source-group 비중첩 처리, 초기 기여의 기록 분해, 검사 이의·답변 보충의 서비스 표현을 core 병합 후 확인한다. 변경이 필요하면 기존 DEMO 계약의 엔진 규칙·Owns를 보완한다.
