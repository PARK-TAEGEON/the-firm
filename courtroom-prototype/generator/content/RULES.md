이번 실행에서는 효과 수치를 변경하지 않았다. 현재 balance.js의 (b) 40~65%는 폭행 57.7%, DUI 56.7%로 충족한다. (c)는 반전 시드 비율, (d)는 재반대 횟수만 출력하며 목표·합격 조건이 없다. 새 슬롯도 없어 새 (b)(c)(d)에 대한 튜닝은 대기 중이다. 아래 기존 반전 수치(+1/-1, +2/-2)와 활성 기준 0.6, 기본 접근법 -1, limited 성공 -1/실패 +1을 유지한다. 임의의 목표를 정해 통과로 보고하지 않는다.

`SIGNATURE.md`의 수치는 생성 원형과 별개인 DEMO 상세 설계 초안이다. baseline 5/5, 준비 예산 4, 집중 신문 3/1, limited minPoints 2 및 성공 -1/실패 +1, overreach +2·credibility -1, 수습/재반대 +1/-1을 제안한다. 이의 유효 창은 인용 0/통과 +1, 무효 창은 기각 시 credibility -1/통과 0. 이는 기존 trial-case 형식으로 구현할 경로 설계이며 런타임에는 추가하지 않았다. 접촉 부인 뒤 인정 접근법은 점수 0·신뢰도 -1, 합의 분기는 법정 판결과 별도 기록이다. 세 사건의 사실과 효과는 모두 authored fixture다.

## 범위와 진입점

- `index.js`의 `buildContestedCase('ARCH_CRIMINAL_ASSAULT' | 'ARCH_DUI', seed)`가 콘텐츠를 채운 공판 정의를 반환한다. `generateDailyCase(id, seed)`는 일상 사건 문구를 채운다.
- 진실 추첨, 활성화 판정, 강도 계산, 상태 변경, 판결은 기존 core/engine/service를 사용한다. 콘텐츠 진입점은 반환된 정의에 문구와 작성된 접근법을 채운다. 실행 중 LLM·추가 RNG·현재 시각은 쓰지 않는다.
- core 직접 호출과 기존 웹 진입점은 자동으로 바뀌지 않는다. 소비자가 콘텐츠 진입점을 선택해야 한다. 이번 공판 정의 버전은 `0.0.3-gen-content`다. 기록 재생 시 해당 버전의 정의를 함께 보존해야 한다.
- 특정 실제 사건·인물·날짜·장소를 재현하지 않는다. 인물은 역할명으로 표시한다. 실제 판결 여러 건의 출처 검증은 수행하지 않았다. 실무 기준을 검증한 법률 모델로 취급하지 않는다.

## 폭행 원형

기존 원형의 쟁점·증거 수·보수·기간·강도 규칙을 유지한다. 말다툼 뒤 손목 상해가 발생한 사건으로, 목격 진술은 접촉 전 과정을 보여주지 못하고 영상에는 낙상 순간이 없다. 진단서는 상해 존재를 확인한다. 이는 모든 시드의 공통 사실이다.

- `eyewitness_reliability >= 0.6`: 얼굴·팔 움직임 관찰. 미만: 옆모습·옷차림에 의존. 양쪽 모두 접촉 부위·낙상 전 과정의 관찰은 아니다.
- `self_defense_evidence >= 0.6`: 팔의 긁힌 자국·후퇴 흔적이 사진에 있다. 미만: 사진만으로 방어 경위를 확인하기 어렵다. 어느 쪽도 정당방위 성립을 자동 확정하지 않는다.
- 반전용 진실 파라미터 4개를 각각 `[0, 1]`로 추가하고 `>= 0.6`일 때 해당 사실 묶음이 성립한다. 조건은 진실을 변경하는 명령이 아니다. `truthEffect`는 활성 조건에 해당하는 사실의 설명이다.
- 새 파라미터가 RNG 스트림을 소비하므로 core 예시 원형과 같은 시드라도 baseline은 달라질 수 있다. 콘텐츠 원형과 콘텐츠 버전을 고정하면 결과는 재현된다.

| --- | --- | --- | --- |
| TWIST_WITNESS_CONFLICT_OF_INTEREST | witness_interest | ISSUE_IDENTITY | +1 / -1 |
| TWIST_MEDIA_ATTENTION | media_contamination | ISSUE_IDENTITY | +1 / -1 |
| TWIST_LATE_DECISIVE_DOCUMENT | prior_injury_record | ISSUE_CAUSATION | +2 / -2 |
| TWIST_CLIENT_HIDES_CONTACT | hidden_contact | ISSUE_CAUSATION | +2 / -2 |

네 반전은 함께 발생할 수 있다. 이해관계는 허위 목격을 자동 의미하지 않고, 사후 정보는 최초 관찰을 지우지 않는다. 이전 통증은 새 타박상을 지우지 않는다. 밀침 인정은 낙상까지의 연결을 자동 확정하지 않는다. 의뢰인의 재면담 진술은 해당 카드 확보 뒤에만 표시한다. 반전별 조사 비용은 반나절 1회다. 양수 효과는 검찰, 음수 효과는 변호인에게 유리하다. 수습은 기존 `anyDefenseGain` 조건과 카드 기반 재반대 규칙을 따른다.

## 음주운전 원형

- `ISSUE_DRIVER`: 이동 중 운전자 특정. 증거는 정차 직후 관찰 기록·주차장 영상.
- `ISSUE_INTOXICATION`: 운전 당시 음주 상태와 측정 자료의 연결. 증거는 측정 기록·시각 대조표.
- `driver_observation`과 `measurement_connection`은 `[0, 1]`. 각각 direct `[3, 7]`, noise `1`을 사용한다.
- `driver_observation >= 0.6`: 정차 직전부터 운전석 쪽을 관찰. 미만: 얼굴은 정차 뒤 처음 식별. 어느 쪽도 이동 중 얼굴을 계속 식별하지 못했다.
- `measurement_connection >= 0.6`: 영상·장비 시계 대조 기록 확보. 미만: 시계 차이 확인 기록 없음. 어느 쪽도 측정은 정차 후다.
- 착수금 `[150, 350]`만원, 성공보수 `[0, 0]`, 기간 `[4, 12]`주. 실무 통계가 아닌 실험 수치다. `claim_amount: [0, 0]`은 청구·합의금 개념 미사용을 뜻한다.
- 아래 DUI 반전 3개를 `twists_allowed`에 등록했다. 폭행 반전은 DUI에 적용하지 않는다.
- 혈중알코올농도 기준, 역산 공식, 측정 위법·증거능력 판단, 사고·측정 거부, 실제 처벌 수준은 구현하지 않는다.

## 공방 수치와 한계

기존 템플릿의 증인당 신문 시간 2, 접근법 delta -1, 한정 결론 성공 -1/실패 +1, minPoints 1, 준비 예산은 변경하지 않았다. 원형당 증인 2명·기본 조사 4개다. 추가 조사 예산은 기존 core가 계산한다. 준비만으로 승소를 보장하는 규칙은 추가하지 않았다. 본문의 법리·증거 한계는 작성된 시나리오이며 범용 추론이 아니다.

## 긴장감과 카드 제시 — 이번 변경

- 주신문은 지목·타박상·운전석 발견·측정 결과 등 검찰 측 근거를 진술한다. 관찰의 공백·방어 흔적·시계 대조 미확보는 먼저 말하지 않는다. 숨은 진실 자체는 바꾸지 않는다.
- 각 기본 접근법에 대응하는 `A_..._UNSUPPORTED`를 추가했다. 카드 없이 실행할 수 있고, 증인은 구체적인 자료를 요구하거나 지목·측정 진술을 유지한다. delta `0`, points `[]`, 기존과 같이 신문 시간 1회를 쓴다.
- 카드 제시 접근법은 기존 ID와 `requiresAny`를 유지한다. 해당 카드가 없거나 다른 카드만 있으면 실행이 거부된다. 해당 카드를 제시한 질문에서만 한계 인정과 delta `-1`, 근거 점수 1개가 기록된다.
- 두 종류는 별도 선택지다. 카드를 보유해도 ‘자료 없이 추궁’을 고르면 증인은 버틴다. 카드 소지와 실제 제시를 구분한다. 카드 제시 접근법을 앞에 두어 기존 준비 후 플레이 정책을 유지한다.
- 자료 없이 추궁한 뒤 한정 결론을 요구해도 근거 점수가 없으므로 실패(+1)하며 증인은 한계를 인정하지 않는다. ‘자료 없이 추궁’만으로 `anyDefenseGain`이 켜지지 않는다.

## DUI 반전 3개 — 이번 추가

각 진실 파라미터는 `[0, 1]`, 활성 조건은 `>= 0.6`, 조사 비용은 반나절 1회다. 조사 카드·수습·재반대는 `twists.js`에 함께 정의돼 있다.

| 반전 ID | 진실 파라미터 | 대상 | 수습 / 재반대 delta |
| --- | --- | --- | --- |
| TWIST_DUI_MEASUREMENT_GAP | measurement_delay | ISSUE_INTOXICATION | +2 / -2 |
| TWIST_DUI_DRIVER_REVISION | driver_revision | ISSUE_DRIVER | +1 / -1 |
| TWIST_DUI_DEVICE_LOG | device_log_gap | ISSUE_INTOXICATION | +2 / -2 |

- 측정 전 대기: 접수표에 장비 도착 대기가 기록돼 있다. 대상자가 같다는 수습에 대해 운전 시점과의 연결 근거를 묻는다. 정확한 경과 시간·농도 역산을 만들어내지 않는다. 시계 대조 기록이 없어도 대기의 선후는 확인할 수 있다.
- 대리기사 진술 번복: 최초 통화의 ‘이후 이동 미관찰’과 추가 진술의 ‘피고인 출발 목격’이 충돌한다. 이전 대리운전 구간과 문제의 이동 구간은 구분한다. 카드만으로 다른 운전자를 확정하지 않는다.
- 장비 관리: 측정 기록과 점검표가 서로 다른 장비 번호다. 기록 연결의 오류를 지적하며, 실제 고장·측정값 오류·증거 배제를 자동 확정하지 않는다.
- 세 조건은 함께 성립할 수 있다. 기존 `measurement_connection`은 시계 대조 자료에 관한 값이므로 장비 관리 오류나 측정 대기와 모순되지 않는다. 추가 파라미터가 RNG를 소비하므로 이전 DUI 버전과 같은 시드의 baseline이 달라질 수 있다.

## 반전 효과 조정과 밸런스

사용자가 지정한 준비 후 무죄율 40~65%를 적용한다. 폭행 반전의 기존 `+1/-2`, `+2/-3`을 각각 `+1/-1`, `+2/-2`로 조정했다. 수습 수치는 그대로 두고 재반대의 추가 이득 1점을 제거했다. DUI 신규 반전도 수습을 상쇄하는 효과로 작성했다.

준비한 반전 카드는 검찰의 수습 효과를 상쇄한다. 카드가 없거나 제시하지 않으면 수습의 +1/+2가 남는다. 모든 반전을 준비했다는 이유만으로 반전 수만큼 추가 감점이 누적되는 구조를 없앴다. 기본 접근법·신문 시간·baseline·활성 임계값은 튜닝하지 않았다.

seed 1~300에서 폭행은 이전 231/300(77.0%) → 173/300(57.7%). DUI는 새 진실 파라미터와 반전을 포함해 170/300(56.7%). 두 원형 모두 준비 없이 무죄 0건이며, 카드 없이 추궁 후 한정 결론을 요구하는 별도 경로도 0건이다. 명령·세부 결과는 `REPORT.md` 참조. 이 표본·정책의 통과는 모든 시드·전략의 승률이나 재미를 보장하지 않는다.
