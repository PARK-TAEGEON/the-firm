# GEN-001 대형 사건 설계 3개

상태: **실험용 authored 설계, DEC 아님.** 구현 파일이 아니라 DEMO-001 인계용 설계다. 첫 번째를 데모 대표 사건으로 제안한다. 현재 웹 페이지나 사건 목록에는 등록하지 않았다.

세 사건 모두 새로 만든 가상 사건이다. 실제 사건의 사람·기관·날짜·장소·금액·특이한 범행 수법을 복원하지 않는다. 유명 강력사건·성범죄·아동 사건을 재현하지 않는다. 참고 자료에서는 아래에 적은 추상적 법리만 차용한다. 게임 문구에 실재 사건 번호나 당사자를 넣지 않는다.

## 공통 증언 원칙

사용자가 지정한 설계 메모 §1.10은 현재 체크아웃에 없다(§1은 1.8까지). 아래는 앞선 사용자 요청의 증언 원칙을 적용한 초안이며, §1.10 원문과의 대조는 대기 중이다.

- 목격자는 자기 기억에 성실하고, 기록 작성자는 자기 업무 범위에서 답한다. 관찰과 추론을 혼동할 수는 있다.
- 검사는 자신에게 유리한 범위를 묻는다. 주신문에서 불리한 한계까지 질문하지 않았다는 이유로 증인을 거짓말쟁이로 만들지 않는다.
- 카드 제시 후에는 그 자료가 확인하는 한계만 인정한다. ‘못 봤다’는 답변이 ‘그 일은 없었다’로 변하지 않는다.
- 근거 없는 일반화와 과욕에는 정중하게 반박한다. 진술 번복은 어느 기억·기록이 달라졌는지 연결해 남긴다.
- 이번 세 사건에 고의적 위증 모듈은 없다. 의뢰인의 초기 축소 진술은 법정 증인의 위증과 구분한다.

## 1. SIG_SEPARATED_MOMENTS — 두 장면 사이 (DEMO-001 상세안)

### 체험 목표와 법리 뼈대

‘밀친 사실이 있다’와 ‘그 밀침으로 이번 상해가 생겼다’를 구분한다. 플레이어가 불리한 접촉 사실을 무리하게 지우려 하면 증인이 버틴다. 접촉을 인정하면서도 영상·진료자료가 설명하는 범위를 좁히면 유리해진다.

진단서의 기재와 다른 자료를 함께 검토해 증명력을 판단한다는 관점만 참고한다. 실제 사실관계는 차용하지 않는다. [대법원 공개 판결 자료의 진단서 증명력 설명](https://www.scourt.go.kr/sjudge/1480471636913_110716.pdf). 원문 다운로드는 열람 시 방화벽에 막혀 공식 검색 색인의 법리 요약까지만 확인했다. 정식 출시 전 전문 검토가 필요하다.

### 고정된 숨은 진실

1. 공동 작업 공간에서 정산 문제로 말다툼이 있었다. 피고인이 상대의 어깨를 한 번 밀었다.
2. 상대는 곧 자세를 회복했다. 피고인은 더 접촉하지 않았다.
3. 상대가 가림막 뒤로 이동하다 바퀴 달린 운반대에 발이 걸려 넘어져 손목을 다쳤다. 피고인의 첫 밀침이 이번 낙상의 원인은 아니다.
4. 목격자는 팔 움직임과 상대가 가림막 뒤로 간 모습을 보았다. 넘어지는 소리를 듣고 앞의 동작이 원인이라고 연결했다. 실제 낙상 순간은 보지 못했다.
5. 현장 조사관은 진단서와 정지 사진을 성실하게 취합했다. 직접 낙상을 목격하거나 의학적 인과관계 감정을 한 사람은 아니다.
6. 의뢰인은 첫 상담에서 ‘몸을 건드리지 않았다’고 축소했다. 재면담에서는 밀침을 인정한다. 이것이 다른 사람의 관찰까지 모두 정확하게 만들지는 않는다.

진실은 고정한다. 새 게임에서 바뀌는 것은 플레이어의 조사·질문·절차 대응뿐이다. RNG·판결 직전 반전 추첨은 사용하지 않는다.

### 처음 보이는 사건 파일

제목: **두 장면 사이**. 혐의 표기: **폭행치상**. 의뢰인·피해자·목격자·조사관은 역할명으로 표시한다.

브리핑: ‘정산을 둘러싼 말다툼 뒤 한 사람이 넘어져 손목을 다쳤다. 검찰은 목격 진술과 진단서를 근거로 피고인의 행위가 상해로 이어졌다고 주장한다. 의뢰인은 접촉을 부인한다.’

초기 진술: ‘말다툼은 했지만 몸을 건드린 적은 없어요.’ 재면담 카드 뒤 추가 진술: ‘어깨를 한 번 민 건 맞습니다. 바로 다시 서 있었고 그 뒤로는 손대지 않았어요.’ 기존 진술은 삭제하지 않는다.

| RESULT_SIG_ACQUITTAL | INV_SIG_SEQUENCE/MEDICAL/LAYOUT/CLIENT 조사 → F_SIG_CAUSE + S_SIG_CONTACT → 두 유효 창 이의, 무효 창 통과 → 목격자는 자료 없는 질문으로 시간 소진·자동 종료 → 조사관 A_SIG_CAUSE_MEDICAL, A_SIG_CAUSE_SEQUENCE, P_SIG_CAUSE_LIMITED → CARD_SIG_LAYOUT 재반대 | CAUSE: 5-1-1-1+1-1=2 → not_guilty. ‘접촉은 인정했지만 상해와의 연결에 의문이 남았다.’ 다음: ‘의뢰인 면담이 개회사에 어떤 차이를 냈는지 비교해 보세요.’ |
| RESULT_SIG_CONVICTION | 조사 없음 → F_SIG_BALANCED + S_SIG_RESERVE → 이의 모두 통과 → 자료 없는 질문 후 종료 | 양쪽 5+1=6 → guilty. ‘검찰이 연결한 경위를 기록으로 좁히지 못했다.’ 다음: ‘연속 영상에서 두 장면 사이를 확인해 보세요.’ |
| RESULT_SIG_PARTIAL_ADMISSION | INV_SIG_CLIENT만 조사 → F_SIG_BALANCED + S_SIG_CONTACT → 이의 모두 통과 → 목격자 A_SIG_OBS_CONTACT 후 endCross → 조사관 자료 없는 질문 후 endCross | 양쪽 5+1=6 → guilty, 입장 태그 S_SIG_CONTACT. ‘일부 사실 인정 · 유죄: 밀침은 인정했지만 상해와의 연결을 다툴 자료는 제시하지 못했다.’ 다음: ‘인정할 사실과 추가로 조사할 쟁점을 나누어 보세요.’ |

세 결과 표시는 먼저 기존 verdict.outcome을 따른다. not_guilty면 무죄, guilty이면 기존 opening.stanceId의 S_SIG_CONTACT 여부를 표시해 위 두 유죄 복기를 구분한다. ‘일부 인정’은 변론 입장 태그이며 법적 일부 유죄 판결을 뜻하지 않는다. 복기에 실제 verdict를 함께 표시한다. 엔진에 세 번째 판결을 추가하지 않는다.

선택적 네 번째 `RESULT_SIG_SETTLEMENT`: 사건 선택 뒤 재판 전 고정 합의 제안 수락 → ‘합의 제안을 받아들였다. 형사 절차의 종결을 뜻하지 않으며 이후 대응은 별도로 협의한다.’ 다음 제안은 ‘다른 선택에서는 어떤 기록으로 경위를 다툴지 살펴보세요.’다. 법정 엔진 판결을 호출하지 않는다. 별도 선택 기록(예: pretrial_settlement_accepted)을 관리하는 서비스가 필요하나 현재 DEMO Owns에는 서비스 파일이 없다. 이 분기를 실제 추가하려면 계약의 소유 파일부터 보완해야 한다. 현재 계약만으로 구현할 기본 세 분기에는 포함하지 않는다. 수임료·양형·처벌불원 효과도 산출하지 않는다.

추가 자동 회귀 요구: 같은 정의·동일 명령열 replay 일치, 카드 없는 준비 접근법 거부 후 상태 불변, 이의 창이 열리지 않았을 때 objection 명령 거부, 과욕 후 기존 인정 보존, 두 기본 접근법 뒤 overreach로 바꾸면 CAUSE 5-2+2+1-1=5여서 무죄 경로 실패, 합의 분기에 verdict record 없음. DENY 후 A_SIG_OBS_CONTACT 사용은 점수 없이 credibility만 1 감소하고 다른 stance에서는 충돌 기록이 없어야 한다. objection 명령은 ID가 아닌 현재 pending 창과 object boolean을 사용한다. 수치 경로는 표의 고정 fixture 기준이며 실제 정의로 이관한 뒤 서비스 완주 테스트로 확인한다.

### 구현 파일과 인계 경계

DEMO 담당자의 Owns 안에서 `data/demo-separated-moments.js`에 위 literal 정의, `ui/trial-*`에 사건 파일·기존 판결과 입장 태그의 복기 표시를 구성한다. UI에서 점수·판결을 계산하지 않는다. 기존 `services/trial.js`를 재사용한다. 기본 세 분기에는 외부 엔진 변경이 필요하지 않다. 선택적 합의 분기 서비스는 계약 보완 대기다. 현재 GEN 코드에 등록하거나 DEMO를 시작하는 작업은 하지 않는다.

## 2. SIG_AFTER_THE_STOP — 멈춘 뒤의 기록

### 사건과 법리 뼈대

정차한 차량에서 확인된 사람과 그 뒤 측정 결과가 앞선 이동 구간을 얼마나 설명하는가. 운전·측정 사이 간격만으로 자동 무죄를 만들지 않는다. 시점, 수치와 관찰 정황을 종합한다는 추상적 관점만 차용한다. [국가법령정보센터의 운전·측정 시점 판단 법리](https://law.go.kr/LSW/precInfoP.do?precSeq=225407). 원 사건의 날짜·장소·수치·음주량·시간 간격은 가져오지 않는다.

- **숨은 진실:** 의뢰인은 대리운전 이용 뒤 정차한 차에 남았으며, 문제의 짧은 이동은 인도 직전에 기사가 했다. 현장 경찰관은 이동 차량을 봤지만 얼굴은 정차 뒤 확인했다. 장비 도착 전 대기가 있었고, 측정값은 의뢰인의 측정 시점 상태를 성실히 기록했다.
- **인물:** 의뢰인은 정차 후 운전석에 앉은 경위를 상담에서 생략했다. 경찰관은 연속된 상황이라고 진심으로 생각한다. 기사는 배차 통화와 후일 설명이 섞여 인도 시점을 혼동했다. 누구도 고의적 위증자로 설정하지 않는다.
- **쟁점:** ISSUE_SIG_DUI_DRIVER(문제의 이동 구간 운전자), ISSUE_SIG_DUI_TIME(측정 자료와 운전 당시 상태 연결).
- **준비:** 배차 인수인계 통화, 주차장 영상, 접수표, 측정 원본, 장비 관리 대장. 후보 조사 5개·예산 3을 제안한다. 아직 수치 밸런스는 확정하지 않는다.
- **반전 A:** 기사 추가 지목 ↔ 최초 통화의 관찰 범위 카드 ↔ 검사의 ‘기억 보충’ 수습 ↔ 인도 전후를 분리한 재반대. 최초 기록도 무조건 진실로 취급하지 않는다.
- **반전 B:** 측정 대상 일치 ↔ 장비 대기 접수표 ↔ ‘같은 사람을 측정’ 수습 ↔ 같은 대상과 같은 시점은 다른 주장이라는 재반대.
- **대표 대사:** 경찰관 ‘정차한 차에서 확인한 사람은 피고인이었습니다.’ 카드 후 ‘이동 중 얼굴을 계속 본 것은 아닙니다. 정차 전후 정황을 연결했습니다.’ 과욕에는 ‘다른 운전자를 제가 직접 확인했다는 뜻은 아닙니다.’
- **선택의 대가:** 운전자만 공격하다 시간 연결을 놓치거나, 측정값 자체를 거짓으로 몰다가 기록 작성자의 성실한 반박을 받는다. 무죄는 미입증 사유를 복기에 명시한다.
- **결과 후보:** 운전자 연결 미입증 / 시간 연결 미입증 / 검찰 주장 유지. 앞 두 개는 동일 not_guilty의 다른 복기 사유로 처리 가능하다.
- **구현 경계:** 기존 DUI 원형과 2증인 구조로 가능하다. 실측 혈중농도·역산·실제 법정 기준·측정 위법·증거 배제 판단은 추가하지 않는다. DEMO 첫 사건으로는 수치와 시점에 대한 사전 설명이 더 필요해 두 번째 후보로 둔다.

## 3. SIG_TWO_ESTIMATES — 두 장의 견적서

### 사건과 법리 뼈대

임대차 종료 때 반환할 보증금과 공제할 원상회복 비용의 범위를 다툰다. 임차인의 복구 범위는 실제 계약·목적물 상태를 살펴 정한다는 관점만 차용한다. [대법원 공개 법리 요약: 임차목적물 원상회복 범위](https://sc.scourt.go.kr/portal/news/NewsViewAction.work?gubun=4&searchOption=&searchWord=&seqnum=6796). 원 사건의 업종·권리금·당사자 관계·시설·금액은 차용하지 않는다.

- **숨은 진실:** 임차인이 이동식 작업대를 옮기다 바닥 일부를 훼손했다. 그 이전부터 다른 구역에 누수 자국이 있었다. 퇴거 뒤 견적서에는 부분 보수와 전체 교체 두 안이 있었지만 관리 담당자는 전체 교체 안만 전달했다.
- **인물:** 임차인은 자기 실수의 범위를 작게 말한다. 관리 담당자는 전체 교체가 안전하고 책임 있는 처리라고 믿는다. 수리업자는 손상 범위와 공법 선택을 구분해 설명한다. 가격 차이를 횡령이나 공모로 단정하지 않는다.
- **쟁점:** ISSUE_SIG_LEASE_END(반환 시점과 인도), ISSUE_SIG_LEASE_SCOPE(임차인 부담 손상 범위), ISSUE_SIG_LEASE_COST(보수안별 필요 비용). 민사 입증 책임은 별도 설계가 필요하다.
- **준비:** 입주 사진 원본, 인도 확인서, 작업대 이동 기록, 두 견적의 작성 요청, 수리업자 면담. 조사 순서에 따라 의뢰인 파손을 먼저 알거나 기존 누수를 먼저 확인한다.
- **반전 A:** 의뢰인 파손 인정 ↔ 이동 기록 ↔ ‘손상이 있다는 점은 인정됐다’ 수습 ↔ 기존 누수와 새 파손 구역을 나눈 재반대.
- **반전 B:** 전체 교체 견적 ↔ 부분 보수 견적 ↔ ‘전체 교체가 더 안전하다’ 수습 ↔ 필요 보수와 선택한 개선 공사의 비용을 구분한 재반대.
- **대표 대사:** 관리 담당자 ‘전체 교체가 가장 확실하다고 판단했습니다.’ 카드 후 ‘부분 보수안도 받았습니다. 다만 제가 전체 교체안을 권한 겁니다.’ 과욕에는 ‘공사 전부가 불필요했다는 말은 아닙니다.’
- **결과 후보:** 공제 범위 합의 / 일부 비용만 인정 / 자료 미확보로 협상 결렬. 비용은 작성된 구역별 항목을 기록에 근거해 비교해야 한다. 임의의 한 숫자 승패로 환산하지 않는다.
- **구현 경계:** 현재 GEN의 임대차는 daily-only이므로 이 사건을 형사 all_required 엔진에 넣지 않는다. 지금은 일상 파일·준비·합의 설계로 보관한다. 민사 공판과 계산 규칙은 다음 계약의 결정 대상이다.

## 선택과 남은 확인

DEMO 후보 1은 두 증인·기존 엔진·고정 명령 경로로 만들 수 있고, 불리한 사실을 인정하는 선택이 무엇을 보존하는지 짧게 보여준다. 후보 2는 시점 연결의 설명 난도가 높고, 후보 3은 민사 판정 모델이 미정이다. 대표 사건 선정은 제안이며 실제 DEMO 착수·병합은 사용자의 결정에 따른다.

세 설계의 재미와 법적 현실성은 사람 검수 전이다. 특히 합의 분기를 ‘형사 무죄’처럼 읽지 않도록 검수한다. 참고 링크는 제작자용 출처이며 플레이 화면의 사건 설정에 옮기지 않는다.
