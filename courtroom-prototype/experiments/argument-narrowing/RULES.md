# 주장 범위 축소 — 실험용 authored 규칙, DEC 아님

기준: DEMO-001 @ 288e1e72. 사건·판정·증거 효과는 기존 값을 사용한다.

## 실행과 비교

- courtroom-prototype에서 `npm start`; `http://127.0.0.1:4173/demo.html?argumentRevision=1`.
- 비교군은 쿼리 없는 `demo.html`. `argumentRevision=0`도 비활성이다.
- 모두진술 화면 하단에서 **이 강한 주장을 공개한다**를 선택하면 “손목 상해는 피고인의 밀침과 아무 관계가 없습니다”라는 별도 변론 기록을 남긴다. 기존 밀침 인정/부인 선택과는 다른 쟁점이다.
- 기존 수사관 신문의 **과한 결론을 요구한다**로 같은 취지의 질문을 한 경우도 수정 대상이다. 질문이 증인의 동의를 얻었다고 간주하지 않는다.
- 최후변론에서 근거를 하나 이상 직접 선택하고 남은 반론 확인 → **주장 범위 축소** → 검사 대응과 변론 미리 보기 → **수정한 논증으로 최후변론**.
- 강한 주장을 유지하거나 기존 최후변론 중 다른 것을 선택할 수 있다. 수정만 하고 다른 변론을 제출했다면 결과 화면에 미사용을 표시한다.

## 기록 규칙

1. 기존 발언, 증거, 과욕 불이익, 검사 재주신문, 신뢰와 시간은 삭제·환급하지 않는다. 새 claim/revision/response는 effects가 빈 advocacy 기록이다.
2. 법정에서 확인된 내용은 실제 증언·동의한 자료의 내용이다. 재판부의 사실인정 또는 숨은 진실로 승격하지 않는다.
3. 근거는 성공적으로 기록된 진료기록 범위 신문, 영상 범위 신문, 성공한 한정 결론, 성공한 동선 재반대 중 선택한다. 자료 확보만 했거나 제출을 막힌 경우, 실패한 한정 결론, 타 쟁점/다른 판 ID는 제외한다.
4. 수정은 최후변론 단계에서 1회. 빈 근거·중복·알 수 없는 ID·반론 미확인·잘못된 단계는 원자적으로 거절한다. 입력 순서 대신 공판 기록 순서로 저장한다.
5. revision은 원래 주장, 선택 근거, 확인 내용, 반론의 실제 record ID를 참조한다. response는 revision ID를 참조하고, 최후변론은 revision·response·선택 근거 ID를 참조한다. 읽기 모델은 기록에서 재구성한다.
6. 상처 존재, 통과시킨 인과 의견, 동의한 수사보고서, 재주신문, 과욕 답변은 남는다. 성공한 동선 재반대는 재주신문을 '일부 한정'하지만 다른 원인을 확정하거나 반론을 삭제하지 않는다.
7. 검사 대응은 이 사건에 작성한 대사 분기다. 실제로 성공한 동선 반박이 있으면 미검토 경로의 한계를 인정하되 원인 확정을 반박한다. 그 외에는 실제 상처 확인 기록 또는 자료의 한계를 근거로 대응한다. 검사 이름/능력으로 보너스를 주지 않는다.
8. 최후변론은 선택한 유리한 근거만 논증 전제로 사용한다. 확인 내용과 남은 반론, 검사의 대응도 함께 포함한다. 이를 재판 증거로 재투입하지 않는다.
9. 실험 모드의 공판 기록 ID는 부모 데모 세션 번호를 사용해 같은 탭에서 새 판을 시작한 뒤 이전 근거 ID가 재사용되지 않게 한다. 비활성 모드는 기존 ID 동작을 보존한다. 탭 간 저장/불러오기는 범위 밖이다.

## 보존 경계

engine/, services/trial.js, services/demo-outcome.js, 기존 사건 데이터, 기존 테스트와 기대값, trial.html, index.html은 수정하지 않는다. 한국 법 조문·양형 수치도 추가하지 않는다. 기존 판정 모델의 개선이나 전반적 절차 축소는 별도 실험이다.

## 재현 플레이

신참 또는 베테랑 → 진료자료 확인·연속 영상 확보 후 둘 다 증거 신청 → 모두진술의 강한 주장 공개 → 상해 연결 집중/밀침 인정 → 목격자 진술서·수사보고서 부동의, 영상·진단서 동의 → 유효한 두 원인 의견에 이의, 나머지는 통과 → 목격자 신문 종료 → 수사관 진료기록 범위·두 장면 사이·한정 결론 → 재주신문 → 최후변론의 위 수정 흐름.

다른 낙상 경로를 시험하려면 준비 때 현장 동선을 추가 확보하고, 기존 규칙대로 공판 개시 뒤 신청한 다음 재반대에서 사용한다. 일찍 신청해 검사가 대비한 경로와도 비교한다. 이 절차 차이는 기존 데모 규칙이며 이번 변경으로 완화하지 않았다.
