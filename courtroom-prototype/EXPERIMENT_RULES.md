# Courtroom Core v0.2 — 사건 전용 시연 규칙

사용자 승인 범위: 별도 웹 실험. 정식 THE FIRM 설계/법률 기준이 아니며 Godot의 Accepted DEC를 변경하지 않는다.

## 사실과 기록
- 거리 27m, 일부 조명 소등, 관찰 1–2초, 최초 진술의 불확실성을 어떤 순서로든 확보한다.
- 최초 진술 대조는 사건에 있는 최초 진술서를 근거로 제시한다. 다른 사실은 증언으로 확보한다.
- 답변과 명제는 분리한다. 증인의 말은 증언으로 기록되며 객관적 진실 확정과 동일하지 않다.
- 동일 명제는 한 번만 기록한다. 중복 질문 명령은 실패하며 상태를 변경하지 않는다.
- 논증은 이 사건의 식별 조건 계획에 속한, 실제 기록된 서로 다른 전제 2–4개만 사용한다. 논증 자체는 Evidence Record에 추가하지 않는다.

## Press 반응 (위에서부터 우선 적용)
1. 이미 압박한 증인에게 다시 압박하면 EXPLAIN: 6년 근무 관계를 설명하고 반대 명제를 기록한다. 이 설명까지 이미 기록되었다면 RESIST.
2. 현재 선택 전제에 최초 진술 불확실성과 관찰 조건 중 2개 이상이 있으면 ADMIT: 식별 단정의 한계를 인정한다.
3. 현재 전제에 조명 제한이 있고, 최초 진술 불확실성이 아직 기록에 없으면 EXPLAIN: 간판 불빛을 설명하고 반대 명제를 기록한다. 설명 명제가 이미 있으면 RESIST.
4. 나머지는 RESIST. 동일 인정/설명 명제는 재생성하지 않는다.

증인 상태의 압박 이력, 확보한 명제, 현재 논증 전제를 참고한다. 질문 순서는 기록/압박 이력을 통해 영향을 준다. 증거 근거는 사실 질문 서비스에서 검증한다. EVADE/CONTRADICT는 유형만 예약하며 생성하지 않는다.

## 시연 판정
종료 시 Evidence Record만으로 순서대로 평가한다. 주장 자체는 사실을 대신하지 않는다.
- 식별 한계 인정 또는 (최초 진술 불확실성 + 관찰 조건 2개 이상), 반대 명제 없음: 식별 근거 약화.
- 관찰 조건 2개 이상 또는 최초 진술 불확실성, 반대 명제 있음: 상반된 식별 근거 병존.
- 관찰 조건 2개 이상 또는 최초 진술 불확실성: 식별 의문 기록.
- 나머지: 식별 판단 자료 부족. 상대 주장이나 유죄의 자동 인정이 아니다.

위 조건은 질문 ID/질문 개수 대신 명제의 의미 태그와 기록을 사용한다. 고의·공격 행위·전체 사건의 유무죄는 판단하지 않는다. Resolution은 `adjudicated` 타입의 이 쟁점에 한정된 시연 판정이며 `negotiated`는 예약 타입이다.

## 전략
A는 식별 쟁점을 다투고 식별 논증을 선호한다. B는 접촉을 인정하고 고의를 다투므로 식별 논증은 보조 전략으로 표시되며 고의에는 효과를 주지 않는다. 실제로 Frame/Press한 논증만 공개 입장에 기록한다. 전략 전환은 가능하고 공개 입장은 보존한다. 충돌 가능성은 표시만 하며 페널티는 없다.
