# Courtroom Core v0.3 — 사건 전용 시연 규칙

사용자 승인 범위: 별도 웹 실험. 정식 THE FIRM 설계/법률 기준이 아니며 Godot의 Accepted DEC를 변경하지 않는다.

## 사실과 기록
- 거리 27m, 일부 조명 소등, 관찰 1–2초, 최초 진술의 불확실성을 어떤 순서로든 확보한다.
- 최초 진술 대조는 사건에 있는 최초 진술서를 근거로 제시한다. 다른 사실은 증언으로 확보한다.
- 답변과 명제는 분리한다. 증인의 말은 증언으로 기록되며 객관적 진실 확정과 동일하지 않다.
- 동일 명제는 한 번만 기록한다. 중복 질문 명령은 실패하며 상태를 변경하지 않는다.
- 논증은 이 사건의 식별 조건 계획에 속한, 실제 기록된 서로 다른 전제 2–4개만 사용한다. 논증 자체는 Evidence Record에 추가하지 않는다.

## 세 행동의 가치와 부담
- Stop: 현재 기록 보존. 새 논증/식별 인정/반대 기록/공개 입장은 생성하지 않는다.
- Frame: 기록된 호환 전제 2–4개를 쟁점에 연결해 재사용 가능한 공개 논증을 남긴다. 증인 인정은 생성하지 않는다. 전략 변경 후에도 공개 입장이 남는 부담이 있다. 이번 버전에는 임의 비용/페널티 수치를 넣지 않는다.
- Press: 증인이 식별 한계를 직접 인정할 수 있고, 실패하면 버팀/반대 설명이 남는다. 결론 질문의 공개 기록은 완성된 Frame과 구분한다.

자료 보존, 주장 구축, 증인 인정은 별도 성과다. 단일 점수로 순위를 매기지 않는다. A의 충분한 근거에서는 Press가 강한 증언을, 약한 근거에서는 Frame이 설명 위험 없이 논증을, B/전략 미확정에서는 Stop이 추가 공개 입장 없이 자료를 남긴다. Frame 후 Press도 허용하며 각 행동의 부담을 모두 보존한다. 장기적인 선택 균형은 실제 플레이테스트가 더 필요하다.

## Press 서명과 반응 (위에서부터 우선 적용)
서명은 논증 계획 + 증인 대상 + 정렬된 전제 ID 집합이다. 같은 조합 또는 이전 조합의 부분집합은 반복이다. 이전 조합의 엄격한 상위집합이며 과거 동일/더 큰 조합이 없으면 근거 보강이다. 서로 포함되지 않는 조합은 새로운 근거다. 새 사실을 확보만 하고 선택하지 않으면 보강이 아니다.

1. 반복 압박이면 EXPLAIN: 6년 근무 관계를 설명하고 반대 명제를 기록한다. 이 설명까지 이미 기록되었다면 RESIST.
2. 현재 선택 전제에 최초 진술 불확실성과 관찰 조건 중 2개 이상이 있으면 ADMIT: 식별 단정의 한계를 인정한다.
3. 현재 전제에 조명 제한이 있고, 최초 진술 불확실성이 아직 기록에 없으면 EXPLAIN: 간판 불빛을 설명하고 반대 명제를 기록한다. 설명 명제가 이미 있으면 RESIST.
4. 나머지는 RESIST. 동일 인정/설명 명제는 재생성하지 않는다.

증인 상태의 근거별 압박 이력, 확보한 명제, 현재 논증 전제를 참고한다. 단순 Press 횟수는 반응 조건이 아니다. 증거 근거는 사실 질문 서비스에서 검증한다. EVADE/CONTRADICT는 유형만 예약하며 생성하지 않는다.

## 친분 반대 명제 대응
기존 ID `P_FAMILIARITY`를 유지한다. 이 기록과 최초 불확실 진술이 모두 있으면 ‘최초 진술과 대조’가 열린다. 증인은 친분이 당시 확신까지 보장하지 않았음을 인정한다. 새 `P_FAMILIARITY_LIMIT` 기록에 원 반대 기록 ID와 최초 진술 기록 ID를 연결한다. 전체 식별 한계 인정과는 구분한다.

원래 6년 근무 기록은 삭제/변경하지 않는다. 판정에서는 연결된 제한 증언을 검증해 친분 반대 기록의 의미를 제한한다. 간판 불빛은 영향받지 않는다. 반박은 한 번만 가능하고, 근거 부족/중복 명령은 상태를 바꾸지 않는다.

## 시연 판정
평가 입력은 Evidence Record + Advocacy Record + 현재 Theory ID뿐이다. UI 선택, 현재 plan, 질문/Press 이력은 읽지 않는다. 최종 판정 규칙에 selectedTags/repeated는 중첩된 경우도 허용하지 않는다. 주장 자체는 사실을 대신하지 않는다.
- 직접 식별 한계 인정, 미해소 반대 명제 없음: Witness Admission. 가장 강한 증언 성과.
- 관찰 조건 2개 이상 또는 최초 진술 불확실성, 미해소 반대 명제 있음: 상반된 식별 근거 병존. 기존 인정/논증도 별도 성과로 남는다.
- 유효한 Frame, 미해소 반대 명제 없음: 식별 논증 구축. 증인의 인정 아님.
- 관찰 조건 2개 이상 또는 최초 진술 불확실성만 확보: 전제 보존. 논증이나 인정을 자동 생성하지 않는다.
- 나머지: 식별 판단 자료 부족. 상대 주장이나 유죄의 자동 인정이 아니다.

위 조건은 질문 ID/질문 개수 대신 명제의 의미 태그와 기록을 사용한다. 고의·공격 행위·전체 사건의 유무죄는 판단하지 않는다. Resolution은 `adjudicated` 타입의 이 쟁점에 한정된 시연 판정이며 `negotiated`는 예약 타입이다.

## 전략
Argument → Issue → 현재 Theory의 contestedIssues/preferredPlans로 핵심/관련/보조 가치를 평가한다. A의 식별 Frame/Admission은 핵심 전략을 발전시킨다. B에서는 같은 성과도 보조 성과이며 고의는 미해결이다. Theory가 바뀌어도 증언 내용/판정 자체는 바뀌지 않는다.

A의 식별 공격에 불리한 counter를 전략상 충돌 기록으로 표시한다. 이것은 논리적 모순을 자동 판정하는 기능이 아니다. B는 접촉을 인정하므로 같은 counter를 고의 전략과의 충돌로 보지 않는다. 의미 제한된 counter도 원 기록과 제한 상태를 함께 표시한다. Frame/Press만 공개 입장을 추가한다. 전략 변경 시 과거 공개 입장을 보존하며 일관성 비용/페널티는 미구현이다.

공개 입장이 현재 우선 쟁점 밖에 있거나 미해소 반대 기록이 있으면 `commitmentReviewRefs`에 설명이 필요한 공개 기록을 남긴다. 공개 입장이 없으면 flexible, 현재 쟁점과 맞으면 aligned, 설명이 필요하면 review_required로 결과에 표시한다. 따라서 B의 식별 Frame은 Stop과 달리 핵심 쟁점을 해결하지 못하면서 공개 입장 설명 부담을 남긴다. 이것은 현재 기록의 후속 검토 상태이며 자동 감점이나 Closing 시뮬레이션은 아니다.

## 미구현
민사 플레이, 유무죄/형량, 자동 법률 추론, 이의/증거능력 판정, 판사 AI, 협상, 항소, Closing, 저장, Godot 통합. 민사 데이터는 테스트 전용이다.
