# PLAN-DEMO-001 실험 규칙 (Accepted DEC 아님)

- 새 사건 진실, 증거, 증인, 대사, 판결 알고리즘은 작성하지 않는다. 기존 DEMO-001 \`demo-separated-moments.js\`, \`engine/trial.js\`, \`services/demo-trial.js\`, \`services/demo-session.js\`가 자료와 실제 진행을 소유한다.
- 플레이어는 담당 변호사의 **내부 변론 계획**을 승인한다. 승인 자체는 법원/검찰 제출이나 법정 발언이 아니다. 재판부는 실제 적법한 증거·주장·증언만 평가한다.
- 이번 실험은 **이미 조사한** 의뢰인 재면담, 연속 영상, 진료기록, 현장 동선 4개를 동일하게 확보한 사건 스냅샷이다. 의뢰인 상담과 합의는 실험에서 실행하지 않는다. 진술이 바뀌거나 숨은 진실이 자동 공개되지 않는다.
- 기본 입장은 \`S_SIG_CONTACT\`, 주력은 \`F_SIG_CAUSE\`. 신참 검사 \`novice\`만 대상. 목격자 기본 주신문은 자동으로 듣고, 수사관에게 \`A_SIG_CAUSE_MEDICAL\`, \`A_SIG_CAUSE_SEQUENCE\` 두 질문을 자동 실행한다. 적합한 질문에만 기존 스크립트의 이의를 하고, 상대 재주신문은 기록대로 실행한다.
- 현장 동선 포함은 **해당 재반대신문이 허용되고 실제로 열렸을 때만** \`rebut(use:true)\` 실행한다. 제외는 \`rebut(use:false)\`. 나머지 준비와 신문은 동일하다. 질문이 나갔다고 원하는 답을 만들어내지 않으며 실제 답변은 기존 서비스의 append-only CourtRecord에서 읽는다.
- 종결은 원본의 기존 \`FINAL_SIG_CAUSE\`로 한다. 원본의 실험 판결을 보여주되, 기록 화면의 '신문 수행'은 판결의 '사실 인정'과 별개다. 별도 승률/능력 보너스는 없다.
- 레거시 제약: DEMO-001은 현장 자료를 일찍 신청하면 특정 검사의 \`preparedAgainst\` 차단을 유발한다. 이번 어댑터는 기존 데모 테스트 경로대로 **증거 의견 뒤 실제 허용된 창에서** 현장 자료를 신청한다. 이는 엔진의 선제 제출 함정을 승인한 결정이 아니며, 향후 기본 경험에서는 별도 개선 검토가 필요하다. 해당 경로의 지연 신청으로 발생할 수 있는 엔진상 효과도 이번 실험이 법적으로 정당화하는 것은 아니다.
- 특별한 개입 이벤트, 임의의 증거 확보, 휴정/속행, 법정 랜덤, LLM 추론, 직원 역량 시뮬레이션, 세계 일정, 저장/불러오기, 양형 검수는 범위 밖이다.
