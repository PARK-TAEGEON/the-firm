- 부분 수정: 기존 현장 동선 대응만 토글, 기본 영상/진료 계획 보존.
- 법정: 기존 서비스의 준비→증거 의견→신문→재주신문→최후변론→실험 판결을 한 번의 승인으로 자동 수행. 질문마다 멈추지 않음.
- 기록: 계획대로 실행된 접근법·재반대신문을 실제 기록에서 확인하고 강조. 상대방 발언과 별도 원본 데모 판정 구분.
- 테스트: Node 동일 기록 결정성·기본 신문 보존·현장 대응 차이·원본 데이터 불변을 검증하는 테스트를 추가함.
