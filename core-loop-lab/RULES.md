# 실험용 authored 규칙, DEC 아님

한 창고 상해 장면, 식별/칼 사용 시점 두 쟁점, 6공방. 승패는 판결이 아니라 해당 장면의 논증 목표 달성 여부다. 사건별 범용 설계, 준비 조사, 전체 공판, 로펌 운영은 없다.

- 집중 최대 4. 질문 비용 1, 증거 비용 2. 기록 정리 +2, 일부 인정 +2, 유지/축소 +1, 강화 비용 1, 전환 비용 0. 회복은 상한까지다. 전술과 수정은 각 공방에서 한 번씩 수행한다.
- 각 쟁점의 질문/증거는 각각 단일 출처이며 재사용 불가. 질문 기여 2, 증거 3. 같은 출처는 중첩하지 않는다. 수치는 내부용이고 화면에는 출처와 언어 평가를 표시한다.
- 질문 뒤 상대는 그 쟁점의 증거를, 증거 뒤에는 질문을 대비한다. 대비한 전술의 기여는 1 감소한다. 상대의 대비는 한 쟁점에만 적용되며 전환 자체로 근거가 생기지는 않는다. 회복 행동은 방어를 해제하지 않는다. 일부 인정 뒤에는 그 쟁점에 대해 특정 전술 방어가 해제된다.
- 두 출처를 연결하는 강화는 이미 기록된 자료의 한정을 해소한다. 출처별 기여를 원래 상한으로 복구하며 별도 점수/증거를 추가하지 않는다. 출처 ID를 인용한 논증 기록이 남는다. 쟁점별 1회만 가능.
- 넓은 주장은 두 출처 연결과 기여 5가 필요하다. 좁은 주장은 기여 3이면 성립한다. 인정/축소는 좁은 주장으로 고정되며 되돌릴 수 없다. 이전 발언은 삭제되지 않는다. 일부 인정 자체는 증거 기여가 없다.
- 한 쟁점의 넓은 주장 성립 또는 양쪽의 좁은 주장 성립이 이번 장면의 목표다. 하나만 좁게 성립하면 부분 성과, 아무것도 성립하지 않으면 미달이다. 유무죄/형량을 계산하지 않는다.
- 명령 replay가 동일 상태·기록을 재구성한다. 실패 명령은 상태/ID/명령 로그를 바꾸지 않는다. 전술 반박은 즉시 나오지만 다음 단계는 플레이어가 직접 진행한다. RNG, 타이머, 자동 진행 없음.

이름·사실관계는 기존 B동 창고 사건을 참조했다. 대사·자료는 이 실험용 축약이며 기존 판정/엔진을 가져오지 않았다. 5–10분은 읽기·선택·복기를 포함한 목표이며 실제 소요시간은 사람에게 미검증.
