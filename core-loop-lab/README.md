# THE FIRM — 주장과 반박

기존 `courtroom-prototype/`과 독립된 한 장면 실험. 상해 사건의 식별/칼 사용 시점을 6공방 동안 다툰다. 첫 읽기와 복기 포함 **5–10분 목표**, 사람 측정 전이다.

## 실행

- 가장 간단히: 이 폴더의 `index.html`을 Edge/Chrome에서 연다. 설치/인터넷 없이 작동한다.
- 서버: 이 폴더에서 `npm start` → http://127.0.0.1:4175
- Node.js 18 이상. 런타임 외부 의존성 없음. 새로고침하면 기록이 초기화된다. 마지막 화면에서 JSON 기록 다운로드 가능.

## 플레이

1. 주력 쟁점을 선택한다.
2. 상대 주장과 다음 대비를 읽고 질문/증거/인정/기록 정리를 선택한다.
3. 반박을 본 뒤 강화/축소/유지/전환을 결정한다.
4. 여섯 공방 뒤 출처를 인용한 결과와 전체 기록을 비교한다.

넓은 주장 하나를 지키거나 양쪽의 좁은 의심을 지키면 장면 목표 달성. 최종 판결은 아니다. 질문과 증거의 순서는 고정되지 않는다. 일부 인정은 넓은 결론을 포기하는 대신 집중을 회복한다.

## 검증

`npm test`: 순수 엔진/서비스, 실패 원자성, 결정성, 250개의 재현 가능한 경로와 기록 replay.

`npm run test:browser`: Playwright와 Microsoft Edge 필요. 별도의 테스트 환경에 Playwright를 설치하거나 NODE_PATH로 제공한다. HTTP/직접 파일, 1440×900 / 390×844, 세 전략, 키보드 툴팁, 다운로드, 재시작을 확인한다. 선택적으로 기존 디렉터리를 LAB_SCREENSHOT_DIR로 지정하면 결과 스크린샷을 저장한다.
