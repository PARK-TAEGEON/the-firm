# 데모 리뷰 후속 — 사건 중심 판단과 수임·비용 v0.1

작성: 2026-10-08 · 상태: **사용자가 확정한 설계 원칙 + 검증할 가설 + 보류 결정**. 구현 완료·법률 검수 완료·Accepted DEC 전면 개정이 아니다.

근거는 「데모 리뷰 feedback」 후속 사용자 요청의 여섯 항목이다. 참조 대화에서 읽을 수 있었던 최근 사용자 발언은 준비 기간과 비용 논의이며, 일부 응답은 참조 표지만 반환됐다. 읽지 못한 응답이나 심층 리서치 원문을 확인한 것으로 간주하지 않는다. 플레이 소감은 전달받은 평가이며 이번 작업에서 새 사람 플레이테스트를 수행하지 않았다.

## 2. 확정 원칙 — 경험·사건·딜레마가 먼저

설계 순서는 **의뢰인의 사정 → 플레이어가 지키고 싶은 것 → 불완전한 정보 → 양립하기 어려운 선택 → 실제 행동과 상대 대응 → 결과/회복 → 필요한 조작**이다. 이전 데모의 과도한 숨은 조건과 새 실험의 반복 공식은 양쪽 모두 판단의 맥락이 부족한 문제다.

“강화”를 눌러 논증을 완성하는 대신, 어떤 증인에게 관찰 위치를 확인하고 어떤 자료로 시간·동선을 대조하는지부터 쓴다. 행동의 효과는 실제 답변·자료·절차 기록을 거쳐야 한다. 상대가 무엇을 새로 알았고 어떻게 대응했는지, 실패 후 무엇이 남고 어느 범위까지 회복 가능한지도 함께 쓴다. 모든 법적 절차와 문답을 수동 클릭하게 하지 않는다. 의미 없는 확인·반복 입력은 자동 기본 수행이나 요약으로 묶는다.

UI/UX와 메커니즘은 공동 검증한다. 행동 전에는 기대하는 이익, 대가, 불확실성과 되돌릴 수 있는 범위를 읽을 수 있어야 하고, 행동 뒤에는 실제 변화와 남은 반론을 보여준다. 법률 퀴즈를 풀거나 제작자의 버튼 순서를 외우는 능력을 난이도로 삼지 않는다.

## 3. 검증할 사건 초안 — 약한 밀침과 상해 혐의

현재 대표 사건을 기반으로 한 **설계 초안**이다. 기존 시나리오·숨은 진실·증거 데이터는 수정하지 않는다. 특히 기존 첫 상담의 접촉 부인과 아래 “약한 밀침”의 공개 시점은 다른 층이다. 이를 첫 화면에서 사실로 공개할지, 재면담에서 드러낼지는 보류한다.

| 정보 층 | 작성할 내용 / 노출 경계 |
| --- | --- |
| 실제 진실(작가 전용) | 약한 밀침의 실제 정도·시점과 부상 발생 경위를 별도 확정할 필요가 있다. 상해 원인, 인물의 고의·거짓말 여부는 이 초안에서 단정하지 않는다. 진실 표를 플레이어/상대의 전지적 입력으로 사용하지 않는다. |
| 처음 공개된 정보 | 의뢰인이 느끼는 억울함과 형사처벌·일상생활에 대한 걱정, 상해 혐의, 검찰이 공개한 자료, 목격자의 주장. 의뢰인의 말도 사실 확정이 아닌 진술이다. |
| 조사로 획득 가능한 정보 | 짧은 관찰의 한계, 검찰이 아직 갖지 못한 현장 사진, 인과관계를 단정하지 못하는 진료기록 등. 발견 경위·접근 권한·입수/검토 상태·누가 알고 있는지를 붙인다. 얻기 전부터 숨은 자료 목록을 보여주지 않는다. |

서사 흐름 후보:

1. 상담에서 “왜 이 사람을 도와야 하는가”를 느낀다. 의뢰인은 책임을 피하려는 면과 과한 책임을 두려워하는 면이 함께 있을 수 있다. 억울함을 들었다고 무죄나 완전한 결백을 보증하지 않는다.
2. 짧게 본 목격자의 말과 공개 자료를 확인한다. 목격자는 악의적 거짓말쟁이 대신 관찰과 추론을 섞을 수 있는 사람이다. 피해자의 통증·생활 손실 역시 존중하며 거짓 피해를 기본 반전으로 삼지 않는다.
3. 현장 사진과 진료기록을 조사한다. 사진은 위치·시야를 다투는 근거가 될 수 있지만 사고 원인 전체를 증명하지는 않는다. 진료기록의 한계는 “부상이 없다”는 뜻이 아니다.
4. 조사 중 피해자 측 합의 제안이 도착한다. 의뢰인은 비용뿐 아니라 책임을 인정하는 문구가 불편하다. 합의 문구 조정·추가 설명·거절을 고민한다. 합의가 무조건 최선이거나 피해자가 돈만 노리는 장치가 되지 않게 한다.
5. 혐의 다툼, 유죄에 대비한 처벌 경감, 피해 회복·합의를 층별로 준비한다. 서로 배타적인 세 직업/정답 루트가 아니며 의뢰인 목표·동의와 자료에 따라 병행할 수 있다.
6. 재판에서 준비한 전략을 실행하고 공개된 주장·자료에 대한 검사 대응을 읽는다. 주장 유지·범위 한정·추가 조사 필요를 판단하고, 결과는 법적 주문, 의뢰인 반응, 비용·사무실 후속 일정으로 나뉘어 돌아온다.

사건에서 먼저 시험할 딜레마(모두 authored 후보, 확정 규칙 아님):

| 실제 행동 | 얻는 것 / 기회비용 | 상대의 후속 행동 후보 | 회복 경로와 남는 것 |
| --- | --- | --- | --- |
| 목격자의 위치·관찰 시간을 현장 사진과 대조 | 진술의 한계를 구체화 / 사진이 보여주지 못하는 원인까지 주장하면 논증이 취약해짐 | 검사는 관찰 한계를 인정하면서 다른 자료의 연결로 이동 | 관찰 범위만 다투고 원인 부정 주장을 좁힐 수 있음. 이전 과장과 답변 기록은 남음 |
| 진료기록의 인과관계 공백에 전문가 의견을 구함 | 해석 보강 / 실비·회신 대기, 유리한 결론 보장 없음 | 실제 제출된 의견의 전제·한계를 다툼 | 기존 기록의 한계만 주장하거나 추가 확인. 불리한 의견을 없었던 정보로 취급하지 않음; 법원 입력 여부는 절차에 따름 |
| 합의 문구에서 상해 원인 인정 범위를 조정하도록 조언 | 피해 회복과 의뢰인 목표 양립 가능 / 상대가 거절하거나 협상이 지연될 수 있음 | 피해자 측은 문구·조건 재제안 또는 거절, 검사는 별도 공개 자료로 대응 | 권한 범위에서 재협의하거나 합의 없이 혐의·양형 대응. 거절 자체에 자동 유죄 페널티 없음 |

## 4. 확정 원칙 — 변호사의 지식과 플레이어의 판단 분리

플레이어가 법률 초보여도 주인공은 로스쿨을 졸업한 변호사다. 기본 법률 지식·쟁점·법적 요건·가능한 처분/판결은 게임이 직관적으로 설명한다. 기본 용어를 알기 위해 조사 횟수를 지불하게 하지 않는다. 추가 법률 연구는 사건별 어려운 해석·적용을 다루며 기본 지식을 잠금 해제하는 장치가 아니다.

전략 보드는 다음 두 영역을 문장으로 분리한다. 아래는 **검수 전 UX 문구 초안**이며 실제 법률 판단·형량 예측이 아니다.

| 법률상 가능한 결과(일반 요건·절차 설명) | 현재 증거 기반 전망(획득·검토한 자료에 한정) |
| --- | --- |
| “상해 혐의가 충분히 입증되지 않으면 그 혐의에 대한 무죄가 가능하다.” | “진료기록만으로 밀침과 부상의 연결을 단정하기 어렵다. 다른 자료가 연결을 뒷받침하는지는 남아 있다.” |
| “상해가 인정될 경우 가능한 형과 양형 범위는 적용 법규·사정에 따라 확인해야 한다.” | “합의와 피해 회복은 검토할 사정이다. 지금 자료만으로 특정 형을 약속할 수 없다.” |
| “상해가 인정되지 않아도 별개 폭행죄의 성립·절차 처리가 문제될 수 있다.” | “접촉 사실과 상해 원인 다툼은 구분해야 한다. 폭행으로 판단 가능한 공소사실·방어권·절차 조건은 확인이 필요하다.” |
| “공소기각은 특정 절차적 요건에 따른 결과이며 무죄의 상위 단계가 아니다.” | “합의 성립만으로 공소기각을 예고하지 않는다. 적용 죄명, 처벌불원 의사와 제출 시점 등 요건을 별도로 확인한다.” |

유죄 시 양형 가능 범위를 제공하되 법정형, 양형기준상 권고범위, 이 사건의 전망을 섞지 않는다. 정확한 수치·형종·요건은 법률 검수 후 ko 팩에 넣는다. 기존 데모의 고정 벌금·집행유예 표를 현실 범위로 재사용하지 않는다. 고정 승률, 숨은 정답 안내, 판사 최종 판단의 선공개는 금지한다.

형사 합의 안내는 단순 폭행의 처벌불원에 따른 절차 효과와 상해에서의 피해 회복·양형 고려를 구별하는 방향으로 작성한다. “합의하면 상해 사건도 자동 종결”로 설명하지 않는다. 실제 적용 죄명·예외·의사표시·시점과 제출 절차는 검수 전이며, 기존 데모의 자동 결과 분기를 그대로 법률 설명으로 옮기지 않는다.

CK3식 맥락 툴팁은 쉬운 뜻 → 이 사건에서 고려할 점 → 짧은 예시 → 확인된 법률 근거 순으로 점진 노출한다. 설명 안의 용어도 열 수 있고 마우스·탭·키보드로 접근할 수 있어야 한다. 지식 제공은 선택의 의미를 설명하며 최선의 전략을 대신 결정하지 않는다.

## 5. 확정 원칙과 보류 — 충분한 준비, 의미 있는 제약

- 다음 단일 사건 데모에서 **인위적인 조사 행동력과 극단적으로 짧은 준비 기간을 기본 제약으로 쓰는 안은 보류**한다. 반나절 4회/5회 조정만으로 문제를 풀지 않는다. 기존 비교 데모는 그대로 보존한다.
- 수임부터 공판까지 준비 여유가 있는 사건을 설계할 수 있다. 1인 사무소가 사건 하나를 맡는 데모는 통상 조사·면담·검토를 충분히 할 수 있어야 한다. 모든 현실 사건이 여유롭다고 일반화하지 않으며 구체 소요 기간은 사건별 검증 대상이다.
- 날짜 사무실·기일·메시지는 유지한다. 실제 회신 대기·접근 가능 시점·기일을 보여주고, 기일 사이 추가 조사와 전략 수정을 허용하는 흐름을 설계한다. 절차상 가능 시점과 데모에서 다룰 기일 수는 보류한다.
- 선택은 자료의 불확실성, 접근 제한, 상당한 외부 실비, 상대가 새로 대응하는 상황에서 나온다. 충분히 조사해도 모든 진실·증거를 확보하거나 원하는 해석을 얻는 것은 아니다.
- 시간·인력 압박은 다중 사건, 기일 충돌, 영업·검토·성장이라는 로펌 운영에서 자연스럽게 나타난다. 기존 §2.15의 시간 예산은 그 층에 유지한다. 모든 날·모든 조사에 필수 클릭이나 화폐 차감을 붙이지 않는다.

## 6. 수임·비용 경영 v0.1

**확정 원칙:** 플레이어는 명성·전문성·시장 평판을 참고해 사선 사건의 수임 보수를 자율 책정한다. 명성이 가격을 기계적으로 잠금 해제하거나 판정 보너스를 주지는 않는다. 국선 등 별도 제도 보수까지 자유가격으로 바꾸는 결정은 아니다.

기존 SYS-004의 유입 경로를 확장해 **문의/의뢰 유입 → 보수·범위 설명 → 의뢰인 결정 → 실제 계약 전환**을 구별한다. 높은 명성으로 문의가 늘면서도 높은 가격 때문에 가격에 민감한 집단의 계약 전환율은 낮아질 수 있다. 의뢰인 유형별로 가격·전문성·신뢰에 두는 비중을 다르게 두되, 정확한 탄력성·비율·공식은 검증할 가설이다. 문의 수를 곧바로 매출/계약 수로 세지 않는다.

| 비용 구분 | 선택과 기록 |
| --- | --- |
| 약정 범위의 기본 업무 | 통상 면담·기록 검토·현장 확인은 기본 보수 범위에 포함하는 데모 계약을 전제한다. 일반 조사마다 별도 게임 화폐를 소비시키지 않는다. 업무 시간·사무소 운영비 자체가 사라지는 것은 아니다. |
| 상당한 외부 실비 | 외부 의료 감정·전문 영상 분석·외부 조사 등의 목적, 기대 정보, 한계, 예상 비용·대기 시간을 설명한다. 적법한 접근 범위와 의뢰인 동의·계약 범위를 준수한다. |
| 의뢰인과 협의·청구 | 승인한 범위·부담 주체·청구/입금 상태를 남긴다. 설명했다고 동의로 처리하거나, 거절 뒤 자동 발주·청구하지 않는다. |

| 기존 자료로 대응 | 추가 지출을 하지 않고 불확실성을 감수하거나 주장 범위를 한정한다. 필수 정답 경로를 돈으로 잠그는 구조가 되지 않아야 한다. |

초기 1인 사무소에서는 “이미 보수를 냈는데 왜 더 필요한가”라는 비용 협상과 설명의 질이 신뢰·만족에 영향을 줄 수 있다. 분쟁의 효과는 설명·동의·이행 기록에 근거하며 비용을 더 썼다는 이유만으로 만족이나 승소를 보장하지 않는다. 큰 로펌은 자체 인력·예산·반복 업무로 일부 비용을 내재화할 수 있으나 인건비·기회비용·전문 감정료가 모두 무료가 되지는 않는다.

결과 화면은 **경영 수익(보수와 실제 지출/미수) / 의뢰인 만족(목표·설명·비용 경험) / 실제 사건 성과(법적 결과와 근거)**를 분리한다. 낮은 이익과 높은 만족, 좋은 법적 결과와 비용 불만이 함께 존재할 수 있다.

**첫 데모 구현 후보:** 수임료 설정 1회, 상당한 전문가 비용 협의 1회. 가격 입력/선택 방식, 거절 후 흐름, 금액과 효과는 미정이다. 전체 경영 시스템·시장 시뮬레이션을 선행 구현하지 않는다.

**법률 주의:** 현대 한국 형사사건의 결과연동 성공보수는 원칙적으로 무효라는 경계를 유지한다. 대법원 2015다200111 전원합의체 판결의 선고 이후 체결 약정에 대한 판단은 [공식 판결 요지](https://scourt.go.kr/supreme/news/NewsViewAction2.work?gubun=4&searchOption=&searchWord=&seqnum=4909)와 [보도자료](https://www.scourt.go.kr/portal/news/NewsViewAction.work?gubun=6&searchOption=&searchWord=&seqnum=1055)를 확인했다(2026-10-08). 외부 실비나 추가 업무 보수를 무죄·감형 보너스의 우회로로 만들지 않는다. 개별 약정과 최신 적용은 출시 전 법률 검수 대상이다.

## 7. 심층 리서치의 사용 범위

FM/HOI4/CK3/RimWorld/Into the Breach는 전달된 리서치의 참고 게임이다. **계획 → 자동 실행 → 예상치 못한 변화 → 선택적 개입**, 정보의 점진 노출은 유용한 설계 가설로 유지한다. 각 게임의 효과나 플레이어 행동에 대한 연구 결과를 이번 작업에서 검증한 사실로 인용하지 않는다.

리서치가 제안한 타임라인 자동전개는 이미 정한 진행 구조의 일부이며 재미의 해법 자체가 아니다. 사건 준비 매트릭스는 정보·계획의 조직, 타임라인은 진행·표현, 전략/전술 병행은 의사결정 층이다. 셋을 배타적 제품 대안으로 투표하지 않는다. 우선 §3처럼 얻는 것·기회비용·상대 후속 행동·회복 가능성이 있는 사건 딜레마를 쓰고, 그것을 지원하는 구조를 선택한다. 원문/출처가 확인되지 않은 연구 주장·효과 수치는 보류한다.

## 8. 후속 검증과 미결정

PR #9의 단계 0·1에 다음 확인을 추가한다. 새로운 일반 개발 일정은 만들지 않는다.

1. 같은 자료에서 다른 합리적 전략 두 개를 설명할 수 있는가? 버튼 이름 없이 실제 행동·대가·상대 대응·회복 경로로 설명하지 못하면 메커니즘 구현 전에 사건 설계를 수정한다.
2. 법률 초보가 법률상 가능 결과와 현재 전망을 구분하고, 의뢰인을 돕고 싶은 이유와 판단 근거를 말할 수 있는가? 정답을 툴팁에서 받아 썼는지도 관찰한다.
3. 충분한 조사 후에도 불확실성과 선택이 남는가? 동일한 강화 공식, 조기 성공 후 공회전, 필수 법률 상식 부족으로만 실패하는 경로는 실패 신호다.
4. 비용 협의에서 청구/흡수/기존 자료 대응을 각각 납득할 수 있는가? 문의 증가와 계약 전환 감소가 함께 표현되는가? 수익·만족·사건 결과를 서로 바꾸어 표시하지 않는가?

보류: 실제 진실과 공개 시점 확정, 준비 기간·기일 수, 외부 감정의 접근·회신·금액, 가격 민감도 공식, 자동 공방 정책, 보드 배치, 구체 형종·양형 수치. 단순 폭행/상해·인과관계, 합의/처벌불원의 효과와 시점, 축소사실 인정·방어권·공소기각 요건은 법률 검수 후 확정한다. 이 문서의 사건 예시가 법률 검수를 대신하지 않는다.

기존 §2.16의 결과 사다리와 베테랑 무죄 불가·예산 4→5·최후변론에 따른 형 단계 조정은 과거 제안/실험 맥락이다. 다음 slice의 확정 제약으로 승계하지 않는다. 새 기본 원칙은 이번 사용자 요청으로 확정됐지만 메커니즘의 재미·경제 효과는 아직 검증되지 않았다.
