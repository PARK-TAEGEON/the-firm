# THE FIRM · 재판 경험 설계 현황판

갱신: 2026-10-11 · v0.6 · 상태: 주인공 역량·참여 방식 사용자 결정 / 구현·플레이 검증 전

## 60초 요약

**정민호 사건은 일반적인 직접 담당 사건의 기준으로 삼는다.** 모든 새 메커니즘을 시험하는 장편 대표 사건으로 키우지 않는다. 사건 구성 범위를 고정하고, 그 안에서 경험 정의 → 기본 시스템 설계를 다시 진행한다. 대표 사건을 설계하면서 확장 경험과 기능을 검토한다.

**제외:** 새로 제안했던 운반대 이동 증언과 사진 공방(INT-01), 그에 따른 후속 A/B 신문·추가 조사 분기. 기존 사진·영상·현장 자료를 없애거나 원본의 사고 경위를 바꾸는 결정은 아니다.

**유지:** 날짜 기반 수임·준비·재판·결과, 법률 검토 ↔ 변론 계획, 자동 기본 공방과 필요한 개입, 짧은 정보와 기록 기반 피드백, 기존 수임료·외부 비용 원칙.

**현재 작업:** 주인공도 역량을 가진 변호사로 두고, 플레이어의 판단이 기본 자동 수행을 보완하도록 설계한다. 정민호 사건은 역량을 고정해 법정 핵심 기능과 가독성을 확인한다. 단순 사건마다 깊은 전략적 딜레마나 강제 개입을 만들 필요는 없다. 직접 참여를 일상 요약·완전 위임으로 바꾸지는 않는다.

재개 입구: [CURRENT](CURRENT.md). 이번 문서 범위: [DESIGN-SYNC-001](../.agent/tasks/DESIGN-SYNC-001.md). Accepted DEC와 런타임 구현 상태는 별도다.

## 1. 정민호 사건 구성 기준선

기준 소스는 통합 DEMO `288e1e7`의 [사건 데이터](https://github.com/PARK-TAEGEON/the-firm/blob/288e1e7276a56887f42f7b5f02146c74b583d50d/courtroom-prototype/data/demo-separated-moments.js)다. 아래는 기존 내용을 재사용할 범위이며 새 대사를 발명한 것이 아니다.

| 구성 | 이번 기본 사건에 남기는 내용 | 경계 |
| --- | --- | --- |
| 사건 | 작업실 정산 다툼 중 밀침, 이후 손목 부상, 상해 기소라는 기존 설정 | 밀침 여부와 상해의 연결이라는 기존 두 핵심 쟁점을 유지 |
| 의뢰인·피해자 | 정민호와 오태윤. 외주 계약을 걱정하는 의뢰인, 실제 손목 부상을 입은 피해자 | 형사처벌과 계약 해지의 자동 연동을 현실 법률로 확정하지 않음 |
| 진술 | 최초 접촉 부인, 재면담의 밀침 인정 | 진술 변경을 기존 내용으로 보존. 거짓말의 새 동기·추가 비밀을 만들지 않음 |
| 증인·상대 | 목격자 한지수, 수사관 서동국, 기존 검사·재판부 | 법정 증인 2명을 기준으로 하며 피해자 등 새 증인신문을 추가하지 않음. 기존 검사 두 유형은 비교 자료로 보존 |
| 검찰 자료 | 목격 진술조서, 영상 정지 사진, 수사보고서, 진단서 | 새 범죄·피해·공소사실을 붙이지 않음 |
| 준비·조사 | 최초 진술 대조, 연속 영상, 진료자료, 현장 동선, 의뢰인 재면담의 기존 5종 | 내용은 재사용. 반나절 4회 제한이나 조사별 필수 클릭을 새 기본 규칙으로 승격하지 않음 |
| 합의 | 기존 제안과 의뢰인의 목표·동의 문제 | 기존 150만 원은 실험 금액. 사건 전용 장기 협상이나 새 비용 갈등을 필수로 늘리지 않음 |
| 결과 | 기존 주문·양형·복기 자료를 검토하며 날짜 허브에 연결 | 기존 고정 형량·판정 조건은 법률 검수·밸런스 완료가 아님. 항소심 전체는 이번 범위 밖 |

**작가용 진실은 유지:** 어깨를 한 번 밀었고, 피해자는 자세를 회복한 뒤 가림막 뒤 운반대에 걸려 손목을 다쳤다. 목격자는 접촉 순간과 낙상 순간을 직접 보지 못했다. 영상의 두 장면 사이에는 약 40초가 있다. 진료기록은 원인 감정이 아니다. 이 사실들을 판사나 자동 검토가 숨은 정답으로 읽게 하지 않는다.

“살살 밀었다”는 최근 대화의 표현을 객관적 강도로 새 확정하지 않는다. 운반대라는 기존 배경·자료는 남지만, **사고 후 누가 옮겼는지·사진이 언제 바뀌었는지의 별도 사건은 다루지 않는다.**

이 기준선에서 구성 요소를 늘려야 한다면 먼저 기존 기본 경험에 왜 필요한지 확인한다. 새로운 재미를 넣을 자리가 생겼다는 이유만으로 기본 사건의 범위를 늘리지 않는다.

## 2. 주인공 역량과 직접 참여

**ROLE-01 / ROLE-02 / BASE-03: 사용자 결정(2026-10-11, “추천대로 할게”).** 주인공도 직원 변호사와 같이 역량을 갖는다. 직접 참여는 역량을 제거하거나 모든 업무를 수동 수행하는 모드가 아니라, 캐릭터의 전문적 판단과 수행에 플레이어가 방향·구체 지시를 보완하는 방식이다. 시스템 구현과 재미는 아직 검증하지 않았다.

| 구간 | 캐릭터가 맡는 기본 업무 | 플레이어가 맡는 판단 |
| --- | --- | --- |
| 사건 검토 | 확보한 자료와 기본 법률 정보를 정리하고 쟁점·위험을 설명 | 무엇을 중요하게 보고 추가로 확인할지 |
| 변론 준비 | 알려진 자료와 정한 방침에 맞는 확인 계획·예상 반론 초안을 제시 | 무엇을 인정하고 다툴지, 어떤 계획을 채택하거나 고칠지 |
| 법정 수행 | 승인한 범위에서 질문·자료 활용·통상 대응을 수행하고 실제 결과 기록 | 필요할 때 신문 목적·주장 범위·대응 방향을 수정 |
| 상담·결과 | 위험과 대안을 설명하고 결과·비용·미해결 사항을 정리 | 어떤 해결을 권하고 어느 부담을 감수할지. 의뢰인 결정 권한은 유지 |

플레이어가 개입하지 않아도 승인된 목표·권한 안에서는 캐릭터가 계속 일한다. 직원에게 위임할 때도 같은 준비·행동·기록·판정의 흐름을 사용하고, 담당자의 역량과 방침이 자동 판단에 작용하도록 한다. 플레이어가 직접 선택했다는 이유로 동일 행동에 추가 성공 보너스를 주는 방식은 채택하지 않는다.

### 역량이 하는 일과 하지 않는 일

- **성장 방향:** 더 효율적인 검토, 더 정교한 초안과 예상 반론, 맡겨둘 수 있는 기본 대응의 범위·질을 높인다. 낮은 역량이 기본 업무를 전혀 못한다는 뜻은 아니다. 구체 역량 항목·효과·성장 공식은 보류한다.
- **기본 지원은 공통:** 용어 설명, 읽은 자료의 정리, 비용·절차·실행 가능 여부 안내와 가독성을 역량으로 잠그지 않는다. 심화 전문 분석의 질과 기본 UI 지원을 구별한다.
- **실행 가능한 타당한 지시:** 능력 주사위로 무산시키지 않는다. 실제 자료·권한·전문 지원이 부족하면 실행 전에 사유를 알린다. 질문이 실행된다는 것과 원하는 답을 얻는 것은 다르다.
- **판정 경계:** 역량은 업무·행동과 실제 기록을 통해 작용한다. 같은 기록에 능력이나 직접 조작 보너스를 더해 판결을 바꾸지 않고, 증거·증언·상대의 비공개 정보·미래 판결을 만들어내거나 읽지 않는다. 명시하지 않은 합의·지출·공개 입장 변경을 자동 승인하지 않는다.

기존 [DEC-017](../DEC-LITIGATION-017_LAWYER_CAPABILITY_AND_PRACTICE_PROFILE.md)의 역량 기반과 [DEC-031 §2](../DEC-LITIGATION-031_NUMERIC_ADJUDICATION_AND_PROPOSED_DEC_RESOLUTION.md)의 행동·기록 경계를 사용한다. 기존 문서는 플레이어 성장 공식을 확정하지 않았다. 능력치의 구체 표시도 보류하며 언어 표시·단일 종합 능력 점수 금지 등 기존 제한을 이번 결정으로 바꾸지 않는다.

### 정민호 사건에서 우선 확인할 핵심 기능

**주인공 역량은 ‘기본 업무 수행 가능’ 수준의 고정 기준으로 두고, 상세 성장·스킬 해금·숙련 등급별 밸런스는 이번 데모에 넣지 않는다.** 역할 분리를 확인하는 임시 기준이며 최종 수치나 프로필을 확정한 것이 아니다.

`짧은 사건·법률 검토 → 기본 변론 계획 검토/수정 → 자동 기본 공방 → 실제 기록과 결과 확인`

이 연결이 이해되고 번거롭지 않은지가 첫 목표다. 플레이어는 준비한 계획을 보고 필요하면 고칠 수 있고, 적절히 준비된 단순 사건을 큰 개입 없이 마칠 수도 있다. 자동화의 관찰 구간을 지루함으로 단정하거나 억지 반전·선택 비용을 붙이지 않는다. 잘못된 판단의 결과는 실제 행동·기록으로 설명하되, 단순 사건마다 복수의 고난도 전략을 요구하지 않는다. 심화 판단과 성장의 체감은 대표 사건 설계에서 확장·검증한다.

첨부로만 제공한 v0.5 PLAY-01은 미반영 검토 초안이다. 이번 v0.6은 원격 v0.4에 최신 사용자 결정을 반영한 것이며, v0.5의 상세 조작·실행 정책을 일괄 승인하거나 구현한 것으로 읽지 않는다. 사건의 구성과 §1은 그대로 유지한다.

## 3. 여기서 설계할 기본 시스템과 이후 확장

| 지금 일반 사건에서 다룰 것 | 대표 사건을 설계하며 검토할 것 |
| --- | --- |
| 기존 자료를 읽고 비교하는 정보 구조 | 복합 쟁점, 다수 당사자, 더 긴 사건 전개가 실제로 요구하는 기능 |
| 법률 검토와 변론 계획의 두 영역 | 새로운 정보로 기존 계획의 중요한 전제가 흔들리는 심화 대응 |
| 계획 → 자동 신문·자료 사용 → 실제 기록 → 결과의 연결 | 휴정·속행 및 기일 사이 추가 준비 등 현재 보류한 절차 후보 |
| 고정 역량의 기본 자동 수행, 짧은 상태·성과·남은 반론 표시 | 상세 성장·전문 역량 보조와 심화 판단의 체감, 필요한 기능의 재사용 |

대표 사건의 구체 소재·분량·필수 기능은 아직 미정이다. 폐기한 사진 공방을 대표 사건에 자동 이관하지 않는다. 대표 사건 때문에 필요한 기능을 찾되 기본 사건 전체에 그 기능의 조작·읽기 부담을 강제하지 않는다. 기본 화면은 공통으로 유지하고 확장은 관련 상황에서만 드러내는 방향이다.

순서는 **일반 사건의 구성 기준선 → 경험 정의 → 기본 시스템 연결 → 대표 사건 경험 설계와 확장**이다. 기본 시스템을 완벽하게 끝내야 대표 사건을 생각할 수 있다는 새 승인 절차나 범용 생성기 선행 개발 요구는 아니다.

| OPEN-01 | 현재 작업에서 종료 | 사진 공방의 유지/추가 확인 비교는 하지 않음. 모든 재판의 개입 문제가 해결됐다는 뜻은 아님 |
| OPEN-02 / OPEN-03 | 후속 유지 | 기본 경험에 맞는 피드백과 최소 공통 데이터는 아래 새 질문에서 구체화 |

## 5. 다음에 답할 질문

**BASE-OPEN-01: 새로운 사건 사실을 추가하지 않고, 플레이어가 준비한 변론 계획이 기존 재판에서 무엇을 달리 실행하게 할 것인가?**

다음은 고정 역량의 주인공이 제시하는 **기본 변론 계획 한 화면**에서 무엇을 자동으로 맡기고 무엇을 플레이어가 고칠 수 있는지 구체화한다. 입장·확인 목적·합의 조언의 상세 컨트롤은 검토 후보이지 최종 UI가 아니다. 핵심은 `방침 → 캐릭터의 기본 계획 → 검토/수정 → 실제 실행·기록`이며 전략 대안의 개수나 강제 중단 횟수를 완료 기준으로 쓰지 않는다. 기존 사건 밖의 사진 이동·새 증인·새 감정은 넣지 않는다.

미정: 기본 계획 화면의 조작·자동 정책, 역량 항목·표시·성장 공식, 지원 범위와 심화 수행 차이, 공통 데이터 형식, 법률 적용·양형, 대표 사건 소재·확장 기능. 다음 제안은 화면의 구체화이며 이번 동의로 코딩 착수를 승인한 것은 아니다. 자동 진행이나 문서 합의를 재미 검증으로 간주하지 않는다.
