## 1. 시작 세계

플레이어는 1인 개업 신입 변호사다. 사무실을 열고 상담을 받으며, 맡은 사건의 결과로 다음 의뢰인과 동료를 만난다. 같은 도시의 변호사들도 사건을 맡고, 사무실을 옮기고, 은퇴한다.

도시 선택지는 WORLD ko 팩의 `population.cities[].name`을 따른다(§4.1 공통 팩 참조). 법조 기관은 지방법원·항소심 법원·최고법원·수사기관 같은 일반 명칭으로 부른다. 시점은 ‘개업 첫해’, ‘지난겨울’처럼 표시한다. 시작 명단에는 신입부터 은퇴자까지 섞여 있고, 선행 시뮬레이션의 이력과 이전 경력의 요약이 이어진다.

업계에서 사람을 소개할 때는 소속, 연차, 주로 맡는 분야부터 말한다. 함께 일하거나 맞붙은 뒤에는 “감정서의 전제부터 묻더라”, “쟁점이 바뀌어도 준비가 되어 있더라” 같은 경험이 붙는다. 오랫동안 쌓인 명성은 은퇴 뒤에도 남고, 한 사건으로 얻은 유명세는 더 빨리 잦아든다.

## 4. 변호사의 분야와 법정 스타일

### 4.1 전문 분야와 공통 팩 참조

전문 분야의 원본은 [WORLD ko 팩](../../task-world-001/courtroom-prototype/world/packs/ko.json)의 `specialties`다. 인물 카드의 대표 꼬리표는 이 배열에서 하나를 고르고, 건설 현장·기업 자금·운송 계약 같은 구체적인 경험은 소개 문장에 쓴다.

| 사용하는 값 | 팩의 위치 |
| --- | --- |
| 전문 분야 | `specialties` |
| 성씨 | `naming.surnames` |
| 도시 | `population.cities[].name` |
| 세대별 이름 생성 음절 | `naming.cohorts` |
| 실존 로펌명 검사 | `firmRegistry.names`와 `naming.bannedFirms` |

참조 기준은 2026-10-07 WORLD 작업 폴더의 `world-003-1`이다. 저장소 기준 경로는 `courtroom-prototype/world/packs/ko.json`이며, 현재 브랜치에는 아직 없어 위 링크는 옆의 `task-world-001` 작업 폴더를 가리킨다. WORLD 병합 후 같은 저장소의 경로로 연결한다. `ko-career.js`는 이 JSON을 내보내는 호환 진입점이다. 본문은 인물별 선택값과 장면 예시를 담고, 선택지 전체는 팩에서 관리한다.

## 5. 시작할 때 생기는 가벼운 연결

시작 시 아래에서 **2개**를 생성하는 안이다. 관계마다 ‘언제 어떤 일을 함께 했는가’ 한 줄을 붙인다. 예: “수습 때 서류 정리를 두 번 도와준 선배.” 상대는 현재 세계 명단에서 경력과 만남 시점이 맞는 사람으로 정한다.

| 연결 유형 | 시작 이력 한 줄 | 정보·소개·경쟁 효과 후보 |
| --- | --- | --- |
| 로스쿨 동기 | 같은 수업의 과제를 함께 준비했다 | 정보: 공개 연수 소식을 전달. 경쟁: 같은 상담 의뢰의 후보로 만나기도 함 |
| 수습 선배 | 수습 때 제출 서류를 함께 검토했다 | 정보: 서류 접수·일정 확인 경로 안내. 소개: 자신의 담당 밖 상담을 연결 |
| 전 직장 상사 | 법조 입문 전 일반 회사에서 함께 일했다 | 소개: 소상공인·회사원의 상담 연결. 경쟁: 다른 사무소에도 견적을 문의 |
| 실무실습 담당자 | 학생 때 상담 접수 실습을 지도했다 | 정보: 공개 상담 행사 안내. 소개: 참가 의뢰인이 원할 때 연락처 전달 |
| 동네 사무실 동료 | 같은 건물의 사무실을 이용한다 | 정보: 회의실·등사·출장 업무 정보. 소개: 일정이 겹친 상담을 서로 연결 |
| 공부 모임 지인 | 자격시험 준비 모임에서 만났다 | 정보: 공개 자료 공유. 경쟁: 비슷한 분야로 개업해 같은 고객을 만남 |
| 전 직장 동료 | 법조 입문 전 같은 프로젝트를 맡았다 | 소개: 동료의 개인 상담. 경쟁: 기존 자문 로펌과 비교 상담 기회 |

플레이어는 연락하기, 소개받은 상담 받기, 이번에는 넘기기를 고른다. 소개 뒤 수임 여부는 업무 여력과 의뢰인의 선택으로 정해진다. 효과는 연락·상담 사건으로 남는다. 시작 이력이 없는 연결은 플레이 중 새로 생길 수 있다.

| ID · 이름 | 현재 | 분야·사건 규모 | 대표 사건과 공식 결과 | 지금도 이야기되는 이유 |

## 7. 세계에 남은 가상 판례 5개

### SET-C01 · 재단표 대금 사건

작은 제작업체가 행사장 칸막이 제작 잔금을 청구했다. 납품 뒤 작성한 요약표와 작업 당시의 재단표가 달랐고, 원고 대리인 황종익는 원자료·인수증·작성자의 설명을 연결했다. **1심 원고 전부 승소, 항소 없이 확정.**

- **증거 검토 요지 후보:** 요약표의 각 수량이 어떤 원자료와 작업에 대응하는지 확인한다. 수정 경위와 다른 자료의 일치 여부를 함께 본다.
- **규칙 수정자 후보:** 제작대금 원형에 ‘원자료 → 집계 → 청구 항목’ 연결을 준비 과제로 추가. 수정본은 작성 경위가 설명되면 검토 근거가 된다.
- **업계의 변화:** 소규모 제작업체들이 납품 수량과 추가 작업을 따로 정리해달라는 계약 자문을 찾는다.

### SET-C02 · 통원기록 사건

환자가 여러 차례 통원 뒤 생긴 손해의 배상을 청구했다. 황정숙은 진료기록의 입력 시각, 진료 시각, 후속 검사 결과를 나누고 전문가에게 각 시점의 판단 근거를 물었다. **1심 원고 일부 승소, 항소심 원심 유지, 확정.**

- **증거 검토 요지 후보:** 나중에 입력된 기록은 작성 경위와 당시 확보된 자료를 대조해 의미를 판단한다. 손해 항목마다 진료와의 연결을 확인한다.
- **규칙 수정자 후보:** 의료 원형의 시간표에 ‘발생·관찰·입력’ 구분을 추가. 추가 설명과 원본 자료가 있으면 기록의 의미가 달라질 수 있다.
- **업계의 변화:** 의뢰인이 가져온 출력물 외에 변경 이력과 검사 시점 자료를 확보하는 준비가 늘어난다.

### SET-C03 · 선급금 장부 사건

여러 납품 계약의 선급금을 다른 용도로 쓴 기업 담당자의 형사 사건이다. 이성후는 유죄 사실을 전제로 실제 사용 내역을 정리하고, 별도로 반환 이체와 피해자 측 수령 확인을 제출했다. **1심 유죄·집행유예, 항소 없이 확정.**

- **증거 검토 요지 후보:** 장부의 ‘반환 예정’ 표기와 실제 반환 사실은 각각 그 근거로 확인한다. 사용 경위 자료와 회복 자료는 서로 다른 판단 단계에 연결된다.
- **규칙 수정자 후보:** 자금 관련 형사 원형에서 ‘약속·이체·수령 확인’ 상태를 구분하고, 회복 사실은 양형 검토 자료에 연결한다.
- **업계의 변화:** 선고 전에 실제 회복 상태를 확인하려는 업무가 늘고, 회사의 발표문과 입금 자료를 따로 챙긴다.

### SET-C04 · 공동작업장 균열 사건

여러 사업자가 공동 작업 공간의 균열 손해를 청구했다. 송미향 측은 일부 구역의 측정 결과를 전체 구역에 적용했으나, 다른 구역의 공사 시기와 사용 하중 차이를 설명할 자료가 부족했다. **1심 원고 패소, 항소심 원심 유지, 상고 기각으로 확정.**

- **증거 검토 요지 후보:** 표본의 선정 이유와 다른 구역에 적용할 수 있는 조건을 살핀다. 각 당사자의 손해와 원인 연결이 쟁점이다.
- **규칙 수정자 후보:** 다수 구역 손해배상 원형에 표본 범위·비교 조건·개별 손해 근거를 기록. 적용 조건이 확인된 표본은 그 범위에서 활용한다.
- **업계의 변화:** 비슷한 공동 청구에서 감정 범위를 먼저 나누려는 수요가 생긴다. 기사에는 패소가 남고, 강연에서는 준비의 한계가 논의된다.

### SET-C05 · 공유단말 삭제 사건

소기업 공용 단말에서 작업 파일이 삭제됐고, 마지막 로그인 계정의 주인이 기소됐다. 조지완은 자동 실행 시간과 다른 사용자의 접근 기록을 연결해 행위자 특정에 다퉜다. **1심 유죄·벌금, 항소심 원심 파기·무죄, 상고 없이 확정.**

- **증거 검토 요지 후보:** 계정 소유, 실제 접근, 삭제 실행의 연결을 검토한다. 개별 인증·목격·자동 실행 기록을 함께 대조한다.
- **규칙 수정자 후보:** 디지털 형사 원형에서 ‘계정 → 접근 → 행위’ 연결을 준비·반박 과제로 추가. 개별 인증 등 연결 근거가 충분한 사례도 같은 구조로 다룬다.
- **업계의 변화:** 공동 장비를 쓰는 고객에게 접근 기록 보존과 권한 구분 자문이 늘어난다.

## 8. 도시별 분위기

| 서울 중앙 | 기업 담당자와 분야별 변호사가 오가는 회의실, 긴 회의 끝에 남는 작은 검토 의뢰 |
| 서울 동부 | 제작 공간과 주거지가 이어지고, 임대차 상담 옆에 납품 계약서가 놓임 |
| 서울 서부 | 창작·공연 계약의 수정 비용을 설명하는 상담, 저녁에 열리는 작은 사업자 모임 |

| 광주 | 전시·공간 운영 상담과 생활 사건, 공개 설명회가 끝난 뒤 이어지는 개별 질문 |
| 대전 | 연구·시험 자료와 공공 발주 문서가 놓인 책상, 기술 용어를 풀어 설명하는 면담 |

## 9. 톤 가이드

기록은 짧고 정확하게, 대화는 당사자의 당면한 필요를 중심으로 쓴다. 전문 용어는 필요한 순간 풀어준다. 사무실의 일상은 밀린 일정, 누락된 첨부파일, 잘못 인쇄한 문서에서 드러난다.

### 9.1 법정

> 변호인: “계정 이름을 확인하신 시각과 파일이 삭제된 시각이 같습니까?”
>
> 증인: “저는 다음 날 아침에 화면을 봤습니다. 삭제 시각은 기록에서 확인했습니다.”
>
> 재판장: “직접 보신 내용부터 말씀해 주시죠.”

### 9.2 기사

> **공동작업장 손해배상 청구 기각…원고 측 패소 확정**
>
> 법조계에 따르면 공동작업장 이용 사업자들이 제기한 손해배상 소송에서 원고 패소 판결이 확정됐다. 쟁점은 일부 구역의 측정 결과를 다른 구역에도 적용할 수 있는지였다. 원고 측은 구역별 공사 시기와 사용 조건의 차이를 입증하는 데 어려움을 겪은 것으로 알려졌다. 사건을 맡은 송미향 변호사는 관련 공개 토론에 참여할 예정이다.
>
> 공식 기록: SET-C04 · 원고 패소 · 항소심 원심 유지 · 상고 기각 · 확정.

### 9.3 의뢰인 대화

> 의뢰인: “못 받은 돈이 있어요. 그런데 소송하는 동안에도 임대료는 나가잖아요.”
>
> 변호사: “청구할 항목과 지금 확인할 수 있는 자료부터 정리하겠습니다. 회수까지 걸릴 시간과 비용도 같이 말씀드릴게요.”
>
> 의뢰인: “그럼 설명을 듣고, 어디까지 맡길지 정할게요.”

## 10. 이름

### 10.1 로펌·인물·사건 표시

로펌은 **법무법인 + 두세 글자**로 쓴다. 본문의 가칭은 서겸·윤맥·정백·명준·의결·여헌다. 작은 개인 사무소는 대표 성명에 ‘법률사무소’를 붙인다.

인물의 성씨는 §4.1 팩의 `naming.surnames`에서 고르고, 세대에 어울리는 두 글자 이름을 붙인다. 본문 이름은 해당 성씨 풀을 사용한 편집 후보이며, 이름 음절은 세대 표를 참고해 조합했다. 같은 화면에 비슷한 소리의 이름이 모이면 후보를 바꾼다. 이름·연령·경력·분야는 따로 고른 다음 경력 시점을 맞춘다.

사건의 공식 제목은 ‘제작 잔금 청구’, ‘진료 관련 손해배상’처럼 대상과 청구·혐의로 쓴다. 기사 별칭은 재단표·통원기록 등 사건에 등장한 보통명사에서 가져온다.

### 10.2 세대별 실제 작명 경향 — 제작용 표

[한국문화원연합회 지역N문화 ‘너의 이름은?’](https://ncms.nculture.org/ceremonial)의 대법원 출처 표에서 세대별 대표 **단일 연도**를 골랐다. 아래는 해당 연도 남녀 1위 이름이며, 여섯 해의 자료로 세대의 이름 결을 참고한다.

| 출생 세대 | 자료의 기준 연도 | 남 / 여의 인기 이름 | 생성할 때 참고할 경향 |
| --- | --- | --- | --- |
| 1950년대생 | 1958 | 영수 / 영숙 | 영·수·숙 계열의 익숙한 한자음 |
| 1960년대생 | 1968 | 성호 / 미경 | 성·호와 미·경·숙 계열 |
| 1970년대생 | 1978 | 정훈 / 지영 | 정·훈·성, 영·정·주 계열이 함께 쓰이는 이름 |
| 1980년대생 | 1988 | 지훈 / 지혜 | 지·훈·민, 지·혜·은 계열 |
| 1990년대생 | 1998 | 동현 / 유진 | 동·현·훈, 유·진·지 계열 |
| 2000년대생 | 2008 | 민준 / 서연 | 민·준·현, 서·연 계열과 부드러운 음절 조합 |

마지막 열은 자료를 바탕으로 한 작명 지침이다. 생성 확률은 사람 검토 뒤 정한다. 연도는 제작 자료에서 사용하고 화면에서는 상대 나이·연차로 표현한다. 2000년대생 후보는 시작 세계의 나이·자격 취득 시점에 맞춰 신입 또는 이후 진입 인물로 배치한다.

### 10.3 실존 로펌명 검사 목록

## 12. 작성 규칙

상위 기준: [게임 헌법](../00_GAME_CONSTITUTION.md), [DEC-016](../DEC-LITIGATION-016_LEGAL_PROFESSIONAL_PROFILE_RELATIONSHIP_AND_INTERACTION.md), [DEC-032](../DEC-LITIGATION-032_LEGAL_SYSTEM_PACK.md). 인물·조직 규모 참고는 [로펌 현황](reference/KO-LAWYERS-FIRMS-2026.md), 결과 다양성 참고는 [법원 통계](reference/KO-COURT-STATS-2025.md)다.

### 12.1 설정의 경계

- 이 문서는 **실험용 authored 설정, DEC 아님**. 로펌·인물·사건·판례·지역 장면·대사는 창작 후보다. 현실의 법률 자문이나 실제 판례 요지로 사용하지 않는다. 판례의 ‘규칙 수정자 후보’는 미구현이며 한국 법 정합성 확인 전 활성화하지 않는다.
- 로펌의 숫자 순위·정확한 인원 비율·창업 일화·대표 이력·고객·고유 조직 특징을 조합해 특정 실존 로펌을 재현하지 않는다. §2의 수십/수백 명은 작성 대역이며 실제 상위 6곳의 대응표가 아니다. 계약 초안의 규모 비율 참고 지시는 최신 §2.10 및 사용자 요청으로 대체했다.
- 실존 인물의 학교·기수·정확한 생년·외모·대표 사건·유명 발언을 조합하지 않는다. 일반적인 동명이인이 있다는 사실만으로 그 사람의 이력을 가져오지 않는다. 이름을 가려도 실존 대상이 식별되는 인물·사건은 이름과 내용을 함께 다시 쓴다.
- 분야 꼬리표는 게임의 경력 표시이며 실존 전문분야 등록 인증을 뜻하지 않는다. 스타일은 판정 보너스가 아니다. 능력·명성·규모·인맥·도시·전관 경력으로 고정 기록의 판정·증거 신빙성을 바꾸지 않는다. 전관 효과는 의뢰인 유치에만 한정한다.
- 연결만으로 내부 정보·상담·수임·친분을 보장하지 않는다. §5의 정보 효과는 공개되거나 적법하게 공유된 정보에 한한다. 소개는 의뢰인 동의와 이해충돌 확인을 거쳐야 하며 소개료 자동 분배는 두지 않는다. 법조 입문 전 직장 관계를 경력 변호사 출발 배경으로 바꾸지 않는다. 1인 시절에 지인을 상시 사건 조언자로 제공하지 않는다.
- 숨은 스타일과 능력은 처음부터 공개하지 않는다. 공개 프로필·관찰·추정·숨김을 구분하고, 보고·소문에는 출처와 시점을 붙인다. 같은 학교·소속이라는 이유만으로 실제 만남 이력을 만들지 않는다.
- 전설의 유명한 패소를 숨은 승리로 바꾸지 않는다. 결과는 당사자 관점과 심급을 함께 쓴다. 집행유예는 무죄가 아니며, 파기환송만으로 최종 승소를 확정하지 않는다. 은퇴자의 명성 감쇠는 §2.10의 최고점·직함 바닥 원칙을 따른다. 여기서 별 수치·감쇠 공식을 발명하지 않는다.
- 다섯 과거 사건은 작성된 요약 이력이다. 실행한 시뮬레이션 결과로 주장하지 않는다. 선행 시뮬레이션에 넣을 때 해당 기록·인물 경력과 정합성을 확인한다. 하급심 확정 사건을 최고법원의 일반 법리로 격상하지 않는다.
- 기사에서는 기자의 해석을 허용하되 실제 세계 기록에 없는 사실·발언·동기를 만들어 넣지 않는다. §9.2의 후속 공개 토론은 L04 이력에 포함된 작성 예시다. ‘법조계에 따르면’도 실제 출처를 대신하는 장치로 쓰지 않는다. 공식 기록은 법률 용어로 보여준다.
- 지역 묘사는 장면 배치안이며 실제 관할·사건 비율·지역민의 성격을 단정하지 않는다. 도시·사투리에 청렴도나 판결 성향을 연결하지 않는다. 피해·가난·장애를 웃음거리로 쓰지 않는다.
- 세대별 이름 표의 단일 연도 순위를 10년 전체의 빈도라고 쓰지 않는다. 이름의 음절로 성별·성격·능력을 고정하지 않는다. 인물 전체 이름은 창작 조합이며 출생 통계에서 추출한 실존 법조인 명단이 아니다.
- 한국 고유 이름·기관·용어·향후 검증된 규칙은 DEC-032의 ko 팩 데이터 후보다. 이 문서에서 엔진 상수·팩 형식·로더를 만들지 않는다. 표시명 교체와 이적·은퇴 뒤에도 실제 세계의 지속 ID와 과거 이력은 보존한다. SET-*는 문서 참조표시다.

### 12.2 이름 겹침 검사 방법과 이번 결과

1. 로펌 가칭에서 공백·구두점·법무법인·유한·법률사무소를 제거하고 §10.3의 팩 목록을 같은 방식으로 정규화해 대조한다. 별칭은 같은 대상으로 묶는다. 띄어쓰기 변경만으로 통과시키지 않는다.
2. 로펌 6곳끼리, 인물 21명끼리 끝 글자가 겹치지 않게 한다. 전체 표시 이름에서 한 글자 교체·삽입·삭제로 같아지는 후보도 제외한다. 인물 검사는 대표 12명·추가 4명·전설 5명을 모두 포함한다. 세대 통계의 실제 예시 이름과 실존 금지 명칭은 창작 명단 검사에서 분리한다.
3. 로펌은 전체 명칭 및 이름+법무법인/법률사무소를, 인물은 이름+변호사를 웹 검색한다. 공개 전에는 판사·검사·분야 조합, 대한변협 명부, 등록 법인명, 상표·영문명·약칭·유사 발음까지 확인한다. 동일 법조 조직·법조인·유명 창작 법조인과 충돌하면 교체한다.
4. 사건은 별칭+판결과 줄거리의 특징을 대조한다. 독립 독자가 이름을 가린 설명을 읽고 실존 대상을 지목하는지 확인한다. 실제 업체·작가 소개 링크와 사생활 자료는 설정집에 싣지 않는다.
