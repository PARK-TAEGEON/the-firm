# THE FIRM — 설계 메모 (2026년 9월)

상태: **실험 lane 지침.** 사용자와 Claude의 설계 대화(2026-09-27~28)에서 합의한 방향이다. Accepted DEC가 아니며, 플레이테스트 결과에 따라 바뀔 수 있다. 정식 채택 시 DEC로 옮긴다.

## §1 사건 생성 (GEN-001)

### 1.1 사건은 경제의 기본 단위
로펌 경영 게임에서 사건은 풋볼 매니저의 선수 같은 핵심 자원이다. 세 층으로 본다.
- 공급: 어떤 사건이 얼마나 들어오나 (명성, 전문 분야, 인맥에 따라)
- 처리: 누구에게 맡기고, 시간을 얼마나 쓰고, 합의할지 다툴지
- 결과: 돈, 명성, 경험, 다음 사건으로의 연결

"서류 더미" 느낌은 공급 층에서 나온다. 매주 쌓이는 사건 파일 중 무엇을 받고 거절할지가 일상 루프다.

### 1.2 세 등급
| 등급 | 비중 | 만드는 방식 | 플레이 |
|---|---|---|---|
| 일상 사건 | 80~90% | 완전 절차 생성 | 수임, 배정, 합의 여부만. 30초~2분 |
| 승부 사건 | 10~20% | 생성 + 반전 모듈 | 준비와 법정 공방 전체 (v0.10 대립 공판 형식) |
| 명품 사건 | 소수 | 전부 직접 작성 | 커리어 전환점. 유명 판례의 법리 뼈대에서 영감 |

### 1.3 생성 공식
`사건 = 원형 × 변수 × 반전 × 인물(의뢰인·상대·증인)`
- **원형:** 실제 판결문 여러 건에서 추출한 법적 뼈대. 필수 쟁점, 흔한 증거 유형, 흔한 항변, 통상 보수·기간
- **변수:** 금액, 관계, 쟁점별 증거 강도, 증인 신뢰도. 시드 기반 결정적 난수
- **반전:** 드라마가 나오는 모듈. 여러 원형에 붙는다. 예: 의뢰인이 사실을 숨김, 핵심 증인의 이해관계, 소멸시효 임박, 이해충돌, 언론 주목, 뒤늦은 결정적 문서
- **반전 하나 = 대응 조사 카드 + 상대의 수습 + 재반대 한 세트.** v0.10의 "간판 불빛 수습 ↔ 조도 측정 카드"가 원형이다. 따라서 `courtroom-prototype/data/trial-case.js` 형식이 승부 사건 생성기의 출력 목표다

### 1.4 진실을 먼저 만든다
1. 숨은 진실 생성 (실제로 무슨 일이 있었나)
2. 진실에서 증거·증언·서류를 도출. 잡음 필터를 거친다: 목격자는 관찰 조건만큼 틀리고, 의뢰인은 성격만큼 숨기고, 문서는 작성자 관점만큼 치우친다
3. 플레이어는 조사로 진실의 조각을 발견한다

사건이 모순 없이 일관되고, 조사가 "진실을 캐는 행위"가 된다. (SYS-001의 "실제 사건 조건" 미정 질문과 연결)

### 1.5 실제 사건 사용 규칙
- 판결문의 **법리 뼈대만** 빌린다. 실명, 날짜, 장소를 복원하거나 조합해 특정인을 알아볼 수 있게 만들지 않는다
- 피해자·유족이 있는 유명 강력사건, 성범죄, 아동 사건은 재현하지 않는다
- 법리 자체가 유명한 판례(예: 전원합의체 판례 변경)는 "판례 변경 이벤트" 재료로 좋다
- 상업 출시 전 법조인 검토 권장

### 1.6 문장 생성
- 실행 중 LLM 생성 금지 (결정성 붕괴, 법률 오류, 비용, 스팀 AI 공개 부담)
- AI는 제작 도구로만: 판결문 → 원형 초안 추출, 반전·대사 변형 대량 초안 → 사람 검토 → 검증기 → 밸런스 점검

### 1.7 원형 데이터 예시
```yaml
id: ARCH_LEASE_DEPOSIT
title: 임대차 보증금 반환
side: 원고(임차인)
fee: { retainer: [200, 500], success_pct: [10, 20] }   # 만원
duration_weeks: [8, 20]
issues:
  - id: CONTRACT_END   # 계약이 적법하게 종료됐는가
    evidence: [계약서, 해지 통지 문자, 내용증명]
  - id: DEDUCTION      # 원상복구비 공제가 정당한가
    evidence: [입주 당시 사진, 수리 견적서, 관리비 내역]
defenses: [원상복구비 공제, 연체 차임 상계, 묵시적 갱신 주장]
twists_allowed: [CLIENT_HIDES_DAMAGE, LANDLORD_BANKRUPT, WITNESS_IS_BROKER_RELATIVE]
truth_params: { damage_by_tenant: [0, 1], landlord_solvent: [0.6, 1] }
```

### 1.8 다양성의 함정
조합 수가 많아도 "다 비슷하다"는 느낌이 오기 쉽다. 해결책은 조합 수보다 **연결**: 다시 찾아오는 의뢰인, 나를 기억하는 상대 변호사, 지난 사건의 결과가 새 사건을 낳는 구조(항소, 관련 소송, 보복 소송).

### 1.9 자동 진행과 전망 (일상 사건의 빠른 처리)

SYS-001 §14의 미정 질문("승부 재판을 명시적으로 분류할까, 직접 개입의 기본 범위는?")에 대한 실험 방향이다. 대부분의 사건은 단순하므로, 조사 후 전망이 좋으면 재판을 자동으로 진행해 빠르게 넘긴다.

**지켜야 할 기존 원칙**
- 헌법 8장: 정확한 승소 확률을 기본 공개하지 않는다. 승패를 준비·선택으로 설명할 수 없는 무작위 결과로만 처리하지 않는다.
- DEC-005 M5 (Accepted): 사건 전체의 성공·실패를 난수 한 번으로 정하는 방식은 기각됐다. M6: 어려운 사건에 별도 실패 주사위를 두지 않는다.
- 따라서 "확률 80% → 주사위 → 가끔 폭사" 방식은 쓰지 않는다.

**역배 = 조사하지 않아 못 본 반전**
- 사건마다 숨은 진실에 따라 반전이 붙거나 붙지 않는다(§1.3, §1.4, GEN-001 구현).
- 조사하면 어떤 반전이 있는지 드러난다. 건너뛰면 모른 채 들어간다.
- 자동 진행 중 숨은 반전이 터지면 그것이 "역배"다. 복기에 "의뢰인 재면담을 했다면 미리 알았을 것"처럼 원인이 남는다. 운이 아니라 건너뛴 준비의 대가다.

**전망은 숫자가 아니라 말로**
- 3단계: "정석대로 갈 것 같다 / 변수가 있다 / 읽기 어렵다".
- 전망 요소: 조사로 확인한 범위(남은 숨은 반전 가능성), 담당자 역량(DEC-017), 사건 복잡도.
- 조사를 더 하면 전망이 **정확해진다**(좋아지는 것이 아니다). DEC-001 L1 "추가 정보는 판단을 바꿀 수 있어야 한다"와 일치.

**자동 진행 = 같은 법정 규칙을 자동 변호 정책으로 실행**
- 별도 확률식이 아니라 대립 공판 엔진을 자동 정책으로 돌린다(GEN-001 `core/playthrough.js`가 원형).
- 담당자 역량에 따라 정책이 달라진다: 신입은 기본 접근법만, 숙련자는 결론 요구·재반대까지.
- 판단 규칙은 같고 상세도만 다르다(DEC-015 §25 원칙과 동일).

**개입 중단점 (풋볼 매니저식)**
- 옵션: 예상 못 한 반전이 발동하면 자동 진행을 멈추고 "직접 변론으로 전환할까요?"를 묻는다.
- 켜면 폭사 직전 개입 기회, 끄면 완전 자동.

**비용**
- 자동 진행은 플레이어의 주간 시간을 거의 쓰지 않고, 직접 변론은 많이 쓴다. "어느 사건에 내 시간을 쓸까"가 경영 판단이 된다(헌법 Finite Human Capacity).

**구현 시점**: 다음 주 "서류 더미" 루프와 함께. 필요한 부품(반전 발동, 자동 플레이, 복기)은 이미 있다.

### 1.10 증언 원칙 (성실하지만 틀릴 수 있는 증인)

- 현실의 증인은 위증죄 부담 때문에 대부분 성실하게 답한다. 게임도 이를 기본으로 한다.
- 법정의 긴장은 거짓말이 아니라 **진심으로 믿지만 틀릴 수 있는 증언**에서 나온다: 짧은 관찰에도 확신하는 목격자, 방법론을 믿는 감정인, 보도로 오염됐지만 자기 기억이라 믿는 증인.
- 대사 규칙:
  - 증인은 자기가 믿는 범위 안에서 성실히 답한다.
  - 근거 없는 일반화 요구에는 "제 기억은 이렇습니다"처럼 버틴다.
  - 기록·자료(카드)를 제시받으면 관찰의 한계를 인정한다. 결론 전체를 버리지는 않는다.
  - 주신문에서 약점을 먼저 말하지 않는다. 증인이 숨겨서가 아니라 검사가 묻지 않기 때문이다.
- 진짜 위증은 드문 반전 모듈로만 둔다. 발각되면 증인에게도 큰 대가가 있는 사건으로 다룬다.

### 1.11 강한 상대와 역전 설계 (2026-09-30)

역량은 판결 합계에 숨은 보너스로 더하지 않는다(DEC-031 N4). 숨은 +2는 화면에 보이지 않아 "왠지 졌다"만 남긴다. 체감은 **상대의 행동**에서 나온다.

**상대 역량이 행동으로 드러나는 곳**
- 뻔한 공격로를 미리 막는다: 예상 가능한 반대신문 접근에 대비한 반박 자료를 이미 들고 있다.
- 이의가 정확하다: 유도·의견 요구가 즉시 잡히고 플레이어 시간이 줄어든다.
- 재주신문으로 복구한다: 흔들린 증언을 다시 세운다.
- 증인 준비가 돼 있다: 신참 측 증인은 흔들리면 무너지고, 베테랑 측 증인은 "기억은 흐리지만 그 사람이 맞다"로 버틴다.

**"실마리를 찾아 어려운 싸움을 풀어냈다"의 구조**
1. 강한 상대가 표면 공격로를 막는다.
2. 상대도 모르는 실마리(진실 쪽 반전, §1.4)가 있다.
3. 찾으려면 플레이어가 조사 방향을 골라야 한다. 역량은 확률·시간만 줄인다.
4. 상대가 준비하지 못한 것이라 막히지 않는다.
5. 복기에 "상대가 막은 것 / 당신이 뚫은 것"을 나란히 보여준다.
6. 업계 소식에 남는다(§2.8 내 로펌).

신참 플레이어는 준비 반나절·신문 선택지가 좁다. 그 빈자리를 플레이어의 판단이 메운다. 성장하면 선택지가 넓어진다.

**검증:** DEMO-001에서 같은 사건을 신참 검사/베테랑 검사로 두 번 하게 해 "차이가 느껴지는가"를 PLAYTEST-001에서 묻는다. 약하면 그때 "경계선 근처의 작은 인상 효과"(DEC-014 원칙과 같은 방식)를 검토한다.

### 1.12 베테랑의 강점 유형, 정보 공개, 조언 창구 (계획 — 데모 이후)

**보여주는 방식: 이름표만, 강점은 겪어서 안다.** 상대 정보는 "베테랑 검사, 형사 20년" 수준만 공개한다. 강점은 재판에서 빡빡함으로 직접 체감하게 하고, 겪은 뒤 인물 정보가 갱신된다("과학수사 증거를 철저히 준비함"). FM의 스카우트처럼 처음엔 모르고 경험·소문·보고로 채워진다(DEC-016 공개/관찰/추정/숨김, §2.6).

**강점 유형 (각 유형은 행동으로만 작용)**
| 유형 | 법정에서의 모습 | 경로 |
|---|---|---|
| 법리형 | 같은 분야를 많이 맡아 해석 다툼에 강함. 법리 쟁점에서 반박이 준비돼 있음 | 법리 조사 카드·반박 자료 |
| 인맥형 | 법조인 네트워크로 **정보**가 빠름: 재판장이 어떤 주장을 중시하는지 알고 그에 맞춰 구성, 감정인·증인 섭외가 빠름, 기일·보석 등 절차 대응이 매끄러움 | 정보·섭외·절차. **판사 편파는 아님**(DEC-016 P16, DEC-031 N4). 전관예우 논란은 업계 소식·소문으로 다룰 수 있으나 판결 보정으로 구현하지 않음 |
| 기술 고문형 | 로펌에 기술 고문·전문가 풀이 있어 기술 증거 사건에서 우위 | 기술 쟁점 카드·감정 반박. 플레이어도 고문을 영입해 같은 우위를 얻을 수 있음(SYS-003 조직) |
| 육각형 | 약점이 뚜렷하지 않음. 드물다 | 여러 경로에 고르게 |

**조언 창구 (사무원·동료 변호사 합류 후)**
- 함께 사건을 맡으면 동료가 조언한다: "상대 측 증인은 아마 이 부분에서 입을 열지 않을 겁니다."
- 조언은 동료의 역량·경험에 따른 **추정**이며 틀릴 수 있다(DEC-027 조언≠보장, DEC-016 추정 층).
- 1인 시절에는 조언이 없다 → 동료를 들이는 이유가 된다(솔로 → 로펌 성장).

**이미 있는 것:** DEC-017 LWP9(강점·한계), LWP18(스타일), LWP20~21(팀 구성·주/보조 역할), DEC-016 P5·P16, DEC-026(업무 배정·팀 협업). 원칙은 있고 게임 내 표현이 없다.

### 1.13 재판 전 물밑 작업 (계획 — 데모 이후, 2026-09-30)

**방향: 한국 법에 근간을 둔다**(2026-09-30 사용자 결정). 미국식 증언녹취(deposition)·디스커버리는 들여오지 않는다. 한국 형사 실무의 승부처를 게임의 고유 장면으로 쓴다. 법정은 준비한 것을 꺼내는 곳이고, **경영 시뮬레이션과 법정 게임이 만나는 곳은 재판 전**이다(누구에게 무엇을 맡기고 시간·돈을 어디에 쓰는가).

**물밑 작업 = 시간·사람·돈을 쓰는 행동 메뉴.** v0.10의 "반나절 4회 · 조사 6종"을 넓힌 형태. 동료가 생기면 나눠 맡긴다(§1.12).

| 행동 | 한국 실무 근거 | 게임에서의 의미 |
|---|---|---|
| 수사기록 열람·등사 | 형사소송법 266조의3 | 검사가 무엇을 들고 있는지 본다. v0.10 "열람 전 증거 봉인"과 같은 구조 |
| 증거 동의/부동의 | 318조, 312조(2022 개정: 검사 작성 피신조서는 피고인이 내용 부인 시 증거능력 없음) | **누구를 법정에 세울지 정한다.** 자백 사건은 "모두 동의"로 끝나고, 다투는 사건은 여기서 전투가 시작된다. 부동의 비용: 재판 지연·비용, 피해자를 법정에 세우면 판사 인상·양형 불리(성범죄 특히), 증인이 법정에서 더 단단해질 위험 |
| 피해자 합의 | 반의사불벌죄의 처벌불원은 1심 선고 전까지만 공소기각 효과(232조 3항 준용). 양형기준상 처벌불원은 주요 감경 요소 | **선고 전 합의 마감.** 기일 연기 신청으로 시간을 벌 수 있다. DEC-028 형사 피해자 합의 보완과 연결 |
| 형사공탁 | 2022.12 공탁 특례(피해자 인적사항 몰라도 공탁). "기습공탁" 문제 이후 법원이 양형 반영 전 피해자 의견 청취(294조의6) | 공탁 선택지. 피해자가 반발하면 효과 감소 |
| 양형 자료 | 반성문, 가족·직장 탄원서, 치료 기록 | 유죄여도 실형/집행유예/벌금을 가른다(결과 층: "유죄 · 집행유예 2년") |
| 증거보전 신청 | 184조: 재판 전 판사 앞 증인신문 | 한국에서 deposition과 가장 비슷하나 드물다. "증인이 곧 출국" 같은 반전 소재 |
| 보석·구속적부심 | 구속 사건이면 최우선 | 의뢰인 만족·시간 압박 |
| 불기소 의견서 | 기소 전 단계 | 재판 자체를 막는 싸움. 수사 단계 사건 유입과 연결 |
| 우리 측 면담·녹취 | 우리 측 증인·참고인 진술서 확보(DEC-022) | 드라마의 회의실 캠코더 장면은 이 형태로 |
| 사설 조사 | 2020년부터 "탐정" 명칭 허용, 사생활 조사 제한 | 정보는 빠르나 선을 넘으면 위험 |
| 언론 대응 | GEN-001 "언론 주목" 반전 | 여론·의뢰인·재판부 인상 |

**윤리 위험이 핵심 긴장.** 상대 측 증인 접촉 → 증인 회유 의심, 합의 압박 → 역풍, 공격적 조사 → 징계. "선을 어디까지 넘을까"는 명성 시스템과 연결된다(System Map "위험한 비정상적 선택": 도입 시 장기 위험과 커리어 훼손). 판결 보정으로는 구현하지 않는다(DEC-031 N4).

**이미 있는 것:** 조사 DEC-021, 면담 DEC-022, 의뢰인 조언 DEC-027, 합의 DEC-028. 부품은 있고 "재판 전 행동 메뉴"라는 틀이 없다.

**확인 필요:** 위 조문 번호·시행일·요건은 대화 중 확인·기억에 근거한다. 구현 직전 원문으로 재확인한다.

### 1.14 법체계 팩 — 한국을 첫 팩으로, 다른 나라로 바꿀 수 있게

**현재 문서 상태(점검 결과):** "다른 나라 버전으로 바꾸기 쉽게"는 명시된 결정으로는 없다. 흔적만 있다.
- `jurisdiction pack`: VS-003·VS-004 계약서에 **범위 밖** 항목으로만 등장.
- TEST-028 / DEC-029 사례 27: "관할별 제한을 하드코딩하지 않는다".
- DEC-023·025: 한국 법 형식·기한·관할 규칙을 발명하지 않는다(데이터로 주입).
- 02_ARCHITECTURE_RULES §3: 반복 콘텐츠는 데이터로 확장. §10: 모드·확장을 위해 빈 계층·범용 프레임워크를 **미리 만들지 않는다**.
- 01_SYSTEM_MAP 법률 범위: "배경 법체계와 추상화 범위" 미정.

**원칙(제안):**
1. **엔진은 법체계 중립, 한국 규칙은 팩 데이터.** 예: "증거 동의 시 조서가 증거가 된다", "처벌불원 마감 = 1심 선고 전", "형사 성공보수 무효", "공탁 시 피해자 의견 청취"는 엔진 코드가 아니라 `ko` 법체계 팩의 규칙 값으로 둔다. 엔진은 "마감 있는 합의", "동의 여부로 증인 소환", "보수 유형 허용 여부" 같은 일반 개념만 안다.
2. **이름·기관·조문도 팩에.** 기관명(검찰/공소청), 절차명, 조문 표기는 현지화 키처럼 팩에서 온다. 법 개정(공소청 전환, 공탁 개정)도 팩 버전 갱신으로 흡수한다.
3. **과잉 설계 금지(ARCH §10).** 지금 만드는 것은 "한국 규칙을 코드에 박지 않고 한 곳의 데이터에 모으기"뿐이다. 두 번째 나라 팩, 팩 전환 UI, 범용 규칙 언어는 실제 필요가 생길 때 만든다.
4. **검증:** 엔진 코드에 한국 고유 규칙 값·기관명이 하드코딩되지 않았는지 검사하는 테스트(v0.10의 "엔진 코드 내 사건 ID 금지" 테스트와 같은 방식).

## §2 세계 시뮬레이터 (WORLD-001)

### 2.1 목표
풋볼 매니저처럼 법조인들이 플레이어 없이도 알아서 움직이는 세계. 헌법의 "Living Legal World". 개별 인물 모델은 DEC-015~017에 이미 있고, 빠진 것은 **세계를 굴리는 시계와 규모·상세도 규칙**이다.

### 2.2 1:1 시뮬레이션 금지, 상세도 3층
DEC-015 §25의 "주요/일반 인물: 판단 규칙은 같고 상세도만 다름" 원칙을 모든 법조인으로 확장한다.
| 층 | 규모(제안) | 내용 |
|---|---|---|
| 주요 인물 | 300~500 | 이름·이력·성격·관계. 매주 시뮬레이션 |
| 일반 인물 | 수천 | 플레이어가 처음 볼 때 생성, 이후 영구 보존(ID 재사용 금지). 월 단위 압축 시뮬레이션 |
| 통계 집단 | 나머지 | 개인 없이 숫자로만. 경쟁 밀도, 수임료 시세, 사건 유입량 |
- **관찰될 때 실체화:** 채용 시장을 열면 그 순간 시드 기반으로 후보자 생성 → 영구 인물
- 일반 인물도 플레이어와 자주 얽히거나 큰 사건에서 이기면 주요 인물로 승격 (DEC-015 일반→저명 전환)

### 2.3 세계의 시계
- 매주: NPC 로펌이 사건 시장에서 수임 → 압축 규칙으로 결과 → 경험·명성 변화, 생애 이벤트
- 매월: 채용, 해고, 이직, 개업. 로펌 순위 갱신
- 연간(한국형 리듬, 실제 시기는 구현 전 확인):
  - 봄: 변호사시험 합격 발표, 연 1,700명 안팎 신규 유입 → 채용 시즌
  - 2월: 법관 정기인사 → **진행 중인 사건의 재판장이 바뀔 수 있음**
  - 검사 정기인사, 연말 파트너 승진·이직 시즌

### 2.4 NPC 판단 (깊은 AI 불필요, 성향 + 간단한 효용)
- 변호사 성향 예: 돈, 명예, 워라밸, 공익, 독립. 매달 급여·업무량·성장·상사 관계를 성향과 비교해 잔류/이직/개업/판사 지원(법조일원화)/휴직/은퇴 중 선택
- 로펌 전략 유형: 형사 부티크, 대형 종합, 공장형(개인회생 대량 처리), 기업 자문, 1인
- 판사·검사: 배치, 순환, 승진, 퇴직 후 로펌행(전관)
- **전관의 효과는 판결이 아니라 의뢰인 유치에만.** "전관이 있으면 이긴다고 믿는 의뢰인이 몰려온다" (DEC-016 유착/합법 경계 준수)

### 2.5 휴직 = 풋볼 매니저의 부상
- 상태: 근무, 휴직(유형, 예상 복귀일), 단축 근무, 정직(징계), 이탈
- 유형: 육아, 건강·번아웃, 유학(LL.M.), 공직 파견
- 원인: 나이, 생애 단계, **업무량**(과로 → 번아웃 확률 상승. 헌법의 Finite Human Capacity)
- 효과: 사건 인계 필요(DEC-002 인계 규칙), 인계 시 준비 일부 손실 가능. 유학 복귀자는 새 전문성

### 2.6 풋볼 매니저 대응
이적 시장 → 인재 영입·스카우트 / 상대 감독 → 상대 변호사·검사 / 심판 → 판사(DEC-013) / 부상 → 휴직 / 유소년 → 로스쿨 실습생·신입 / 리그 순위 → 로펌 순위 / 뉴스 → 법조 신문 / 스카우트 보고서 → 불완전 정보(DEC-016 공개·관찰·추정·숨김)

### 2.7 첫 구현 검증
화면 없이 10년치 돌리고 "법조 신문" 로그를 사람이 읽는다. 확인: 그럴듯한 이야기, 인구 폭증·소멸 없음(DEC-015 L20), 한 로펌 독주 없음.

### 2.8 업계 소식 (인게임 법조 신문)

시뮬레이터의 재미는 플레이어가 세계를 들여다보고 만져 보는 데서 나온다. 세계에서 일어난 일을 게임 안에서 수시로 볼 수 있는 "업계 소식" 화면으로 정리한다. 풋볼 매니저의 뉴스 받은편지함·리그 소식에 해당한다. WORLD-001의 `news.md`가 이 기능의 원형이다.

**소식 분류**

| 분류 | 예시 | 게임에 주는 의미 |
|---|---|---|
| 순위 | 연간 매출 순위, 전략 유형별 1위, 급성장 로펌 | 내 위치 확인, 목표 설정 |
| 대형 사건 | "다온 vs 이음, 3년 분쟁 다온 일부 승소"(기사 말투는 §2.9) | 라이벌의 강약 파악 |
| 판례 | "대법원, 공용 물품 지문의 증명력 제한" | 게임 규칙이 실제로 바뀜 |
| 인사 | 스타 변호사 이적, 전관 영입, 재판장 교체 | 영입 기회, 내 사건 영향 |
| 시장 | "올해 개인회생 수요 증가" | 전문 분야 선택 근거 |
| 내 로펌 | "무명 변호사, 대형 로펌 꺾어" | 성취감, 명성 |

**판례는 규칙을 바꾼다**
- 판례 하나 = 사건 원형·반전에 붙는 수정자(modifier). 예: 측정 방식 엄격화 판례 → 해당 원형에서 변호인 접근법 효과 상승.
- 출처: NPC 로펌 사건의 대법원 확정, 또는 플레이어 사건의 대법원 확정(명품 사건급 커리어 하이라이트, §1.2).
- 전문성이 정보 우위: 해당 분야 전문가가 판례의 영향을 먼저 알아본다(헌법 4장).
- 판례 수정자도 기록 기반·결정적이어야 하며, 판결 무작위화나 숨은 보너스로 쓰지 않는다.

**대형 사건 결과**
- NPC 로펌 간 주요 분쟁은 압축 규칙으로 결과를 내되, 기사에는 "무엇이 결정적이었나"를 한 줄로 남긴다(설명 가능한 결과, 헌법 4장). 세부 규칙은 WORLD-002에서 설계.

**쏟아지지 않게**
- 주간 요약: 한 주 시작 시 1면 5~7건, 나머지는 섹션별 목록.
- 관련도 점수: 내 로펌, 라이벌, 내 사건의 판사·상대, 내 전문 분야 관련 소식을 위로.
- 행동 연결: 이적 기사 → 영입 제안, 패소 기사 → 해당 의뢰인 접근.
- 소문 기사: 확인되지 않은 정보를 섞고 조사로 확인하게 한다(DEC-016 공개·관찰·추정·숨김 층).
- 연말 결산: "올해의 법조 10대 뉴스"를 중요도 순으로.

**데이터 요건 (WORLD-001 다음 라운드부터)**
- 모든 기사에 분류(순위/대형사건/판례/인사/시장/내 로펌), 중요도(1~5), 관련 로펌·인물 ID.
- 기사는 세계 기록의 투영(projection)이다. 기사 때문에 세계 상태가 바뀌지 않는다.

### 2.9 사건 기록·명성·용어 (2026-10-06 사용자 결정)

**사건 기록이 커리어를 만든다.** WORLD의 대형·승부 사건은 GEN 자동 진행(§1.9)으로 실제 재판을 거치고, 결과는 사건 기록으로 남는다. 기록 = 원형·시드·버전·당사자·결과·결정적 장면 한 줄. 시드와 버전만 저장하고 플레이어가 펼칠 때 재생성한다(관찰될 때 실체화). 일상 사건은 통계층.

**공식 기록 용어(법률 용어만)**
| 구분 | 표현 |
|---|---|
| 민사 | 전부 승소 / 일부 승소 / 패소 / 조정 성립 / 화해 / 소 취하 |
| 형사(변호인) | 무죄 / 일부 무죄 / 공소기각 / 집행유예 / 벌금 / 유죄(실형) |
| 형사(검사) | 유죄 / 일부 유죄 / 무죄 |
| 상소 | 원심 유지 / 원심 파기 / 파기환송 |

**업계 소식(기사)은 기자 말투 허용**: 판정승, 완승, 역전승, 체면 구겨 등. 기사는 사실이 아니라 해석이다. 과장·한쪽 시각 가능(DEC-016 공개/추정 층). 기사에서 공식 기록으로 들어가면 정확한 결과를 본다.

**명성 = 별(0.5~5, 반 개 단위)**
- 경력(직함)은 별이 아니라 글로 표시. 직함은 명성의 **출발점**만 정한다.
- 명성은 사건 기록으로 오르내린다. 평가는 **기대 대비**: 형사 무죄율이 약 3%이므로(사법연감 2026) 실형 예상 사건의 집행유예, 강한 상대 상대의 일부 무죄도 성과다. 상대의 명성·사건 등급·언론 주목을 반영.
- 활동이 없으면 서서히 식는다. 대표 분야 꼬리표 하나.
- 명성 ≠ 실력. 실력은 숨김이며 맞붙거나 함께 일하며 드러난다(§1.12).
- 명성은 의뢰인 유입·채용 수락·수임료·기사 비중에 작용하고, 판결에는 작용하지 않는다(DEC-031 N4, DEC-016).
- 로펌 별: 소속 변호사 명성과 로펌 사건 기록으로.

### 2.10 세계관 기본 결정과 시작 시점 (2026-10-06 사용자 결정)

- **지명**: 실제 도시명(서울·부산 등)은 쓴다. 로펌·인물·사건·판례는 전부 가상. 기관명은 일반 명칭.
- **연도**: 흐리게 한다(구체 연도를 화면에 고정하지 않음). 법 개정은 `ko` 팩 버전으로 흡수(DEC-032).
- **주인공 출발점**: 1인 개업 신입으로 고정. 배경 선택(전관·대형 로펌 퇴사·국선전담 등)은 추후 검토.
- **시작 세계 만들기 — 혼합 방식**: 처음부터 나이·연차가 섞인 명단을 현실 분포로 배정해 만들고(사용자 제안), 그 위에서 세계를 일정 기간(예: 10~20년) 저밀도로 미리 돌린다. 미리 돌리는 동안 들어온 사람은 실제 기록을 갖고, 그 이전 경력은 요약 이력으로 생성한다. 시작 시점엔 신입·중견·베테랑이 자연스럽게 섞인다. 끝 상태를 현실 분포(docs/reference/KO-LAWYERS-FIRMS-2026.md: 서울 76%, 초대형·중견·소형·법인 외 비율)에 맞춰 검증한다.
- 기준 데이터: docs/reference/ (변호사·로펌 현황, 로펌 매출, 사법연감 통계).

**설정 2차 방향 (2026-10-07 사용자 결정)**
- **개성은 로펌보다 변호사에게.** 로펌은 현실적인 구조(규모·업무 구성·사업 방식: 종합/대중 네트워크형/부티크/지역 거점)로만 가볍게 구분한다. 이야기와 색깔은 개별 변호사의 전문 분야·평판·법정 스타일에서 나온다(예: 연예계 사건에 강한 변호사, §1.12 강점 유형).
- **설정을 과하게 잡지 않는다.** 로펌에 서사·사명·캐릭터를 부여하지 않는다. 현실감이 우선.
- **주인공과의 연결은 조금만**: 고정 서사 대신 가벼운 연결 몇 개(예: 로스쿨 동기, 수습 때 선배)를 시작 시 생성한다.
- 이름: 로펌은 "법무법인 + 두세 글자", 인물은 세대별 실제 작명 경향. 실존 로펌명 금지 목록.
- 전설적 인물: 사건 규모와 결과를 다양하게, 유명한 패소 1건 포함. 안전 문장은 한 섹션으로 모은다. 판례는 증거 규칙형 우선.

**명성 감쇠 (2026-10-07)**: 활동이 없어도 별은 천천히 식고, 최고점·직함이 바닥을 정한다(은퇴한 전설도 높은 별 유지). 빨리 식는 것은 사건 한두 건으로 생긴 반짝 명성뿐.

### 2.11 장면 연출 — 장소 배경 + 대화창, 페이스팩 (2026-10-07 사용자 결정)

데모 플레이 후 지적: 사건에 몰입하기 어렵다(인물이 역할 이름뿐, 시작이 규칙 설명, 반전이 요약 카드로 지나감).

- **인물에게 이름과 사정**: 대표 사건의 목격자·수사관·검사·피해자에게 가상 이름을 주고, 의뢰인·피해자에게 걸린 것(생계·계약 등)을 한 줄씩 둔다. 이름·사정은 표시 데이터이며 판정 입력이 아니다(DEC-031 N4).
- **사건 시작 = 첫 상담 장면**: 규칙 메모 대신 의뢰인이 사정을 말하는 대화로 시작한다. 사건 메모는 다시 열 수 있는 참고 자료로 남긴다.
- **FM식 장소 배경 + 대화창**: 사건마다 같은 삽화를 띄우지 않는다. 장면마다 장소 키(사무실 응접실·경찰서 접견실·법정 복도·법정·현장 등)를 두고, 장소 사진을 어둡게 깐 위에 대화창을 올린다. 사진이 없으면 단색 + 장소 이름으로 대체한다(사진 없이도 동작). 직접 그린 삽화 시안은 폐기.
- **얼굴은 기본 비움**: 기본판에는 인물 얼굴을 넣지 않는다. 기본 초상은 FM식 실루엣(얼굴형·머리·어깨만, 이목구비 없음) 하나를 모든 인물에 쓴다(2026-10-07 결정, 성 한 글자 표시 대체).
- **첫 장소 사진**: 의뢰인 면담 = 사무실 회의실(Unsplash, 무료 라이선스). 출처는 `courtroom-prototype/assets/CREDITS.md`.

### 2.12 데모 공판 절차 보강 (2026-10-07 사용자 결정)

실제 단독 형사 공판과 비교해 데모에 넣은 것: 준비 → 모두진술 → **증거 의견(동의/부동의, 318조)** → 부동의한 진술 증거의 증인만 소환 → **구형(302조) → 최후변론 → 최후진술(303조)** → **선고 기일(2주 뒤)** → 판결.
- 증거 의견: 진술조서·수사보고서 동의 시 해당 증인 미소환 + 기록에 내용 반영. 다툴 이유 없는 서류(진단서·사진) 부동의는 재판장 신뢰 −1.
- 변호인 증거 신청(294조): 조사 결과마다 신청/신청 안 함/보류. 변론 종결 전까지 변경 가능, 종결 시 보류=미신청. 증거물(연속 영상·진료기록·현장 사진)은 신청해야 효과. 탄핵용 조서·의뢰인 면담은 신청 불필요.
- 신청 시점: 공판 전 신청은 노련한 검사가 대비(재반대 차단), 공판 중 늦은 신청은 재판장 신뢰 −1. 신참 검사는 대비하지 않음.
- 최후변론·최후진술은 판정 입력이 아님(DEC-031). 판결 화면에서 최후변론과 판결 근거의 일치만 복기.
- 베테랑 검사 → "노련한 공판검사 · 공판 전담 10년차"(20년차 부장급이 단독 사건 공판에 드는 것은 비현실적).
- 데모 밖으로 미룬 것: 인정신문, 피해자 증인·진술권(294조의2), 피고인신문(296조의2), 양형 자료(반성문·탄원서·공탁).
- 조문 표기는 ko 팩에 unverified로 두고 출시 전 법률 검수.
- **페이스팩·장소팩(창작마당 모드)**: 유저가 얼굴과 장소 사진을 팩으로 넣을 수 있게 한다.
  - FM은 고정 DB의 ID에 사진을 붙이지만, 이 게임은 세계 시뮬이 판마다 인물을 만든다. 그래서 두 방식을 함께 쓴다. (1) 태그(성별·나이대·분위기) 붙은 얼굴 **묶음**에서 세이브 시드로 결정적 배정(같은 세이브에서 같은 얼굴). (2) 직접 작성한 고정 인물은 **ID 지정**.
  - 초상·배경은 표시 전용이다. 판정·기록·NPC 판단은 읽지 않는다.
  - **실존 인물 사진 금지**를 창작마당 규칙과 팩 안내에 명시한다(가상 세계이므로 실존 법조인 얼굴을 가상 인물에 붙이면 초상권·명예훼손 위험).
  - 데모 단계는 매니페스트(`byId`, `pool`)와 대체 표시까지만. 태그 배정·스팀 창작마당 연동은 제작 단계.
- **배경 사진 출처**: 상업 이용 무료 스톡(Unsplash·Pexels 등, 사용 직전 라이선스 재확인) 또는 직접 촬영. 법원 내부는 촬영 제한이 많아 스톡 또는 단색 처리.
