## 1. 직급과 책임: 최소 4+1

| 분류 | 보수 구조 | 게임 내 주된 의미 |
| --- | --- | --- |
| 주니어 어쏘시에이트 | 고정급 + 계약된 성과 보상 | 조사·리서치·초안·기본 사건 수행. 검토·지도 필요도는 사람과 업무에 따라 다름 |
| 시니어 어쏘시에이트 | 높은 고정급 + 성과 보상 | 사건 리드·핵심 서면·후배 검토. 시간은 유한 |
| 고용 파트너 | 높은 계약 보수 + 실적 보상 | 고객 확보·팀 총괄·중요 사건 감독; **법적 구성원 여부는 별도** |
| 지분 파트너 | 파트너십 약정에 따른 이익 배분, 별도 보수 가능 | 출자·경제적 권리·의결권·책임 구조는 조직 형태와 계약에 따라 구분 |
| 카운슬/고문 (별도 경로) | 연봉/계약 자문료 | 특정 분야 전문성 및 자문. 일반 승진의 필수 관문이 아님 |

별도 **직책**은 대표/매니징 파트너, 팀장, 사건 책임자 3종을 핵심으로 하고, 지원 인력은 법률지원/운영관리/외부 전문가의 3개 **직무군**으로 간소화한다. 한 사람이 여러 직책을 겸할 수 있다.

연차·직함을 법률 실력, 진실 판단, 법정 성공 보너스로 변환하지 않는다. 주니어도 해당 법적 자격/지정 요건에 맞으면 실제 사건을 수행한다. 법무법인 구성원 요건·담당변호사 책임은 `ko` 팩의 확인된 법적 제약을 따른다.

## 2. 승진과 계약 변경

- **실무 적격성:** 실제 WorkProduct·검토·독립 수행 범위·전문 분야 경험. 승패 횟수나 만능 XP가 아님.
- **책임 적격성:** 사건 리드·업무 감독·고객 응대·지도 및 실제 팀 운영 이력.
- **조직 필요:** 현재 맡길 직책·검토 병목·급여 지속 가능성·직원 본인의 커리어 선호.
- 주니어→시니어는 실무 비중이 크고, 시니어→고용 파트너는 고객·팀·책임 역량이 중요하다. 지분 파트너는 자동 승진이 아니라 **별도 계약/지위 변경**이다.
- 승진과 급여 인상은 독립 선택이다. 승진 없이 급여 인상, 승진 심사 유예, 타 로펌으로 이직, 카운슬 전환 등이 가능하다.
- 계약 당사자의 합의와 적법한 고용·파트너십 조건 없이 급여·권한·책임을 소급 변경하지 않는다.

승진은 즉시 능력치를 올리지 않는다. 역량 변화는 DEC-017에 따라 실제 실무·교육·지도 경험 및 검증된 성장 이벤트가 프로필 버전을 바꾸는 방식이다.

## 3. 직원 성향과 관계·만족의 분리

기존 World의 주된 가치관 **돈 / 명예 / 워라밸 / 공익 / 독립**을 유지하고, 보조 선호 1개까지 표현 가능하게 한다. 초기 성격 표현은 `협상 태도(직설/신중)`와 `협업 선호(독립/협력)` 정도로 제한한다.

| 축 | 의미 | 요구에 반영되는 방식 |
| --- | --- | --- |
| 보수 기대 | 시장·경력·외부 제안·계약 | 급여/성과급/이익 배분 협상 |
| 성장 기대 | 업무 난도·승진·인정 | 승진 심사·자율권·중요 업무 배정 요구 |
| 업무환경 기대 | 과로·휴식·협업·자율성 | 사건량 조정·팀 이동·관리 방식 요구 |
| 가치관 기대 | 공익·전문 분야·커리어 방향 | 사건 구성, 멘토링, 전문 팀 이동 요구 |
| 존경심 | 선임/대표의 능력과 판단에 대한 **방향성 평가** | 협상 태도, 설명 수용, 한시적인 유예 의향에 제한적으로 작용 |
| 호감·업무 신뢰 | 개인적 선호 / 과거 약속·업무 이행의 평가 | 협업·소개·구체 약속의 신빙성에 영향 |

'만족도' 단일 충성도 게이지로 모든 요구를 결정하지 않는다. **급여 만족, 업무량 만족, 성장 만족, 자율성, 인정, 가치관 일치**의 근거와 시점을 보존한다. 존경하지만 과로에 불만일 수 있고, 싫어하지만 급여·업무환경에 만족할 수 있다.

NPC가 인지하지 못하는 외부 제안이나 내부 숨은 평가를 요구 생성기에 미리 넘기지 않는다. UI는 공개/관찰/추정/비공개 정보 경계를 유지한다.

## 4. 보수 정책과 실험용 요구식

기본 정책 후보: **안정형**(직급/경력 중심), **실적형**(근거 있는 업무·고객 기여), **혼합형**(기본급 + 평가 가능한 보상; 초기 추천). 파트너 이익 분배는 별도 계약으로 처리하며, 청구/미수/실입금과 이익을 혼동하지 않는다.

**실험용 보수 요구식** (실제 한국 임금통계나 확정 밸런스가 아님):

`기준 월 보수 B = max(시장상 알려진 적정 조건, 현재 계약 보수)`  
`첫 요구 월 보수 = B × (1 + p)`

프리미엄 `p`의 제안값:
- 협상 기본 +4%p
- 돈 중시 +4%p
- 현재 보수에 대한 뚜렷한 불만 +3%p
- 대표에 대한 존경심 낮음 +2%p / 높음 −1%p
- `p`는 우선 +2%~+13% 범위에서 제한해 **실험**한다.

같은 B=450만원, 돈 중시+보수 불만의 예:
- 존경심 높음: `p=10%` → **495만원**
- 존경심 낮음: `p=13%` → **508.5만원**

**중요:** 이는 **최초 희망 제시액**이지 자동 수락 하한, 법률상 적정 임금 또는 이직 확률이 아니다. 존경심/공익심을 핑계로 현재 약정 급여·시장 기준선을 낮추지 않는다. 실제 외부 제안·승진·업무 조건·신뢰 가능한 일정 있는 약속은 별도 제약과 근거로 판단한다. 실적형 보상은 기여 기록을 요구하며 승소율 가산과 연결하지 않는다.

## 5. SYS-004 가정의 손익 계산 교차 확인

**단위는 만 원.** 기존 SYS-004 v0.3의 실험 조건: 사선 사건 350만원·30시간, 국선 50만원·12시간, 수임료 변동비 10%, 급여 부대비용 20%. 이를 채용 1명이 **추가로** 부담하는 일을 평가하는 단순 기여이익 계산에 사용했다.

| 가정 월급 | 연 총인건비(×12×1.2) | 사선만으로 회수할 추가 사건 수(올림) | 대응 업무시간 |
| ---: | ---: | ---: | ---: |
| 주니어 450 | 6,480 | 21건 | 630시간 |
| 시니어 700 | 10,080 | 32건 | 960시간 |
| 고용 파트너 1,200 | 17,280 | 55건 | 1,650시간 |

사선 한 건의 변동비 차감 기여는 `350×0.9=315`만원. 따라서 1,200만원 고용 파트너를 **개인 처리 건수만으로** 회수하려면 큰 업무시간이 필요하고, 실제 고객 유치·팀 운영/감독 및 다수 사건 기여가 중요하다.

연 1,104 사건시간 중 80%(883.2시간)만 청구 가능한 업무로 채우는 주니어 가정:

| 사선/국선 업무시간 구성 | 변동비 차감 연 매출 | 주니어 총인건비 후 기여 |
| --- | ---: | ---: |
| 사선 100% | 9,274 | +2,794 |
| 사선 70% · 국선 30% | 7,485 | +1,005 |
| 사선 50% · 국선 50% | 6,293 | −187 |

**모든 수치는 산식에 따른 반올림값**이며 검토·멘토링·영입 비용, 공용 인건비, 사무실 고정비, 사건 수요 제약, 중복 매출 제거는 반영하지 않았다. **추가 매출만** 채용의 증분 수익이다. 대표가 이미 처리하던 사건을 주니어에게 배정한 금액은 신규 매출이 아니다. 월급표 자체도 한국 전체 시장의 표준이 아니다.

## 6. 인사 요구 → 협상 → 이탈

1. **요구 이벤트:** 정기 인사 시즌(초기 후보: 연 1회) 혹은 외부 채용 제안, 승진 약속 지연, 과로, 주요 사건/책임 변화 등 실제 변화가 있을 때만 발생.
2. **요구의 종류:** 급여/성과급, 승진·직함, 업무량, 자율권/사건 구성, 근무 형태, 교육·멘토링.
3. **로펌의 선택:** 수용 / 조건 변경 제안 / 근거·시한 있는 유예 / 거절. 모든 제안이 실제 재무·권한·기일 조건을 충족해야 한다.
4. **잔류·이직 판단:** 직원의 가치관, 현재 조건, 약속 신뢰도, 알게 된 실제 외부 대안, 경력 목표를 비교. 무작위 매주 퇴사 주사위나 단일 충성도 임계값 금지.
5. **이직/승진 후속:** 계약·보수·책임·팀/사건 인계·남은 업무·고객 선택·커리어 이벤트를 변경 기록으로 보존. 인물이 사라지거나 법정 기록이 재작성되지 않는다.

예상된 상황의 반응 예:
- 돈 중시 + 낮은 존경심 + 월 500만원 제안 → 더 높은 보수 역제안 **가능**.
- 워라밸 중심 + 과로 지속 + 월 550만원 제안 → 돈보다 업무량 개선을 요구할 수 있음.
- 명예 중심 + 승진 정체 → 승진 심사·중요 사건 요구.
- 독립 중심 파트너 + 자율권 부재 → 팀 운영 권한이나 별도 진로 요구.
- 공익 중심 + 의미 있는 공익 업무 부족 → 업무 구성 조정 요구.

위 반응은 **설계 기대 사례**일 뿐 보장된 행동/검증 통과 사례가 아니다.

## 7. 시스템 책임·검증·후속

- **Organization:** 계약 직급/직책, 인사·업무 배정·가용시간, 승진·인수인계.
- **Business:** 급여 약정·실지출·인건비 예산·미지급 의무·이익 분배.
- **Career / World:** NPC 목표·외부 제안·경력 기록·관계·이직 의사결정.
- **Litigation:** 업무 수행·검토 결과와 경험 출처. 법정 결과에 성향·직급·존경심 직접 가산 금지.
- **Presentation:** 알려진 정보와 선택지 표시. 숨은 성향·실제 내부 능력을 그대로 공개하지 않음.

**검증 게이트 (미실행)**
- 동일 직원의 급여만 인상 / 직급만 승진 / 업무량만 줄이는 실험에서 요구 종류가 구분되는가.
- 존경심 높음/낮음의 동일 시장·동일 현재 보수 대조에서 **희망액** 차이는 작지만 약정 급여 이하로 내려가지 않는가.
- 과로/자율성/공익 요구가 돈으로 무조건 해결되지 않는가.
- 손익 계산이 수요 한도·인력시간·검토 병목·재무 현금에 의해 제한되는가.
- 3~5년 규모별 인사 실험에서 과도한 급여 상승·잦은 무작위 이직·지나치게 유리한 승진 정책이 없는가.
- 승진/멘토링만으로 능력 변화가 없고, 실제 업무/교육 경험과 이력에 의존하는가.
- 동일 법정 기록이라면 직원의 성향/존경/연봉 변화만으로 판결이 달라지지 않는가.

**확인된 것:** 위 §5와 보수 첫 요구액의 **산술 재검산**.  
**미검증:** 정책의 게임 균형, 장기 행동, 실제 이직률, 현실 급여 대표성. 과거 대화에서 언급된 '150개 조합·12개 협상 사례 검사'의 독립 실행 원자료는 현재 GitHub에서 확인하지 못했으므로 이번 작업의 테스트 통과 수치로 주장하지 않는다.

후속: 최소 10~20명 NPC, 소형/중형 로펌, 3~5년 시뮬레이션 → 실제 이직 제안·급여·파트너 승진·검토 업무 영향 확인 → 필요한 척도 보정 → 승인된 규칙만 구현 계약으로 승격. 재판 P0/P1 우선순위는 변경하지 않는다.
