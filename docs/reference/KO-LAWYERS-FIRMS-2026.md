## 4. 게임 설계 함의

- 무죄율 3.3%: 형사 변호의 실제 승부는 무죄보다 **양형(집행유예·벌금)과 합의**다. 결과·명성 평가를 "기대 대비"로 해야 하는 근거(WORLD-002).
- 국선 37%: 신입·소형 로펌의 사건 유입 경로로 큰 비중(SYS-004).
- 소액·본인소송이 민사의 다수: 일상 사건 자동 진행(§1.9)의 근거.
- 매출 피라미드: 1인당 매출 차이(약 4억 대 7억 대 15억)가 로펌 층별 경제 모델의 기준.
