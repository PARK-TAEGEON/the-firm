# PLAYTEST-001 진행 키트 — DEMO-001 “두 장면 사이”

대상: 법률을 모르는 사람 최대 5명(PLAYTEST-001). 진행자는 먼저 설명하거나 정답을 알려 주지 않는다. 한 명당 **30~40분**: 안내·동의 3분, 첫 판 15~20분, 선택적 두 번째 판 5~10분, 종료 질문 5분.

> DEMO-001은 아래 종료 질문 **5개로 확정**한다(2026-10-07 사용자 요청). v0.10용 질문 9개를 추가로 묻지 않는다.

## 0. 준비 (진행자용)

- 실행: 전달받은 폴더의 **`courtroom-prototype/demo.html` 파일 하나를 더블클릭**한다. 서버·터미널·설치는 필요 없다. `data/`, `engine/`, `services/`, `ui/` 폴더는 HTML 옆에 그대로 둔다(HTML만 따로 옮기지 않는다).
- 테스터 사이에는 **브라우저 새로고침**으로 사건 파일 시작 화면을 확인한다. 이전 사람의 검사·준비·합의·복기를 이어서 보여 주지 않는다.
- 시작 화면처럼 첫 판은 **신참을 권장**하고, 최종 선택은 테스터에게 맡긴다. 시간이 남으면 두 번째 판은 **다른 검사**로 권한다(질문 3을 위해).
- P1 수정 확인 장면: 통과시킨 유효 이의의 설명, 재면담 후 부인 복기, 무죄·공소기각의 놓친 준비, 동선 복기 중복. 재발하면 단계와 발언을 적는다.
- **중단 규칙:** 테스터가 그만두고 싶다고 하거나 불편·피로를 말하면 즉시 중단한다. 기술 오류로 진행 불가, 3단계 힌트 후에도 진행 불가, 총 40분 도달 시 플레이를 끝낸다. 중단을 실패로 설득하거나 재시작을 강요하지 않는다. 원인·단계·시간을 기록하고 원하면 종료 질문만 받는다.

### 3분 막힘 시 힌트 3단계

같은 지점에서 3분 멈추면 아래 순서로 한 단계씩 제공한다. 각 단계 뒤 약 1분 스스로 시도할 시간을 준다. 진행자가 대신 클릭하지 않는다.

1. **의도 확인:** “지금 무엇을 하려고 하세요?” 말로 정리하게 한다.
2. **화면 위치 안내:** “화면 아래의 진행 버튼과 현재 안내 문구를 확인해 보세요.” 필요한 영역만 가리키고 선택은 맡긴다.
3. **조작 안내:** 현재 화면에서 계속하는 데 필요한 조작만 설명한다. 예: “이 화면에서는 입장 두 항목을 고른 뒤 아래 버튼으로 진행할 수 있어요.” 조사·이의·합의의 정답이나 승리 경로는 알려 주지 않는다.

힌트 시각·단계·문구·이후 해결 여부를 적는다. 도움을 받은 완주와 설명 없이 완주를 구분한다.

## 1. 테스터 안내문 (읽어 주거나 보여 줄 3줄)

> 당신은 형사 사건을 맡은 변호사입니다. 화면의 안내만 보고 사건을 끝까지 진행해 주세요.
> 생각나는 것은 소리 내어 말해 주세요. 막히거나 헷갈리는 순간이 저희에게 가장 중요한 정보입니다.
> 정답은 없고, 저는 먼저 설명하지 않습니다. 오래 막히면 조작 힌트만 드리며, 언제든 쉬거나 그만두셔도 됩니다. 끝나면 짧게 다섯 가지를 여쭙겠습니다.

## 3. 종료 후 질문 5개

답을 그대로 적는다. “왜요?”만 한 번 더 묻는다.

1. **설명 없이 끝까지 할 수 있었나요?** 가장 헷갈렸던 순간은 언제였나요?
2. **결과가 왜 그렇게 나왔는지 설명해 주실 수 있나요?** 납득이 됐나요? (테스터가 자기 말로 이유를 말하는지 본다)
3. **(베테랑으로 했다면) 상대 검사가 강하다고 느꼈나요? 그 강함이 공정했나요, 불공정했나요?** 어느 장면에서 그렇게 느꼈나요? (신참만 했다면: 신참 검사가 어떤 상대로 느껴졌나요?)
4. **재판 전에 합의를 할 수 있다는 것을 알아챘나요?** 합의가 결과에 어떤 영향을 줬다고 생각하나요?
5. **한 판 더 하고 싶나요?** 한다면 무엇을 다르게 해 보겠어요?
